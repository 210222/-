## 1. 场景层设计

### 1.1 戏剧变化与信息策略

```text
场景前状态：无继承——独立故事。周岚已拆开信，已知道内容——她站在水槽旁，背对或侧对父亲。周成已看过信，坐在餐桌前沉默。两人之间的沉默意味着"信的内容"已经改变了他们的关系——场景开始于变化已经发生之后，观众看到的只是后果。

戏剧变化：周岚要求父亲承认一个真相（"你早就知道她还活着"），周成不口头承认也不否认——他用一个动作（关火、交钥匙）代替所有回答。钥匙是他能给出的全部，但信里没有地址——他给的不是答案，是通往答案的路径。周岚接受钥匙但把信留在桌上——她选择行动但不选择原谅，或者她选择未来但不选择接受过去被隐瞒的方式。场景的戏剧实质：两人建立了"以物代替语言"的交流通道——这是他们此刻唯一可能的交流方式。

信息策略：观众从沉默中进入——不知道信的内容、不知道"她"是谁、不知道周成为什么隐瞒。周岚的一句对白给观众关键信息：父亲早就知道某人还活着。其余的——信的内容、"她"的身份、钥匙通向何处——保持为未解问题。观众始终比人物知道得更少，悬念在于"他们之间发生了什么"而非"会发生什么"。水壶鸣叫是场景的中场转折——在此之前是质问与沉默对峙，在此之后是行动与交接。

场景后状态：钥匙在周岚手中，信留在桌上。周成未辩解、未解释。两人的物理距离未变（仍一个在水槽旁一个在桌边），但关系已变——从对峙转为某种对"不完美解决"的接受。独立结算，无下场传递。
```

### 1.2 空间调度

```text
场景空间：老旧小厨房，约 2.5m x 3m。厨房有岁月痕迹——墙面可能发黄、木制橱柜门不太严合。水槽靠左墙，上方有小窗（清晨光线入口，窗外可能是居民楼墙面或天空）。炉灶在水槽右侧紧邻。小餐桌靠右墙，方形（约 0.8m x 0.8m），桌面有旧桌布或直接是木面。周成坐在餐桌靠墙侧，面朝水槽方向（偏左前方）。周岚站在水槽旁，身体微侧向餐桌方向。

关系线：周岚站立（高）→ 周成坐着（低），形成俯视-仰视的权力倾斜。但周岚的质问未获口头回应——她的"高度优势"被周成的沉默化解。两人之间的对角线约 2m——厨房小但距离感大。关系线沿两人视线连线（周岚→周成，约 45 度斜线），轴线为连接两人的假想线。

人物路径：
- 周岚：场景开始时站在水槽旁（可能刚放下手中的碗碟或杯子，或只是站在那里面对父亲）。L19: 说质问句时身体完全转向周成。L26: 上身微前倾，右手伸出拿钥匙。拿起钥匙后，身体微微挺直，视线从钥匙→父亲→桌上的信。场景结束时仍站立。
- 周成：场景开始时坐在餐桌前。L19-L21: 视线不移向周岚——看水壶蒸汽。L21: 水壶鸣叫后，他身体略前倾站起约 10cm（不完全站起），右手伸向炉灶关火。L23: 重新坐定，右手从桌面推钥匙向周岚方向约 20cm。L23-27: 视线保持在水壶或蒸汽方向，不直视女儿。

摄影可用区域：厨房门口（可拍全景建立）、餐桌与炉灶之间的狭窄通道（约 0.8m 宽）、水槽侧墙角（可拍周岚正面带父亲后景）、餐桌正对面墙角（可拍周成正面带周岚后景）。空间狭窄限制机位选择——使用广角至中焦段。
```

### 1.3 视觉策略

```text
视觉强度：低开场 → 中高（水壶鸣叫时峰值）→ 中低收尾。强度曲线呈单峰：蒸汽积聚和鸣叫是场景的物理高潮，视觉强度同步上升——蒸汽变浓、人物紧张度提升、声音层加厚。鸣叫后的关火和交钥匙是释放，强度缓缓下降。

色彩策略：冷暖对峙。窗外晨光（色温约 5600K，柔和的北方光线或薄云过滤的阳光）从水槽上方窗户斜入——照亮周岚的左侧面和厨房左半部。室内暖色灯泡（约 3000K，可能在餐桌上方或厨房中央）照亮餐桌区域——使周成的面部呈暖调。蒸汽（白色/半透明）是中性的中介色——在两种色温中飘过，将两者揉在一起。信的白色在暖色桌面上是视觉落点。强调色：钥匙的金属银/铜色（反光）。

光比策略：整体中等对比（约 1:2.5）。晨光从侧窗入为主光源，柔和不刺眼。室内灯为辅。光比在关火时微变化——炉灶火焰熄灭使餐桌区暖色减少约 20%，周成的面部从暖调转向微冷——与他的情感闭合同步。

稳定性策略：固定机位为主。首镜可能有极缓慢的微幅移动（模拟呼吸），次镜和三镜固定。厨房场景的"静止"中有一种凝固的时间感——像厨房里的空气本身也停住了。

节奏曲线：三镜。Shot 1（5s，建立+沉默）→ Shot 2（8s，质问+蒸汽+鸣叫+关火+推钥匙+对白——场景最长镜，承载核心动作）→ Shot 3（4s，拿钥匙+留信——收束）。节奏形状：慢→快→停。
```

### 1.4 镜头拆分理由

```text
三镜结构对应场景的三段式呼吸：沉默对峙→爆发与交接→选择。

Shot 1（5s）是"进入"——观众需要时间注册空间关系（谁在哪、气氛如何、什么已经发生了）和蒸汽的视觉存在（它是本场的重要视觉母题）。拆出一个单独建立镜而不是从 Shot 2 直接开始，是因为沉默本身携带信息——它告诉观众"对话开始前已经发生了什么"。

Shot 2（8s）是场景的核心——从质问到关火到推钥匙到说话，是一个连续的物理和情感弧线。不拆这个段落：蒸汽积聚→鸣叫→关火→推钥匙是一条因果链，打断它会破坏累积的压力感。水壶鸣叫的物理压力（声音尖利、蒸汽喷涌）是周成行动的触发器，必须在同一镜内完成才成立。

Shot 3（4s）是"选择"——周岚拿起钥匙但留下信。这个动作需要独立一镜是因为它改变了场景的物质状态（信留在桌上 / 钥匙离开），而且它是对整个场景的裁定——需要给观众时间看清她的选择。
```

### 1.5 全场转场策略

```text
入场方式：Shot 1 直接切入——观众进入一间已有沉默的厨房。蒸汽在上升，两人在各自位置静止。没有"进入厨房"的动作——观众被直接放置在"已被改变的关系"中间。

出场方式：Shot 3 以周岚手中的钥匙和桌上留下的信作为结束画面。她不看信的最后一眼——她已经决定不取走它。画面在此停留 1s 后切出。

场间关系：本场独立故事。无前场继承。无后场传递——Scene 3 是独立故事。末镜结束即独立结算。
```
