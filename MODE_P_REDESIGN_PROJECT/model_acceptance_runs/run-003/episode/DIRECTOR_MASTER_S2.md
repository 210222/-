## 1. 场景层设计

### 1.1 戏剧变化与信息策略

```text
场景前状态：(无) — 独立场景，无前场继承
戏剧变化：周岚以质问开场（"你早就知道她还活着"），父女之间的沉默对抗。周成不回答，以行动代替语言——关火、推钥匙。周岚最终拿起钥匙但留下信——接受行动许可但拒绝被替代的真相。情感从对峙的张力转为沉默的分离。
信息策略：观众开场不知信的内容——只看到已拆开的信纸。周岚的质问揭示真相：母亲还活着，父亲知道。周成的沉默是回答——他确实知道。钥匙的出现提供出路但也是新的谜题。最后信留在桌上——真相被绕过了，但未消失。
场景后状态：周岚取走钥匙，信留在桌面。父女之间的断裂已确认但未解决。无跨场传递。
```

### 1.2 空间调度

```text
场景空间：老旧厨房，约十余平方米。水槽靠东墙（面向北窗），窗在北墙——清晨光线从此斜入。煤气灶在水槽旁边。小餐桌位于厨房中部偏南，上有信纸。铝制水壶在灶上。
关系线：东北-西南斜线——周岚站在东北侧水槽旁，朝向南侧餐桌方向；周成坐在餐桌南侧，朝向西北（看向灶台和水壶方向）。二人的视线不直接相交——他们的对峙通过空间中的物件（水壶、信、钥匙）来中介。
人物路径：周岚开场站在水槽旁，未走动。周成始终坐在桌旁。周岚在 S2-4 中从水槽方向移动至餐桌旁取钥匙，然后走向厨房门口（假设在南侧或西侧）离开——这是本场唯一的空间位移。
摄影可用区域：厨房门口方向（南侧，可用于建立镜头）、水槽侧（东北，低角度拍周岚）、灶台侧（西北，拍周成与窗户关系）、窗对侧（南侧，逆光剪影）。
```

### 1.3 视觉策略

```text
视觉强度：低→中→低。开场是静态的、被蒸汽柔化的低强度对峙。水壶鸣叫时将强度推至中等——声音的刺耳打破沉默。关火后强度回落，钥匙推过桌面的动作在极度安静中进行。末镜周岚离开，强度回到低——一种沉静的了结。
色彩策略：琥珀暖调（色温约 3200K），清晨低角度阳光经窗进入。墙面的暖灰色、木桌的深棕色、水壶的铝银色。信纸的白色在暖调中是唯一的冷点——它是无法被暖化的冷真相。蒸汽在光线中形成白色/乳白色体积。
光比策略：中低光比（约 1:4），清晨柔光通过窗户的漫射使阴影柔和。蒸汽进一步提高光的散射，降低整体反差。人物面部在蒸汽中柔和——周成的面部被蒸汽部分遮挡是一种有意为之的视觉遮蔽。
稳定性策略：固定机位为主，三脚架。S2-4 中周岚走向门口时摄影机保持静止——她走出画面而不是摄影机跟随。厨房的视觉语言是稳固的、不加修饰的——像一个见证了太多而不需要动摄影机的空间。
节奏曲线：8s-6s-8s-7s。第一镜长而静——建立空间和等待。第二镜最短——质问的尖刺。第三镜回到长镜头——行动计划取代对峙。末镜是离开——用适中的时长完成空间清退。
```

### 1.4 镜头拆分理由

```text
四镜结构对应对峙→行动→分离的三段式。(1) 建立镜让观众先理解空间和二人物理距离，同时蒸汽和信暗示未言的紧张。(2) 周岚的质问需要她自己的镜头——她的身体静止在蒸汽中是一种视觉宣言。(3) 周成的回答不是语言而是行动——镜头必须紧紧抓住他的手：关火、推钥匙。这是整场的戏剧核心。(4) 回到广角——周岚穿过空间取钥匙离开，信的留守是最终画面。四镜之间的节奏变化遵循"静→言→动→离"。
```

### 1.5 全场转场策略

```text
入场方式：S2-1 开场即为厨房全貌——蒸汽、信、二人已就位。观众被投入对峙的起点，无铺垫。
出场方式：S2-4 末镜——周岚离开画面后，镜头在空荡的厨房（信留在桌上，水壶不再鸣响）停留片刻后切出。空间的空荡是情感的余音。
场间关系：本场结束后进入独立的 S3（夜行列车），无叙事连接。S2 的"钥匙代真相"母题与 S1 的"警徽反制权力"、S3 的"存储卡换身份删除"形成物件交换的系列。
```

### 1.6 双视图共享上下文

```text
场景蓝图：[D] 老旧厨房，十余平方米。清晨暖光从北墙小窗斜入，在空气中与灶上铝水壶的蒸汽交融——体积光可见。周岚（30 岁上下，居家便装，袖口微卷）站在东侧水槽旁，身体朝向水槽，转头看向桌边。周成（60 岁上下，旧工装背心，手部皮肤粗糙）坐在南侧小餐桌前，不看女儿——看水壶或蒸汽。桌上放着一封已拆开的白色信纸。空间紧凑，物件充满生活痕迹——老式煤气灶、白瓷水槽、木质小餐桌。视觉核心是蒸汽——它模糊边界，软化冲突，让沉默有视觉形状。
声音基调：[D] 水壶加热的渐进声——从安静到轻微沸腾再到即将鸣叫的张力累积。清晨室外极轻微的鸟鸣或远处车辆声（低频，几乎不被注意）。对话在蒸汽的轻微嘶声中稍显模糊——声音的柔软包裹了尖锐的质问。关火后，声音世界从"蒸腾的嗡声"骤变为"绝对安静"——这个对比是声音设计的核心。
```
