## 1. 场景层设计

### 1.1 戏剧变化与信息策略

```text
场景前状态：(无) — 独立场景，无前场继承
戏剧变化：审讯权力从林警探手中翻转到许然手中。开场林以物证（照片）施压，握有主动权；许然以反证（警徽）回击，迫使林收回手——身体语言的撤退确认权力已转移。
信息策略：观众开场与林共享"照片指控"的已知信息；许然的警徽是全新信息，在放置瞬间同时揭示给观众和林；观众见证林的权力瓦解全过程。
场景后状态：权力反转已完成，无跨场传递。
```

### 1.2 空间调度

```text
场景空间：密闭审讯室，约 12 平方米，无窗，灰色墙面，单一顶光源。金属桌居中，桌面长约 1.8 米，宽约 0.8 米。
关系线：东西向轴线——林警探坐东侧，面朝西；许然坐西侧，面朝东。二人视线在桌面中心线交汇。
人物路径：无大幅位移。林前倾→后退（收回手）；许然后靠→前伸手（放警徽）→回靠。二人空间入侵与撤退通过上半身和手臂完成。
摄影可用区域：桌面西端外侧（OTS 林→许然）、桌面东端外侧（OTS 许然→林）、桌面北侧或南侧（侧拍双人）。
```

### 1.3 视觉策略

```text
视觉强度：中→高。开场审讯对峙是稳定的中强度；警徽出现时升至高峰（金属反光破局）；林收手后回落至新的平衡——一种沉静的、已决出胜负的低强度。
色彩策略：冷硬青灰基调（色温约 4000K）。金属桌面的冷色反光是空间主调。警徽的金色/银色高光是唯一暖色破局点，集中观众全部注意。
光比策略：高反差（约 1:8），顶光源在人物面部留下深眼窝阴影。警徽出现后，桌面出现一片新的亮反射区，吸引视线。
稳定性策略：固定机位，三脚架稳定。审讯室的视觉语言是控制与静止的——直到林的手在半空停住，摄影机不运动，让演员的身体语言独立承载戏剧。
节奏曲线：7s-8s-6s。第一镜建立空间和权力初始状态；第二镜是反击和节奏峰；第三镜是收束，用最短的镜头完成最大的心理变化。
```

### 1.4 镜头拆分理由

```text
三镜结构对应权力的三次位移：(1) 林推照片→指控建立，(2) 许然放警徽→反击发生，(3) 林收手→权力翻转确认。过肩机位使观众轮流与攻防双方共情——第一镜观众站在许然身后承受压力，第二镜站在林身后被反击，第三镜以客观中近景见证结果。不切双人中景或俯拍桌面，因为物件之间的关系必须通过人的反应来赋义。
```

### 1.5 全场转场策略

```text
入场方式：S1-1 开场即进入对峙——照片可能已在滑动中或刚停稳。观众被直接扔进审讯的中段，前因由物件暗示。
出场方式：S1-3 末镜林的手完全收回，画面留驻于他的面部或上半身——他已不是审讯者，而是被反制的对象。画面在此停住，给观众消化权力翻转的空间。
场间关系：本场结束后进入独立的 S2（老旧厨房），无叙事连接。S1 的收束情感（权力被颠覆的冷感）为后续各场"物件交换"的母题定下基调。
```

### 1.6 双视图共享上下文

```text
场景蓝图：[D] 密闭审讯室，冷硬顶光。林警探（40 岁上下，深色便装）与许然（30 岁上下，深色外套）隔金属桌相对。桌面有一盏台灯或顶灯集中照明，使桌面成为画面最亮区域。一张模糊的停车场照片从林手中推向桌面中央；许然从外套内袋取出一枚金属警徽放在照片旁边。物件占据桌面视觉重心，人物面部在顶光下形成深影。空间的紧张感来自对峙的静止与物件的微小移动之间的反差。
声音基调：[D] 持续低频空调嗡嗡声（约 60Hz）。物件接触金属桌面的硬质摩擦声（照片滑动）和轻金属撞击声（警徽落下）是仅有的声音事件。对话声音干燥、无混响——审讯室墙面吸音，声音压得很近。无外部声音渗入——空间是绝对密闭的。
```
