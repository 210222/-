## 1. 场景层设计

### 1.1 戏剧变化与信息策略

```text
场景前状态：(无) — 独立场景，无前场继承
戏剧变化：顾言（执法人员）要求米娅（证人）交出存储卡。米娅先以沉默和把玩（卡夹在指间不递出）对抗，然后提出条件——从证人名单中删除她的名字。顾言以翻扣工作证回应——暴露自己的身份和脆弱面。米娅确认此条件被接受后，才将卡放到桌面中央。力量从顾言（初始要求者）到米娅（条件制定者）再到双方（互给互取的平等交换）。
信息策略：观众开场不知二人具体关系和卡的内容——仅从对话和物件推断。隧道黑暗是信息遮蔽的物理隐喻——谈判在黑暗中更赤裸。出隧道后，光回归等于真相回归——观众看到证件的翻转和卡的放置，交换在光下完成。
场景后状态：交易完成——卡在桌面中央，证件面朝下在桌面。二人之间建立了新的关系（互有把柄）。无跨场传递。
```

### 1.2 空间调度

```text
场景空间：夜行列车狭长包厢，宽度约 2 米，长度约 3-4 米。窗在北侧——占据包厢大半面墙。窄桌固定于窗侧，宽约 0.5m，二人隔桌对坐。窗外是城市夜景（灯光广告牌、街灯）和偶尔的隧道壁。
关系线：南北向轴线——顾言坐南侧，面朝北（面窗），背对包厢门方向；米娅坐北侧，面朝南（面朝包厢内部），背对窗。窄桌在二人之间。
人物路径：无人走动。所有位移限于上半身和手臂。顾言的手从桌面→证件→翻扣；米娅的手从指间→桌面中央。物件的空间移动是唯一的"走位"。
摄影可用区域：包厢门方向（南侧，建立镜头，拍向窗）、窗侧向外拍（逆光剪影）、通道侧向窗拍（侧光近景）。
```

### 1.3 视觉策略

```text
视觉强度：中→低（黑暗）→中高（光回归）。开场城市灯光穿过车窗形成动态光带——视觉活性高。隧道中近乎全黑——强度降到最低，只有仪表灯和偶尔的外部光闪现。出隧道后强度回升——光线恢复，物件交换在清晰的侧光下完成。强度的曲线是一个 V 字形。
色彩策略：双状态系统。隧道外：冷色城市灯光（约 5600K）为主，广告牌的彩色闪光（霓虹粉、蓝、绿）为点缀。隧道内：近乎单色——极暗蓝灰基调，仅有列车仪表灯（约 3000K 暖橙小点）和偶尔的安全灯。出隧道后回到冷色调——但这时的冷是清晰而非杂乱的。
光比策略：隧道外高反差（1:16+）——窗外明亮城市与暗色包厢内部形成剪影。隧道内极低光比（接近 1:1）——几乎无反差。出隧道后恢复高反差。光的开关即是戏剧的开关。
稳定性策略：三脚架固定。列车的微振动是空间真实感的来源——摄影机不动但画面中的人物和物件有轻微晃动（列车运动的传递）。这种振动在隧道中更明显（铁轨回声增强导致振动频率变化）。
节奏曲线：8s-9s-9s。第一镜是过渡——从光到暗的空间建立。第二镜是最长的静止——在黑暗中谈判，时间被拉长。第三镜是解决——光线回归后的交换，用与第二镜相等的时长给出对称的收束。
```

### 1.4 镜头拆分理由

```text
三镜结构对应光的三相：(1) 光→暗的过渡——建立空间的特殊条件。(2) 暗中的对峙——在视觉最低点展开戏剧最高点的谈判。(3) 暗→光的回归——在光明中完成交换。不拆分更多镜头因为隧道的长度是场景的自然时钟——在黑暗中的对峙需要不被切割的长镜头来维持幽闭感。三个镜头对应列车运行的三段：入隧→隧中→出隧。
```

### 1.5 全场转场策略

```text
入场方式：S3-1 开场即为列车运行中的窗外视角——城市灯光流动。观众先感受空间的速度和光的环境，再看到人物。从外到内的建立顺序将"光"确立为场景的第一语言。
出场方式：S3-3 末镜——卡和证件在桌面中央，侧光稳定。画面停在物件上——交换已完成。切出至黑场。
场间关系：本场结束后进入独立的 S4（雨中停车楼），无叙事连接。S3 的"双条件交换"母题延续的物件主题——卡换身份删除 vs 警徽换审讯逆转 vs 钥匙代信——形成完整的物件权力三部曲后转入动作场景。
```
