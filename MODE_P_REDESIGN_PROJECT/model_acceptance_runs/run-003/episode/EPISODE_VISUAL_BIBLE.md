## 1. 全片视觉策略

### 1.1 核心戏剧母题：物件即权力

本集四场独立场景共享一个深层结构——人物在压力下通过一件物理物件的递交、扣留、交换或隐藏完成权力的转移。物件不是道具，而是戏剧关系的可触化载体：警徽翻转审讯、钥匙替代真相、存储卡交换身份、文件袋以牺牲保全。每场的视觉设计围绕"物件在空间中的路径"展开，让物件运动成为构图的引力中心。

### 1.2 全片色彩与光线策略

四场场景跨越四种截然不同的空间与时段，各自使用独立的色调系统，但共享一条底层原则：光的方向性随权力转移而偏移。

- **场景 1 审讯室**：冷硬荧光主导（色温约 4000K，青灰基调）。警徽金属反光作为唯一暖色破局点——它打破光的单调，宣告权力的反转。
- **场景 2 老旧厨房**：清晨低角度暖光（色温约 3200K，琥珀基调），从一扇小窗斜入，在水蒸气中漫射。信纸的白色在暖调中显得冷——它是被遗弃的冷真相。
- **场景 3 列车包厢**：双状态——隧道内近乎全黑，仅有微弱仪表灯；出隧道后冷色城市灯光（约 5600K）斜穿过窗，形成高反差条纹。光的回归即是真相的回归。
- **场景 4 停车楼**：雨夜的钠灯光（约 2200K 橙黄）与水泥冷灰形成互补对比。雨水反射将所有光源拉长，垂直方向上暖光递减、暗部加深，形成从地面到顶层的亮度梯度。

全片不使用单一统一调色板；每场的色彩与光比从其空间、时段和戏剧状态内生出来。

### 1.3 全片摄影风格

- 镜头运动由物件驱动：摄影机追踪或等待物件的移动路径，物件落定后摄影机才转向人物反应。
- 构图权重始终偏向手握/放/递/藏物件的身体局部——手是每场戏真正的主角。
- 景别变化遵循"物件→面孔→手→物件"的循环：物件引入压力，面孔揭示意图，手执行决定，物件落定证实结果。

## 2. 角色视觉身份

### 2.1 林警探（Lin）
- 年龄：40 岁上下。职业刑警的外形——短而整齐的发型，深色便装外套或衬衫，不系领带的敞开领口。
- 视觉签名：手指习惯性压在物件上（照片、桌面），站/坐姿前倾幅度控制空间支配感。眼睛在审讯中始终锁定对方，直到警徽出现后才首次断开视线。手比脸先反应——手在半空停住的瞬间是他的权力瓦解点。
- 标志镜头：中近景，略俯角，让观众看到他在桌面空间中的控制区域。

### 2.2 许然（Xu Ran）
- 年龄：30 岁上下。外型干净但不刻意——深色外套，便于隐藏内袋物品。动作极少，每一个都有明确目的。
- 视觉签名：静止中的精确。他先让林警探完成全部审讯动作，再以一次不加速的、从内侧掏出的动作放置警徽。手放稳后抬起，回到视线水平，重新与林警探对视。整个过程中身体后靠在椅背上，不进攻，只等待。
- 标志镜头：过肩中景——观众透过林警探的肩膀看见许然完成反击。

### 2.3 周岚（Zhou Lan）
- 年龄：30 岁上下。居家便装，不刻意打扮，袖口可能微微卷起——她在厨房环境中是自然的。
- 视觉签名：站在水槽边的垂直姿势与坐在桌旁的父亲形成高度差。转身幅度不大——身体朝向水槽，只转头与父亲对话。拿钥匙的动作是手臂伸出、手指合拢、收回——全程身体重心不向父亲移动，保持物理距离等于情感距离。
- 标志镜头：低角度中景从水槽方向看过去，让水蒸气在画面中制造柔和的遮挡。

### 2.4 周成（Zhou Cheng）
- 年龄：60 岁上下。穿着旧居家服或工装背心，手部皮肤粗糙——常年劳作的人。动作缓慢但稳定。
- 视觉签名：沉默有重量。他不看女儿，看水壶、看蒸汽、看自己的手。关火的动作使水壶鸣叫戛然而止——声音空白成为他的回答。推钥匙的动作不抬头，手停住后仍留在桌上不动。
- 标志镜头：近景正面，蒸汽在他与镜头之间，面部始终被部分柔化。

### 2.5 顾言（Gu Yan）
- 年龄：35 岁上下。穿深色外套或夹克，携带可翻面出示的工作证。
- 视觉签名：隧道中他的面部仅被窗外偶尔闪过的光勾勒边缘，几乎不可读——他在隐瞒。出隧道后，他把证件翻面扣下——这个向下翻转的动作是他交出脆弱面的身体语言。米娅放卡后，他不立即伸手取卡——先看她，再取卡。
- 标志镜头：侧光近景，窗外灯光在他脸上形成移动的高光条。

### 2.6 米娅（Mia）
- 年龄：28 岁上下。穿着中性——证人身份不需要视觉标签，但双手的紧张感出卖她的处境。
- 视觉签名：存储卡始终在两指之间——像捏着一张扑克牌。直到顾言的证件翻面扣下，她的手指才松开，将卡平放到桌面中央。放卡时手指推卡至中心线区域，不越过中线——她仍保留最后的安全距离。
- 标志镜头：中景稍俯——让观众看到她的手与卡，以及桌面作为"交易区"的物理边界。

### 2.7 阿泽（A-Ze）
- 年龄：25 岁上下。快递公司制服或深色工装，运动鞋。怀中文件袋用透明防水袋或塑料袋包裹——雨天可见。
- 视觉签名：跑步姿态不是逃亡而是路线执行——他知道要去哪里。在转角处弯腰滑包的动作是熟练的（可能不是第一次这样做）。到顶层后的静止：双手撑膝，大口呼吸，侧耳听。面部在听到发动机声时的微变化——不是解脱，是确认。
- 标志镜头：跟拍中全景——始终能看到他的文件袋与身后追赶者的距离关系。

## 3. 空间视觉设计

### 3.1 场景 1：审讯室
- 空间基调：密闭、无窗，单一顶光源。灰色或蓝灰色墙面。金属桌面的反光是空间中最亮的表面。
- 视觉母题：桌面等分——照片侧（初始权力区）vs. 警徽侧（翻转后的权力区）。两件物品在桌面中心线两侧形成视觉对位。
- 摄影可用区：桌面两端的外侧（过肩机位）、桌面侧面（侧拍机位）、桌面正上方不可用（无实际机位支撑点）。

### 3.2 场景 2：老旧厨房
- 空间基调：小——大约十余平方米。墙面有年代痕迹，水槽是老式白瓷或水泥材质。煤气灶，铝制水壶。清晨光从一扇小窗斜射进，在地面和桌面投下窗格阴影。
- 视觉母题：蒸汽——它模糊边界，让周成的沉默有视觉借口。信——白色长方形在暖色桌面上像一个冷缺口。钥匙——被推出后的运动轨迹在桌面上形成一条斜线。
- 摄影可用区：厨房门口方向（建立镜头）、水槽侧（拍周岚）、灶台侧（拍周成）、窗对侧（逆光剪影）。

### 3.3 场景 3：列车包厢
- 空间基调：狭长包厢，宽度约 2 米。窄桌固定于窗侧。窗外是城市夜景——灯光广告牌、街灯、偶尔的隧道壁（黑色）。
- 视觉母题：光/暗交替——隧道是谈判的遮蔽，出隧道是协议的见证。窗外光以横向条纹落在人物身上，随列车移动而流动。证件和卡在桌面上形成两个静止点，与流动的光形成对比。
- 摄影可用区：包厢门方向（建立镜头）、窗侧向外拍（逆光剪影）、通道侧向窗拍（侧光）。

### 3.4 场景 4：多层停车楼
- 空间基调：混凝土结构，裸露的梁柱。坡道有防滑纹或裂痕。每一层有转角平台。橙色钠灯光从天花板悬挂。雨水从坡道边缘淌下，在地面形成流动反光。
- 视觉母题：垂直空间——追赶者从下方出现、阿泽向上跑、文件袋横向滑入车底。三个运动方向（上、横、下）构成空间的完整张力。货车是一座"墙"——它隔断了追赶者的视线，保护了文件袋。
- 摄影可用区：坡道下端（仰拍，建立追赶关系）、坡道转角（跟拍阿泽）、顶层边缘（俯拍建筑边缘）。

## 5. 全片声音策略

每场使用完全不同的声音世界：
- **S1 审讯室**：持续低频空调嗡嗡声。物件的硬质接触声（照片滑过金属桌面、警徽落下的轻金属撞击）是仅有的声音事件。对话量少但声音干燥、无混响——近距离压迫感。
- **S2 老旧厨房**：水壶加热的渐进声、沸腾后的鸣叫、关火后的静默。清晨的室外偶有鸟鸣或远处车辆，但极轻微。对话在蒸汽声中稍显模糊。
- **S3 列车包厢**：持续铁轨节奏（低音区），隧道内混响变化（回声加重、高频衰减），出隧道后轮轨声恢复。窗外城市的碎片化声音——广告声、喇叭——在隧道中完全消失。对话在隧道内外混响不同。
- **S4 停车楼**：持续的雨声（在混凝土结构中的独特混响），脚步回声，追赶者的喊叫（内容不清晰，只有声音指向）。货车发动机从下方传来的低频轰鸣——这是全片最后的声波事件。
