## 总览

本集由四场独立场景组成，每场为自足的"戏剧单元"。无人物、道具、服装、伤势、时间或空间跨场发生。
这是设计上的选择——四场场景通过物件转移的母题而非叙事连续性连接。因此本连续性账本记录每场的自足边界，不建立跨场继承关系。

## 场景 1：审讯室（S1，L3-L14）

- **人物**：林警探、许然。仅存于本场。
- **道具**：停车场照片、警徽。仅存于本场。
- **状态继承**：无前场状态。开场：林警探已将照片推到桌中央（动作刚完成或正在进行中）。
- **状态交出**：林警探收回手，审讯权力反转已完成。无跨场传递。
- **连续性类型**：self_contained

## 场景 2：老旧厨房（S2，L15-L27）

- **人物**：周岚、周成。仅存于本场。
- **道具**：已拆开的信、储物柜钥匙。仅存于本场。
- **状态继承**：无前场状态。开场：周岚已站在水槽旁，周成已坐在餐桌前，信已在桌上。本场开场即为对峙的起始瞬间。
- **状态交出**：周岚拿走钥匙，信留在桌上。无跨场传递。
- **连续性类型**：self_contained

## 场景 3：夜行列车包厢（S3，L28-L39）

- **人物**：顾言、米娅。仅存于本场。
- **道具**：存储卡、顾言的工作证。仅存于本场。
- **状态继承**：无前场状态。开场：二人已隔着窄桌就座，谈判尚未开始。列车正在运行中。
- **状态交出**：存储卡在桌面中央，工作证面朝下在桌面。交易完成。无跨场传递。
- **连续性类型**：self_contained

## 场景 4：多层停车楼（S4，L40-L47）

- **人物**：阿泽、两名追赶者。仅存于本场。
- **道具**：文件袋。仅存于本场。
- **状态继承**：无前场状态。开场：阿泽已在坡道上奔跑，追赶者从下一层冲上来——追逐正在进行中。
- **状态交出**：阿泽停在顶层边缘，文件袋在货车底部，货车发动机启动。阿泽的逃生路线被切断但任务完成。无跨场传递。
- **连续性类型**：self_contained
