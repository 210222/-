## 1. 场景层设计

### 1.1 戏剧变化与信息策略

```text
场景前状态：(无) — 独立场景，无前场继承
戏剧变化：阿泽（快递员）从被追赶的逃亡状态，通过一次隐蔽的物件转移（将文件袋滑入货车底部），转变为任务完成但逃生路线被切断的状态。追赶者（二人）从"追"到"错过"——他们在物理上胜过阿泽但追丢了目标物件。阿泽在顶层听到货车发动声——文件袋安全但自己被困。戏剧的核心是"牺牲"：用自身暴露换取物件安全。
信息策略：观众开场即可见阿泽怀抱文件袋奔跑——物件是可见的目标。追赶者的出现建立威胁。转角滑包是信息的关键——只有观众和阿泽知道文件袋去了哪里（追赶者不知）。S4-3 的 POV 镜头让观众通过追赶者的眼睛见证"错过"——制造悬念的延迟释放。末镜货车发动声从下方传来——给观众确认：物件安全。
场景后状态：阿泽在顶层边缘，文件袋在货车底部，货车发动机已启动。逃生路线切断但任务完成。无跨场传递。
```

### 1.2 空间调度

```text
场景空间：多层停车楼，混凝土结构，裸露梁柱。坡道盘旋而上，每层有转角平台。橙色钠灯光（约 2200K）从天花板悬挂，每隔 10-15 米一盏。雨水从坡道边缘淌下，在地面形成流动反光。空间垂直延伸——从地面层到顶层有显著高度差。
关系线：垂直上下——阿泽在上、追赶者在下。初始追赶距离约 10-20 米。水平方向——坡道是主要移动轴，转角平台是关键时刻发生地（滑包）。
人物路径：阿泽：从坡道下方入画→沿坡道向上跑→跨过排水沟→在转角平台滑包入车底→继续向上→到达顶层边缘停住。追赶者：从坡道下方入画→向上追赶→越过排水沟→经过货车→继续向上（追错方向）。
摄影可用区域：坡道下端（仰拍建立追赶关系）、坡道转角（跟拍阿泽滑包）、货车旁（POV 过肩）、顶层边缘（俯拍建筑边缘和下方）。
```

### 1.3 视觉策略

```text
视觉强度：高→极高→高→中。S4-1 以仰角追逐建立高强度；S4-2 以跟拍+滑包动作推向极高（动作密度最大）；S4-3 以 POV 切换带来紧张感（观众知道秘密但追赶者不知）；S4-4 强度降至中——静止的等待和声音悬念。
色彩策略：橙色钠灯（约 2200K）与混凝土冷灰（约 5000K 灰色调）形成互补对比。雨水将光源拉长——湿地面反射使橙色在暗处延伸。垂直方向上的亮度梯度——地面层（下方）更亮（更多灯光），越高层越暗（灯光间距增大）。文件袋的牛皮纸/防水袋颜色在橙光下偏暖棕——与水泥地形成视觉区分。
光比策略：高反差（1:16+），钠灯点光源形成硬影。雨水反射将阴影区略微提升（约 1-2 stop），但不能消除高反差。人物在移动中穿越亮区和暗区——曝光从亮到暗的跳跃是追逃视觉语言的一部分。
稳定性策略：手持为主——S4-1 轻微晃动（呼吸感），S4-2 更明显的手持跟拍（奔跑节奏），S4-3 手持 POV（主观晃动），S4-4 固定/稳定（终点静止）。稳定性曲线从动荡到静止——与阿泽的旅程对应。
节奏曲线：6s-8s-5s-7s。第一镜短而暴——建立追逃。第二镜最长——动作核心（滑包）。第三镜最短——追赶者 POV，紧张但信息密度低（他们不知道）。末镜中长——静止与声音悬念收束。总时长紧凑——追逃不拖沓。
```

### 1.4 镜头拆分理由

```text
四镜结构对应追逃的四段空间移动：(1) 建立——从追赶者视角看阿泽逃上坡道。(2) 关键行动——跟拍阿泽滑包，物件转移是整场核心。(3) 错过——POV 让追赶者"通过"而不"发现"，维持悬念。(4) 收束——阿泽的静止和声音的悬念。不拆分更多镜头因为追逃需要空间的连续性——每个镜头覆盖一段不可切割的空间移动。S4-3 使用 second_nodes 时间控制——追赶者经过货车的关键 5 秒需要精确到每秒的时机描述（跑过→错过→不停留）。
```

### 1.5 全场转场策略

```text
入场方式：S4-1 开场低角度仰拍坡道——阿泽从上方入画或已经在画面中奔跑。观众被立即置于追赶者的空间位置——仰视阿泽。"追"是进入本场的第一情绪。
出场方式：S4-4 末镜——阿泽在顶层边缘静止，雨水打在他身上，下方传来货车发动声。画面在声音中停留——留给观众"然后呢？"的悬念——切出至黑场。
场间关系：本场是四场中的最后一场，无后续叙事连接。作为收束场，它以"动作+物件隐藏"完成物件母题的第四变奏（文件袋的隐藏 vs 前场的交换/转移/对峙）。雨中停车楼的垂直空间和开放结局为此系列给出一个高能量的休止符。
```

### 1.6 双视图共享上下文

```text
场景蓝图：[D] 多层停车楼，雨夜。混凝土裸露结构——梁柱、坡道、防滑纹地板。橙色钠灯从天花板悬挂——间隔约 10-15 米，形成亮区和暗区交替。雨水从坡道边缘流下，湿地面反射灯光——橙色光在暗处拉伸为长条。阿泽（25 岁上下，深色快递制服或工装，运动鞋，怀中抱着一包用防水袋或塑料袋包裹的 A4 尺寸文件袋）沿坡道向上跑。两名追赶者（衣着不特定——深色便装）从下一层冲上来。空间中还有一辆停着的货车——在转角平台附近，车身底部离地约 30-40cm。空间的垂直性定义了追逃——上（阿泽）、横（文件袋滑入车底）、下（追赶者）。雨水是持续的视觉元素——它连接所有镜头。
声音基调：[D] 持续雨声——在混凝土结构中的独特混响（坚硬表面产生较高频的雨滴撞击声，结构回声使声音立体）。脚步声在湿混凝土上的回声——阿泽的奔跑声和追赶者的脚步声形成两层声音（更近的 vs 较远的）。追赶者偶尔的喊叫——内容不清晰，只有声音的方向感和紧迫感。货车发动机的启动声（低频轰鸣，约 60-120Hz）从画面外下方传来——这是场景最后的声音事件。全片无对白——追逃是纯粹的声音与视觉。
```
