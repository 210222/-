# TRANSFER REVIEW — D4 Knowledge Transfer Across Scenes

## D4: 同一知识在不同场景中的迁移，而不是套用同一方案

**Requirement**: The Director must transfer cinematic knowledge across different dramatic situations, applying principles contextually rather than mechanically repeating the same template.

## Three Dialogue Scenes: Transfer Comparison

The episode contains three dialogue-driven indoor scenes (S1, S2, S3) plus one action-driven exterior scene (S4). The first three share the structural pattern of "two characters across a table, one object transferred" — yet the Director's design varies fundamentally for each.

### Scene 1 — Interrogation (conversation_power + investigation_object + suspense_reveal)

**Knowledge applied**: Power-reversal dialogue via object placement.
**Specific choices**:
- Three fixed cameras at seated eye height — no movement. Power shifts through object positions, not camera movement.
- Single cold fluorescent (4700K), high ratio (1:8). No light change — dramatic change is purely through object placement and body posture.
- Profile: conversation_power for the establishing exchange, investigation_object for the badge retrieval close-up, suspense_reveal for the resolution.
- Timing: event_nodes. No second-by-second action; pauses carry dramatic weight.
- Space: Minimal — 3m×4m room, one table, two chairs, one door. Every element serves the power dynamic.

### Scene 2 — Kitchen Grief (conversation_power + investigation_object + contemplative_silence)

**Knowledge applied**: Grief and silence through indirect address — different from interrogation's direct confrontation.
**Specific choices**:
- Wide two-shot (38mm) to medium close-up (60mm) to medium two-shot — different lens progression from S1.
- Mixed light sources (5500K window + 2800K stove fire) with dynamic ratio change when stove turns off — unlike S1's static single source. The light change mirrors the emotional shift.
- Profile: contemplative_silence for the final shot — no equivalent in S1. Silence and steam resolve the scene instead of a power stare-down.
- Space: Kitchen with depth — foreground counter, mid table, background stove/window. Three depth planes vs S1's single-plane desk.
- Timing: event_nodes for dialogue shots, but the kettle whistle creates an organic temporal marker absent in S1.

### Scene 3 — Train Negotiation (conversation_power + investigation_object + suspense_reveal)

**Knowledge applied**: Negotiation under time pressure — the tunnel as dramatic clock.
**Specific choices**:
- Dual-source lighting (3000K wall lamp + 5500K passing window stripes) with tunnel transition arc (darken→total dark→return). Neither S1's static single source nor S2's two-anchored mixed source — S3 adds temporal light dynamics.
- 58mm close-up for the storage card (3×2cm) — the smallest object in the episode requires the tightest framing. The Director explicitly mitigates small-object visibility through lens choice.
- Profile: Same expression labels as S1 (conversation_power, investigation_object, suspense_reveal) but applied to a negotiation rather than an interrogation. The tunnel clock, dual-source light, and hand-proximity framing create a fundamentally different tension.
- Space: 2m×2.5m train compartment — tighter than S1's interrogation room. The window behind characters creates a depth constraint S1 and S2 don't have. The Director chooses front-only camera positions.
- Timing: event_nodes. The tunnel entry/exit provides organic temporal structure — different from S1's pause-based rhythm and S2's kettle-based structure.

### Cross-Scene Transfer Pattern

| Dimension | S1 (Interrogation) | S2 (Kitchen) | S3 (Train) |
|-----------|-------------------|-------------|-----------|
| Light | Single cold static (4700K) | Mixed warm/cool with ratio shift | Dual-source with temporal arc |
| Lens range | 60mm fixed | 38mm-60mm progression | 58mm close-up mitigation |
| Depth planes | 1 (desk plane) | 3 (counter/table/stove) | 2 (table/window constraint) |
| Rhythm driver | Dialogue pauses | Kettle whistle | Tunnel clock |
| Final shot profile | suspense_reveal | contemplative_silence | suspense_reveal |
| Object size | Badge (medium, metallic) | Key (small, metallic) | Storage card (tiny, plastic) |
| Camera movement | None (all fixed) | Micro-push on S2-2 then fixed | None (all fixed) |

### Scene 4 — Chase (action_chase × 3 + contemplative_silence)

**Knowledge applied**: Action choreography transferred from the dialogue scenes' spatial precision.

The Director applies the same spatial rigor from interior dialogue scenes to exterior action: A-Ze's path (up ramp → over ditch → crouch → slide → continue → roof) is as precisely mapped as the desk-to-desk power exchanges in S1-S3. The four camera positions (28mm tracking, 24mm low-angle, 50mm fixed, 40mm behind) are as deliberately chosen as the dialogue scene cameras. The timing mode shifts to second_nodes and half_second_nodes only where the action density requires it — not mechanically applied to all action.

## Conclusion

The Director does NOT apply a single template. Each scene's light design, lens selection, timing structure, spatial treatment, and profile choice responds to its specific dramatic problem. The shared knowledge — object-as-power-locus, hand-as-decision-organ, spatial precision, light as dramatic marker — transfers as principles, not as repeated solutions. The DP confirmed this: each READY evidence line cites specific, observable scene-specific evidence rather than generic compliance.
