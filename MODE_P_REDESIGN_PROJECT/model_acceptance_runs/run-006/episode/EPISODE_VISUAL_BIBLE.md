## 1. 全片戏剧与信息释放弧线

本集由四场独立戏剧组成，跨越四个不同的空间、时间和人物。共通命题是：**权力通过物理物体的转移而被重新分配**。每一场戏中，一个关键道具——警徽、钥匙、存储卡、文件袋——从一方交付、交出或隐匿至另一方，改变场景内的人物关系。

四场独立场景形成本集的情绪节拍：冷对峙 → 沉默哀伤 → 紧张交易 → 释放。

- **场景 1 (审讯室)**：以林警探的审讯权力开场，许然被动。信息释放顺序：先让观众看到林警探施压（推照片）→ 许然不回应照片，出其不意地放置警徽 → 观众与林警探同时发现警徽的意义 → 林警探收回手，权力彻底逆转。观众在此场与林警探同步获得信息，同样震惊。

- **场景 2 (老旧厨房)**：开场即揭示冲突——信已拆开，周岚已知母亲存活。信息释放顺序：观众先看到对峙站位和信 → 周岚发出指控 → 周成以沉默和水壶蒸汽回避 → 水壶鸣叫打破僵局 → 周成交出钥匙但不解释 → 周岚取钥匙而留信。观众知道的与周岚相同：钥匙指向未知地点，信里没有地址。

- **场景 3 (夜行列车)**：开场建立交易处境——顾言要存储卡，米娅握有它。信息释放顺序：顾言下令 → 米娅展示卡片但不交出 → 隧道降临使窗外光消失，对峙陷入黑暗僵局 → 米娅提出条件 → 隧道驶出，光线恢复，顾言扣下工作证 → 米娅交出存储卡。观众目睹双方的交易代价。

- **场景 4 (多层停车楼)**：开场即追逐——阿泽抱着文件袋向上跑，追赶者从下方冲来。信息释放顺序：观众看见阿泽怀中的文件袋 → 阿泽在转角处将文件袋滑入车底 → 观众知道文件袋的位置，追赶者不知道 → 追赶者越过货车追赶阿泽 → 阿泽在顶层停下，货车发动声从下方传来。观众比追赶者多知道文件袋的下落，悬念来自文件袋是否能被取走。

## 2. 人物视觉关系

本集四个场景人物互不相关，无需跨场统一人物外观。每场在自身空间内保持人物服装、年龄和体态一致即可。

| 场景 | 角色 | 年龄 | 服装要点 | 体态/特征 | 场景内关系线 |
|------|------|------|----------|-----------|-------------|
| 1 | 林警探 | 35-40 男 | 衬衫或便装，深色系 | 短发，审讯坐姿前倾 | 画右，面朝画左许然，180度线沿桌面长轴 |
| 1 | 许然 | 30-35 男 | 外套（有内袋），便装 | 初始后靠，转身后身体打开 | 画左，面朝画右林警探 |
| 2 | 周岚 | 22-28 女 | 日常便装，浅色或中色 | 站立，面对父亲，身体微倾 | 画右站立（水槽旁），俯视画左的父亲 |
| 2 | 周成 | 55-65 男 | 旧汗衫或棉质居家服 | 坐姿，背微驼，沉默 | 画左坐（餐桌前），面朝画后炉灶，回避对视 |
| 3 | 顾言 | 30-38 男 | 外套或便装，偏深色 | 坐姿笔挺，命令姿态 | 画左，面朝画右米娅，180度线沿桌面 |
| 3 | 米娅 | 25-32 女 | 便装或轻便外套 | 坐姿防卫性，手握卡片 | 画右，面朝画左顾言 |
| 4 | 阿泽 | 20-28 男 | 快递员制服，亮色 | 敏捷奔跑，呼吸急促 | 画深上方，向前跑，运动线从画前下方向画深上 |
| 4 | 追赶者 | 25-35 男 | 深色便装 | 速度快，体格较壮 | 画前下方，向上追 |

场景 1-3 均以桌面为权力交换平台，人物隔桌相对。桌面承载双方之间的距离、犹豫和最终决定。场景 4 以坡道为动作轴线，垂直高差和水平距离共同构成空间张力。

## 3. 色彩、光比与稳定性变化

### 场景 1: 审讯室
- **光色**：冷白色荧光灯，色温约 4500-5000K，高光比（顶灯单一光源，暗部深）。无暖色补充。
- **色彩基调**：灰、绿灰、金属冷色。许然外套可为深藏蓝，唯一的中性暖色是肤色。
- **稳定性**：全场固定机位为主，不运动的压迫感。荧光灯恒定不变——权力反转来自演员动作而非光线变化。

### 场景 2: 老旧厨房
- **光色**：混合光源。窗外清晨冷光（约 5500-6000K）从右方射入。炉火暖光（约 2700-3000K）在背景。水壶关火后暖光减弱或消失，场景渐偏冷调。
- **色彩基调**：米黄、奶白瓷砖、旧木色、蒸汽白。周岚的浅色衣物与周成的旧色形成代际对比。
- **稳定性**：开场固定建立空间。水壶鸣叫段可微推近。钥匙推出时固定。蒸汽的升腾与消散是唯一持续的运动元素。

### 场景 3: 夜行列车
- **光色**：双层光源。包厢内暖壁灯（约 2800-3200K）。窗外冷色城市灯光（约 5000-6000K，运动掠过）。隧道内仅壁灯，暗调。隧道前后光色对比形成视觉节拍。
- **色彩基调**：暖木色内饰、暗绿或暗蓝座椅、窗外运动冷光条纹。隧道段暗调，恢复段光返回。
- **稳定性**：列车恒动微晃由场景自身产生。摄影以固定为主，窗外光线变化承担运动的替代。隧道过渡期间光线的大幅变化是场景的核心视觉节拍。

### 场景 4: 多层停车楼
- **光色**：停车楼荧光灯（约 4000-4500K），冷白泛绿。夜雨外光偏冷蓝。无暖光。雨水在地面和墙面形成反光。
- **色彩基调**：灰色水泥、深色沥青坡道、黑色或深蓝色夜雨、荧光灯绿白。货车深色。阿泽的快递员制服若为亮色（橙/黄/荧光绿）则提供视觉追踪的便利。
- **稳定性**：追逐段手持或肩扛感的呼吸式运动，跟随阿泽。文件袋滑出段可用低角度固定。顶层停顿时恢复稳定，与追逐形成动静对比。

## 4. 关键空间拍摄逻辑

### 场景 1: 审讯室
小型封闭审讯室（约 3m x 4m）。中间金属长桌，桌面灰色或灰绿色。头顶日光灯管一只。墙壁裸露水泥或吸音板。无窗，金属门在林警探身后（画右后方）。桌面是权力交换的唯一平台。两个物体并置于中央时，视觉上建立新旧证据的对峙。拍摄：中焦建立空间压迫感 → 中近焦取两人上半身正反打 → 近焦或微距取桌面物体。物体移动路径在桌面上完全可见。

### 场景 2: 老旧厨房
简陋厨房（约 2.5m x 3m）。水槽在画右，窗在上方，清晨冷光从右射入。餐桌在画左靠墙。炉灶在画中后部，水壶在炉火上。墙壁瓷砖老旧，米黄或泛灰。拍摄：中焦建立厨房全貌 → 中近焦对水壶蒸汽、手推钥匙、周岚拿取钥匙。周成与水壶的关系——他利用蒸汽作为不直视女儿的借口——需要通过视线方向（周成看画后炉灶）来明确。

### 场景 3: 夜行列车包厢
列车软卧包厢或小型隔间（约 2m x 2.5m）。中间窄桌，两侧座位。宽窗在画后墙面，窗外城市夜景灯光掠过。包厢内暖壁灯。列车运行有轻微晃动。拍摄：中焦建立包厢空间和窗外 → 中近焦对准两人面部和手 → 存储卡特写需要微距或极近中焦。窗外光线的周期性变化（城市灯光→隧道黑暗→恢复）是场景的自然视觉节拍器。

### 场景 4: 多层停车楼
停车楼某层坡道区域。水泥地面湿滑，荧光灯管。雨水从开放侧飘入。坡道向上连接更高层，向下通往较低层。排水沟在坡道一侧。转角处停着深色箱式货车，底盘距地面约 30-40cm。楼顶边缘有护栏或矮墙。拍摄：较广焦段（24-35mm eq.）建立空间纵深和两层高差 → 长焦（70-100mm eq.）压缩追赶距离 → 低角度广角（文件袋滑入车底）。转角是物人分离的关键点，需要明确的空间定位让观众理解文件袋与货车的关系。

## 5. 视觉母题与使用边界

### 母题 1: 桌面作为权力舞台
场景 1、2、3 均以桌面为权力交换的物理平台。桌面材质随场景变化（金属审讯桌、老旧木餐桌、列车窄桌），但功能相同：物体从一方推到、放到或扣在桌面上。
**使用边界**：每场以建立桌面与两人关系的全景或中景开场。物体的移动路径在桌面上可见。物体落定后给予至少一秒的停留。场景 4 不使用此母题——权力转移通过隐匿而非桌面交换完成。

### 母题 2: 手作为决定器官
每一场的关键决定都由手完成：推照片、取警徽、推钥匙、夹存储卡、扣工作证、滑文件袋。
**使用边界**：关键物体转移时至少有一个镜头包含手部可见动作。手在物体上停留、离开或收回的时点清晰可读。不为每个物体转移都使用手部特写——只在信息变化最大的转移中使用。

### 母题 3: 物体落定后的停留
每一场物体到达最终位置后（两个物体并置在桌面、钥匙被拿起、存储卡在桌面中央、文件袋在车底），不给立即切离。停留让观众消化信息。
**使用边界**：停留长度与信息密度成正比——警徽的出现需要最长停留（观众与林警探同时处理信息），文件袋滑入车底需要最短停留（动作节奏要求快速切换至追赶者反应）。

### 母题 4: 光的变化伴随权力转移
- 场景 1：荧光灯恒定——权力反转完全由演员动作承担。
- 场景 2：水壶关火后暖光减弱——从对峙到交出钥匙的过渡。
- 场景 3：隧道黑暗→光线恢复——僵局到妥协的视觉标记。
- 场景 4：荧光灯恒定——动作追逐中光不变，雨水补充环境层次。
**使用边界**：不强制每场必须变化光线。光线变化只在剧本中存在物理原因（关火、进出隧道）时才使用，不凭空添加。
