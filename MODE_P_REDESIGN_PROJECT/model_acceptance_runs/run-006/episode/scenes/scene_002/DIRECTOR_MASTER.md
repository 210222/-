## 1. 场景设计

```text
场景前状态：硬切自场景 1，无连续性继承。周岚立于水槽旁（画右），周成坐于小餐桌前（画左）。已拆开的信在餐桌上。水壶在画后炉灶上加热中，蒸汽初起。清晨冷光从水槽上方窗户射入。
戏剧变化：周岚以指责开场——父亲早就知道母亲还活着。周成不辩解、不直视，用沉默和水壶蒸汽回避。水壶鸣叫打破僵局，周成关火后将一把储物柜钥匙推向周岚，并以一句话将寻找母亲的责任从自己移至女儿手中。周岚拿起钥匙但不带走信——接受了寻找的工具，却拒绝带走父亲隐瞒的证据。
信息策略：观众与周岚同步知道母亲活着的消息（信已拆开）。周成的沉默和水壶蒸汽为观众创造了等待——他在想什么？他会说什么？蒸汽成为视觉悬念。水壶鸣叫是听觉转折点。钥匙的意义由周成的对白揭示。周岚取钥匙、留信的瞬间是她的选择——观众与她同时完成这个判断。
场景后状态：周岚手握钥匙立于水槽旁，信留在桌上。周成坐于餐桌前，手收回。水壶火已关，蒸汽渐散，暖光减弱，场景色调向冷偏移。钥匙的转移已完成，但人际关系并未修复。

场景空间：老旧厨房，约 2.5m x 3m。水槽靠画右墙，窗户在水槽上方。小餐桌靠画左墙（约 1.2m 长）。炉灶在画中后部靠墙，水壶在炉火上。地面为旧瓷砖，墙壁为泛黄的白色瓷砖。整体为暖米色调。
关系线：周岚站立（画右）高于坐着的周成（画左），存在垂直权力差。周成面朝画后炉灶方向（回避女儿视线），周岚面朝画左父亲方向。180 度线从画左餐桌斜向画右水槽。
人物路径：周岚——全场景保持站立于水槽旁，身体微转向餐桌方向，不移动位置。仅在最后伸手取钥匙时上身前倾约 20cm，完成后恢复站姿。周成——全场景保持坐姿于餐桌前，身体朝向后方的水壶（回避姿态），关火时起身倾向炉灶约 15cm，推钥匙时上身转向画右前方。
摄影可用区域：画前方（摄影师一侧）沿厨房宽度约 2m 可架设机位。画右窗前区域不可用（强逆光）。画左靠墙仅容窄角机位。主拍摄方向：正前（厨房全景）、偏左（对周岚）、偏右（对周成和炉灶）。

视觉策略：固定机位开场建立空间，中段有极慢微推近周成面部（跟随蒸汽节奏），尾段回到固定。清晨冷光（5500K）与炉火暖光（2700K）混合，水壶关火后暖光减弱——色温变化标记权力转移。中焦（35-50mm）建立空间，中近焦（50-70mm）取周成面部与蒸汽。蒸汽是可见的沉默——上升、聚集、被关火驱散。
镜头拆分理由：三镜头对应三阶段。Shot 1 建立厨房全貌并完成周岚的指控，以周岚说完对白、等待父亲回应为切点。Shot 2 聚焦周成——蒸汽回避、水壶鸣叫、关火、推钥匙、说对白——这是全场最密集的表演段落，需要一个镜头内的节奏推进。Shot 3 拉回双人中景完成周岚的选择——取钥匙、留信，以钥匙在周岚手中的画面结束。
场间关系：硬切自场景 1（冷灰审讯室→暖米厨房的色调跳切）。出口为周岚手握钥匙的构图，给足停留后硬切至黑场。

场景蓝图：[D] 老旧厨房清晨。右窗冷光 + 后部炉火暖光混合。周岚（画右站立，浅色便装）面朝画左父亲质问。周成（画左坐姿，旧棉质居家服）面朝画后水壶看蒸汽。水壶蒸汽升腾。桌上摊开一封信。水壶鸣叫后周成关火，将一把小钥匙从桌面推向画右。周岚伸手拿起钥匙。信留在桌上未被带走。蒸汽渐散，暖光减弱。
声音基调：[D] 清晨室外微弱的远处声（鸟鸣的若隐若现）。水壶加热的渐强高频鸣叫——从隐约到刺耳到被关火掐断。钥匙在木桌上滑动的清脆短促声。对白在安静中的清晰声。关火后的安静带有残响。无背景音乐。
```
