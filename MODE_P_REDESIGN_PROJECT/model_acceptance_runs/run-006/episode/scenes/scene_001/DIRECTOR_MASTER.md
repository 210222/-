## 1. 场景设计

```text
场景前状态：黑场开场，无继承状态。林警探与许然已隔桌对坐。停车场照片在林警探手中。警徽在许然外套内袋，观众不可见。
戏剧变化：审讯权力从林警探转移至许然。表面上是许然出示警徽反击，实质是许然用一件物理证据揭露林警探自身的涉案嫌疑，彻底反转双方关系。
信息策略：观众初始与林警探共享视点——林警探掌握主动权，照片是施压工具。当许然取出警徽时，观众与林警探同步获得这个新信息，同步震惊。警徽出现后的停留让观众消化其含义：它不是许然的身份证明，而是林警探昨晚遗落在许然车内的物证。
场景后状态：林警探手已收回，视线锁定警徽，问询权瓦解。两件物体（照片与警徽）并置于桌面中央，形成新旧证据的对峙。许然保持静止，已取得控制权。

场景空间：小型封闭审讯室，约 3m x 4m。金属长桌居中，桌面灰绿色。头顶单只荧光灯管，冷白光。墙壁为裸露水泥。无窗。一扇金属门在林警探身后（画右后方）。桌面是权力交换的唯一平台。
关系线：180 度线沿桌面长轴。林警探在画右（靠门一侧），面朝画左。许然在画左（靠墙一侧），面朝画右。两人视线相对。
人物路径：林警探——前倾坐姿，右手将照片从面前推至桌面中央，后被警徽的出现逼退（身体微后倾，手收回）。许然——初始后靠坐姿，身体前倾仅发生在取警徽和放置警徽的短暂动作中，完成后恢复后靠。
摄影可用区域：画前方（摄影师一侧）沿桌面长轴有约 1.5m 范围可架设机位。无法从两人身后拍摄（林警探身后是门与墙，许然身后是墙）。可用正前（对准两人正面）、偏左（对准林警探）、偏右（对准许然）三个主方向。

视觉策略：全场以固定机位为主，不运动。冷白荧光灯高光比造成深暗部。中焦（35-50mm eq.）建立空间压迫感，中近焦（50-70mm eq.）捕捉面部反应与手部动作。色彩为灰、绿灰、金属冷色，仅肤色提供暖色。摄影的静止与权力的剧烈转移形成反差——画面不动，但关系已颠覆。
镜头拆分理由：三个镜头覆盖三阶段戏剧动作。Shot 1 建立空间并完成林警探的施压（推照片+对白），以照片在桌面中央落定、林警探等待回答为切点。Shot 2 切换至许然一侧，不被照片吸引，进行警徽的取出与放置，以警徽落定、许然说完对白为切点。Shot 3 拉回双人，以两个物体在桌面形成的对峙构图为核心，捕捉林警探收回手——权力彻底转移完成的瞬间。
场间关系：黑场淡入开场。出口为林警探手收回并静止、两物体并置桌面的构图，给足停留后切至黑场。

场景蓝图：[D] 冷灰审讯室，单人头顶荧光灯，金属长桌。林警探（画右，短发，深色衬衫）与许然（画左，外套有内袋）隔桌相对。照片从右推到中。警徽从左取出放到照片旁。两件物体在桌面中央并置。林警探的手从照片上方犹豫收回。冷色、暗部深、固定机位、极简调度、表演克制。
声音基调：[D] 低沉室内静默。荧光灯微弱持续嗡鸣。物体触碰金属桌面的短促干涩声（照片滑推、警徽轻放）。对白的回音极小（吸音板墙体）。无背景音乐。警徽落桌后短暂静默承载权力转移。
```
