# S1 — Video Prompt

## Scene Blueprint

冷灰审讯室，单人头顶荧光灯，金属长桌。林警探（画右，短发，深色衬衫）与许然（画左，外套有内袋）隔桌相对。照片从右推到中。警徽从左取出放到照片旁。两件物体在桌面中央并置。林警探的手从照片上方犹豫收回。冷色、暗部深、固定机位、极简调度、表演克制。
Sound Baseline: 低沉室内静默。荧光灯微弱持续嗡鸣。物体触碰金属桌面的短促干涩声（照片滑推、警徽轻放）。对白的回音极小（吸音板墙体）。无背景音乐。警徽落桌后短暂静默承载权力转移。
