## 1. 场景设计

```text
场景前状态：硬切自场景 2，无连续性继承。顾言与米娅已隔窄桌对坐于列车包厢。包厢内暖壁灯亮。窗外城市夜景灯光快速掠过。存储卡在米娅手中——初始状态未完全展示。列车即将进入隧道。
戏剧变化：双方从对峙到交易。顾言以命令姿态要求存储卡并要求米娅下车。米娅不直接拒绝，而是以存储卡为筹码提出反向条件——删除证人名单中的名字。僵局在隧道黑暗中持续。列车驶出隧道时光线恢复，顾言以翻转工作证表示妥协，米娅随即将存储卡交出。权力从单向命令变成了双向交易。
信息策略：观众初始与米娅共享信息——知道她握有存储卡这个筹码。当顾言命令时，观众等待米娅的反应。隧道黑暗将双方锁入同一空间压迫——窗外世界的消失使包厢变成孤立战场。光线的恢复与顾言的妥协同步——视觉释放与叙事释放合一。存储卡最终在桌面中央，工作证扣在顾言一侧——两个物体都在桌上，各自付出了代价。
场景后状态：存储卡在桌面中央。工作证翻转扣于顾言一侧桌面。两人静止。窗外灯光恢复掠过。隧道已过。交易完成——存储卡已不在米娅手中，工作证已不在顾言身上。

场景空间：列车软卧包厢，约 2m x 2.5m。窄桌居中，两侧各一排座位。宽窗在画后墙面上占据横向约 1.5m。窗外为掠过的城市夜景（灯光条纹）。包厢内一盏暖壁灯在画左上方。列车运行有持续低频晃动。
关系线：180 度线沿窄桌长轴。顾言在画左座位，面朝画右。米娅在画右座位，面朝画左。两人正对——视线在桌面中线相遇。
人物路径：顾言——初始坐姿笔挺，命令姿态。隧道驶出后右手从口袋取工作证，翻面扣在桌面（动作约 2s），完成后手收回。米娅——初始存储卡夹在右手两指间，展示但不推出。隧道驶出后右手将存储卡放在桌面中央（动作约 1.5s），完成后手收回身前。
摄影可用区域：画前方沿窄桌短轴约 1m 可架设机位。无法从两人身后拍摄（身后均为包厢壁板）。可用正前（对两人正面）、偏左（对米娅）、偏右（对顾言）三个方向。画后窗外不可用（逆光且窗外运动元素干扰）。

视觉策略：固定机位为主，列车自身晃动提供底层运动。窗外光线变化是场景的视觉节拍器——城市灯光条纹→隧道全暗→恢复灯光。中焦（35-50mm eq.）建立包厢空间。中近焦（50-70mm eq.）取两人面部。隧道段暗调——仅壁灯照明，面部为暖光单光源。隧道前后——窗外冷光掠过为人物面部添加运动冷光条纹。整体色调：暖木色+窗外冷光运动条纹。
镜头拆分理由：三镜头对应隧道前、隧道中、隧道后。Shot 1 建立包厢并完成顾言命令——隧道正在进入，窗外光即将消失，增加视觉紧迫感。Shot 2 聚焦米娅的反击——在隧道黑暗中，仅壁灯照亮她的面部和两指间的存储卡，她提出条件。Shot 3 以光线恢复为信号——窗外光返回，顾言妥协（翻证），米娅交出（放卡），交易在光线中完成。
场间关系：硬切自场景 2（清晨厨房→夜间列车的空间与时间跳跃）。出口为存储卡在桌面中央和工作证扣在桌上的构图，给足停留后硬切至黑场。

场景蓝图：[D] 夜行列车包厢。暖壁灯照明。宽窗外城市灯光条纹快速掠过。顾言（男，画左，深色外套，约 35 岁）与米娅（女，画右，便装，约 28 岁）隔窄桌相对。窗外光消失（隧道），包厢仅壁灯暖光。米娅两指间夹着一枚小存储卡展示但不交出。窗外光恢复（隧道结束）。顾言将工作证从身前翻面扣在桌面。米娅将存储卡放在桌面中央。
声音基调：[D] 列车运行的持续低频隆隆声（约 50-60Hz 基频）+ 车轮与轨道接触的规律节奏（约每秒 2-3 次）。隧道内回声加强——隆隆声更大、更密、包厢内反射增加。隧道外恢复常规运行声。对白在列车噪声上稍提高音量。存储卡落桌和工作证扣桌的短促轻碰声。无背景音乐。
```
