## 1. 场景层设计

### 1.1 戏剧变化与信息策略

```text
场景前状态：（无）—— 场景 4 为独立叙事片段，无前场继承。阿泽已被追赶——追赶从何时何地开始不可知。他正抱着一个文件袋沿停车楼坡道向上跑。
戏剧变化：阿泽从被动逃跑变为主动设计——他在转角处将文件袋滑入一辆静止货车的底部，使追赶者被自己的视线所骗（他们只看见阿泽的背影，错过了藏文件袋的动作）。他继续向顶层跑以引开追赶者。到达顶层后，货车发动声从下方传来——文件袋已被接应者取走。阿泽的逃跑从"保住文件袋"转变为"引开追赶者直到文件袋被运走"。
信息策略：观众初始跟随阿泽的视角——知道追赶者在身后，知道文件袋很重要。在转角处，观众看见阿泽将文件袋滑入货车底部——但追赶者没有看见。此时观众比追赶者多知一个关键信息（文件袋在货车下）。追赶者越过货车追上去时，观众理解他们追错了方向。场景结束时，货车发动声从下方传来——观众和阿泽同时获知这一信息，但不清楚接应者是谁。
场景后状态：阿泽站在顶层边缘，文件袋已不在手中。追赶者仍在向上追（可能即将到达顶层）。货车发动声暗示文件袋正在离开停车场。阿泽的处境（是否能脱身）和文件袋的去向均悬置。
```

### 1.2 空间调度

```text
场景空间：多层混凝土停车楼，开放式侧面可看见雨。坡道连接上下层（宽约 3-4m，坡度约 8-10 度）。每层有混凝土方柱、荧光灯管（冷白 4000K）和钠灯（暖黄 2200K）混合照明。角落有排水沟（宽约 30-40cm，浅）。一辆货车停在转角处——可能是小型厢式货车或皮卡。顶层有半高混凝土护栏或金属栏杆。[空间布局为 inferred]
关系线：无对话关系线。追逐的银幕方向为 up_ramp——阿泽向上跑，追赶者从下方向上追。转角的货车是空间的转折点——阿泽在此改变视线策略。
人物路径：
  - 阿泽：坡道（向上跑）→排水沟（跨过）→转角货车处（蹲或弯身滑入文件袋）→继续向上坡道→顶层边缘（停下）
```

### 1.3 视觉策略

```text
视觉强度：高（全场）。唯一的动作场景——持续性运动、雨、夜、追逐。强度曲线：高（开场逃跑）→ 极高（跨沟+藏袋+骗过追赶者）→ 骤然降低（顶层静止）。
色彩策略：冷色基底（混凝土灰 + 荧光冷白 4000K）+ 暖色污染（钠灯黄 2200K 在停车楼部分区域）。雨水在混凝土上形成反光面，将所有光源的颜色混合反射。整体色调偏冷但不单色——钠灯的暖黄区形成视觉变化。
光比策略：中高光比 1:5-1:6。荧光灯为硬光源——在混凝土柱后形成锐利阴影。雨水的漫反射在地面产生柔化效果——地面比垂直面略亮、影子边缘略柔。

节奏曲线：Shot 1 加速（~7s）→ Shot 2 高速+关键动作（~10s）→ Shot 3 骤停（~6s）。节奏由阿泽的运动状态驱动——摄影机跟随他的节奏。
```

```text

Shot 3（顶层静止）：从全速运动突然切至静止——阿泽在顶层边缘停下，呼吸，听见下方的货车发动声。此镜的运动停止本身就是戏剧事件。广角或中景展示停车楼顶层和下方的城市/雨夜景。
```
