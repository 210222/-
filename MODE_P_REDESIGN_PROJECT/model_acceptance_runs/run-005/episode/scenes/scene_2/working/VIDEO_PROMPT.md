## Scene Blueprint

一间老旧但干净的小厨房，清晨的光线透过窗户散射进来，暖黄而柔和。水壶在炉灶上加热，白色蒸汽缓缓上升。周岚站在水槽旁，身体朝向父亲但不完全正对——既是质问者又是一个保持距离的女儿。周成坐在小餐桌前，面前是一封已拆开的信。他看着蒸汽而不是女儿。这个空间的紧张是安静的——水壶的加热声是唯一的倒计时。
Sound Baseline: 持续的环境声：水壶加热的渐强嗡声（从低沉到尖锐），窗外远处偶尔的鸟鸣或街道的低频噪声。小厨房硬表面（瓷砖、金属水槽）造成短混响。对话稀疏——更多是沉默和蒸汽的声音。水壶鸣叫是全场的音量和戏剧高点。
