## Scene Blueprint

一间封闭的小审讯室，荧光顶灯是唯一光源。金属桌居中，桌子两侧各坐一人。画面冷调，肤色微灰。桌面上有两件物品代表两个未解答的问题：一张模糊的停车场照片（林警探推过去的），一枚警徽（许然刚从外套内袋取出的）。权力已经从推照片的人转移到了放警徽的人手中。摄影机是安静的观察者，固定在三脚架上，不替任何人站队。
Sound Baseline: 持续的低频空调嗡声，远处走廊偶尔传来沉闷的脚步声。室内声学干而近——硬表面无吸音。对话清晰，不叠加音乐。安静中能听见衣服的摩擦声和警徽放置在金属桌面上的轻响。
