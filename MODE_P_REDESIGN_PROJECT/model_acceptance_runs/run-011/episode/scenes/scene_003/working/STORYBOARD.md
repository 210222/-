## Scene Blueprint

夜行列车包厢内，暖色顶灯照着贴窗窄桌，窗外城市灯光成流动光点自右向左掠过；顾言（男约三十八岁，中等身材，深色头发梳理整齐，深灰大衣未脱，白衬衫扣至领口）坐画面左；米娅（女约二十七岁，深棕色齐颚短发，军绿连帽外套拉链拉至领口，神情戒备）坐画面右；列车入隧道时窗外光消失、包厢只剩暖灯；本场以黑暗中的索要开始，以复明后的桌心交换结束。
