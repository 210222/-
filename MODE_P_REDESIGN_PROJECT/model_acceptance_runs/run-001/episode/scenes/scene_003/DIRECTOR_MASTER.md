## 1. 场景层设计

### 1.1 戏剧变化与信息策略

```text
场景前状态：无前场继承。全新场景。观众不知人物关系和前史。
戏剧变化：从顾言主动要求交卡（单方要求）变为双方互提条件（存储卡换除名）再变为交易达成（谨慎的相互信任）。
信息策略：观众全知——存储卡在米娅手中、顾言要卡、米娅提条件、两者交换。隧道黑暗期隐藏了双方的表情细节，
          但公开的对白和动作足以让观众理解交易内容。出隧道后的光明确认交易完成。
场景后状态：存储卡在桌面中央，工作证翻面扣着。交易完成，但双方保持了距离。
```

### 1.2 空间调度

```text
场景空间：【inferred】列车包厢约 1.5m x 2m。两张椅子面对面，中间一道约 40cm 宽的固定窄桌。
         左侧是车窗（窗外有城市夜景/隧道黑暗交替）。包厢门在右后侧。
关系线：两人隔窄桌面对面，距离极近（约 60cm）。桌面极小，物品的放置几乎是手边的延伸。
         极度近距离使双方没有退让空间——任何动作都在对方的直接视野内。
人物路径：两人均在座，无入场/出场。身体运动限于上半身、手和视线方向。
摄影可用区域：包厢空间极小，机位只能在走廊侧过道外拍摄（隔着门/半透明玻璃），
             或从侧翼透过车窗反方向拍摄。最实用的机位是从走廊通过半开的包厢门拍摄。
             也可在两人侧上方（列车行李架高度）获得极端的俯角。
```

### 1.3 视觉策略

```text
视觉强度：中（开场车厢灯光对话）→ 高（隧道黑暗，压缩空间）→ 中（出隧道，交易完成）。
色彩策略：主色调冷蓝黑（夜间车厢内），窗外暖色城市灯光（夜景时），完全的黑色（隧道时）。
          回归后暖色城市灯光重现，场景回到冷蓝+点状暖光。
光比策略：全景 3:1（车厢内顶灯+窗外城市光）。隧道内 5:1（仅有应急灯和窗外无光）。
          出隧道后回到 3:1。光比的变化由窗外灯光条件驱动，非人为改变。
稳定性策略：固定为主，但允许轻微的列车行进震动（自然的上下微震，非手持晃动）。
节奏曲线：6s → 8s → 5s。隧道段最长（全镜几乎都在黑暗中进行谈判），节奏最慢。
```

### 1.4 镜头拆分理由

```text
三镜拆分：建立空间与初始要求（双人镜，包含进入隧道的光变化）→ 黑暗中的谈判（单人近景交替）→ 出隧道后的交易完成（双人回归）。
不需要更多镜：信息变化集中在两个阶段（入隧道的紧张 / 出隧道的完成），每镜覆盖一个阶段。
隧道黑暗段在同一镜中完成两个角色的条件交换——黑暗使视线切换失去意义，声画配合更重要。
```

### 1.5 全场转场策略

```text
入场方式：首镜从列车包厢的窄桌建立开始——窗外城市灯光移动，列车震动，两人面对面。
出场方式：末镜以存储卡放在桌面中央、窗外城市灯光恢复的画面结束——交易完成，视觉上"光明重现"。
场间关系：独立场景。前场（厨房晨光）硬切至夜间列车，从暖色调切换至冷色调。
```

### 1.6 双视图共享上下文

```text
场景蓝图：[D] 夜行列车包厢，夜间。窄桌两侧对坐。靠窗一侧有城市夜景——隧道将中断它。
          包厢内暖色顶灯。桌面极小，放置物品即进入对方领域。
声音基调：[D] 列车行驶的持续轮轨声。包厢的微封闭空间声学（稍微混响）。
          进入隧道后外部声音消失（变成隧道混响和回音），出隧道后恢复。
          对白在隧道内需要稍大的音量才能互相听清。
```

### 2.3 摄影与构图 `[D: 自然语言]`

摄影设计：[D] 单人近景交替——本镜从米娅的近景开始（MCU），在顾言取工作证时切到他（或采用同一镜头内聚焦切换）。由于包厢极小，建议使用 50mm 焦距拍摄单人近景，让两人各自占据画面，视线指向对方（形成视线互补）。镜头完全固定——黑暗中的微小运动会让画面显得不稳。
构图设计：[D] 米娅的画面以她的面部和夹卡的手为主——存储卡在光源下闪闪发亮，引导视线。顾言的画面以他取证件和翻面的手部动作为主——手在顶灯下穿越桌面。由于窗外全黑，车窗变成黑色镜面，偶尔反射包厢内镜像，但不干扰主体。
光影设计：[D] 隧道中只有包厢顶灯作为光源。光比大幅增加（约 4:1），阴影更深。存储卡在灯光下反光，形成画面中最亮的小点。顾言取工作证时，证件的白色边缘在灯光下清晰可读。翻面扣下后，只有证件的深色背面可见——这个视觉变化标志着他的让步（信息被隐藏）。
表演设计：[D] 米娅举卡的方式是关键——手指张开让卡清晰可见但不递出，这是一个"展示但不给予"的姿态。顾言取工作证前有一个评估性的停顿——他在衡量是否值得先让步。翻面扣下的动作决定了交易方向——他不是把证件推给米娅，而是扣在自己一侧，让对方看到但无法取走。
