## 1. 场景层设计

### 1.1 戏剧变化与信息策略

```text
场景前状态：无前场继承。全新场景。
戏剧变化：从被追（阿泽逃）→ 藏匿文件（被动防御）→ 触发计划（货车发动，暗示保护机制已激活）。
信息策略：观众全知——看见阿泽藏匿文件袋，看见追赶者未发现。货车发动声是阿泽和观众共知的信号，
          但观众不知道这意味着什么（安全？还是新的危险？）。
场景后状态：阿泽到顶层停下，货车发动——文件袋被保护或被取走？阿泽能否脱身？开放性悬念。
```

### 1.2 空间调度

```text
场景空间：【inferred】多层停车楼，雨夜。圆形坡道连接各层。每层有停车位和立柱。
          排水沟在坡道中段横向穿过。转角处停着一辆货车。
          顶层边缘开放，可看见下层和远处城市灯光。
关系线：追逐线——阿泽在前（向上），追赶者在后（从下往上），垂直方向的距离在不断变化。
人物路径：阿泽沿坡道向上跑——从下层入口到坡道中段（排水沟/货车处）再到顶层边缘。
          追赶者从下一层冲上来，沿相同路径追到货车处，然后越过货车继续向上。
摄影可用区域：坡道上下方、立柱后、货车旁、顶层边缘。可利用多层结构从上层俯拍下层。
```

### 1.3 视觉策略

```text
视觉强度：高（开场追逐）→ 高峰（藏匿时的悬念）→ 高（到达顶层后转为静默悬念）。
色彩策略：主色调冷灰蓝（雨夜+混凝土停车楼），霓虹白（停车楼灯光），雨水的反光。
光比策略：整体 3:1 — 停车楼灯光分区域，有些区域较亮，有些区域被立柱遮挡较暗。
          利用明暗交替制造追逐的节奏感。
稳定性策略：手持跟拍（追逐段），稳定固定（藏匿段），固定（顶层静默段）。
节奏曲线：6s → 7s → 6s。全片最短/最快节奏场景。中间镜藏匿段稍慢（悬念），末镜恢复为静的收束。
```

### 1.4 镜头拆分理由

```text
三镜拆分：建立追逐（宽景跟拍，展示坡道和追赶者）→ 藏匿动作（中景，排水沟/货车的动作链）→ 到达与悬念（宽景，顶层，货车声）。
中间镜覆盖从跨排水沟到滑文件袋再到继续奔跑的连续动作——这是一个完整的动作短语，不应拆分。
末镜从奔跑转入静默——阿泽停下、倾听、货车发动形成声音上的高潮。
```

### 1.5 全场转场策略

```text
入场方式：首镜直接进入追逐——阿泽在坡道上跑，追赶者从下方冲上。观众立即理解追逐关系。
出场方式：末镜阿泽停在顶层边缘，货车发动声从下方传来。画面固定在此——答案留给观众。
场间关系：独立场景。前场（列车包厢）硬切至雨夜停车楼。从封闭室内到开放外景，从静默谈判到身体追逐。
```

### 1.6 双视图共享上下文

```text
场景蓝图：[D] 多层停车楼，雨夜。水泥坡道螺旋上升。雨水从上层边缘流下。停车楼灯光（霓虹白）
          在潮湿地面形成反光。一辆货车停在转角阴影处。远处城市灯光模糊在雨中。
声音基调：[D] 持续的雨声（大小随位置变化——坡道下层雨声较小，上层更直接）。
          脚步声在混凝土坡道上回响——阿泽的运动鞋 vs 追赶者的硬底鞋（可区分）。
          偶尔车辆驶过的远处声音。货车的发动机启动声是末镜的关键声音事件。
```

### 2.3 摄影与构图 `[D: 自然语言]`

摄影设计：[D] 先跟拍（广角 24mm）阿泽跨越排水沟和接近货车。在藏匿文件袋时，机位切换到静止的低角度机位从货车后方拍摄——这个切换在本镜内完成（一个自然的机位调整）。藏匿后恢复跟拍阿泽继续奔跑。追赶者到达时，从货车后方固定机位拍摄他们经过——镜头不跟随，让货车和车底（隐藏文件袋的区域）成为画面主体。
构图设计：[D] 排水沟处：阿泽跨沟动作形成高度动态的构图——跨越的身体和下方的流水。货车处：蹲下/藏匿动作被货车车身遮挡一半——观众看到动作但看不到文件袋的具体位置，制造悬念。追赶者处：他们的腿部画面经过货车——脚步在车旁暂停然后继续，让观众紧张文件袋是否被发现。

表演设计：[D] 阿泽跨排水沟的动作干脆——他熟悉这个路线。藏匿时没有多余动作：蹲下、放入、站起、继续跑——每一步都经过练习。不回头看文件袋是专业的表现——让追赶者相信他仍在全力逃跑。追赶者只看见他的背影——这是剧本事实，他们的视线被上方的奔跑吸引，没有检查货车。
