## 1. 全片戏剧与信息释放弧线

- 权威与范围：剧本原文与 SCRIPT_FACTS.md 为叙事事实权威；独立分集无项目背景；ASSET_CARD_INDEX 无 verified 资产卡，全片 text_only。
- 标题事实：本集为"四种压力下的决定"（L1）。四场彼此独立，无共享人物、道具或空间；连接它们的不是情节，而是同一结构——决定从不通过宣言完成，而通过一件物体在共享表面上的位置改变完成。
- **各场决定链**：
  - 场景1：照片被推到桌中央施压（L5）→ 警徽放在照片旁反压（L9）→ 手收回，压力方向反转（L13）。
  - 场景2：信已在桌上（L17）→ 钥匙被推向周岚（L21-L22）→ 钥匙被拿走、信被留下（L26）。
  - 场景3：存储卡被两指夹持扣留（L34）→ 工作证翻面扣在桌上作抵押（L38）→ 存储卡放到桌面中央（L38）。
  - 场景4：文件袋被抱在怀中（L42）→ 滑进货车底部藏匿（L44）→ 货车发动，物体脱离所有人视线（L47）。
- **信息释放（观众与人物的信息关系）**：
  - 场景1：观众与林警探同步。警徽出现前观众不知道许然握有反制物；惊讶落在林警探身上，观众通过他的手撤回（L13）读出权力反转。
  - 场景2：观众与周岚同步。周成的沉默（L21）用蒸汽与水壶鸣叫替代回答；钥匙先于解释出现。
  - 场景3：观众与谈判双方全程同步；隧道黑暗是节奏器而非信息遮蔽——扣留（L34）在暗场清晰可见，交换（L38）在驶出隧道的亮场完成。
  - 场景4：投放瞬间（L44）观众比追赶者知道得多（追赶者只见背影，L45）；结尾货车发动声（L47）让观众与阿泽重新对齐为"都不知道"。只给声音，不给下方画面。
- **全片纪律**：不用画面替剧本回答它故意不回答的问题——警徽的归属、"她"的身份、发动货车的人。这些信息缺口是剧本的设计，不是待修复的漏洞。
- **声音母题**：机械声与落物声即决定落地。
  - 场景1：警徽金属触桌声（L9 时点的设计音效）是全场最响的单音；底噪为审讯灯低鸣与室外隐约夜声。
  - 场景2：水壶从蒸汽嘶声升级到鸣叫（L21 剧本事实）触发决定；关火后的骤静中，钥匙刮过桌面的声音替周成说话。
  - 场景3：隧道进出改变轮轨声压（L30、L38）；工作证扣桌与存储卡落桌是先后两个干声，构成交换的声音对句。
  - 场景4：持续雨声与踏水脚步；全场无对白，以声音事件为节拍；最后一个声音事件是下方传来的货车发动声（L47 剧本事实），只闻其声。
  - 对白时点一律以剧本行号锚定，不改写、不增补对白。

## 2. 人物视觉关系

无 verified 资产卡，身份稳定依靠每个 Shot 提示词逐字复用以下规范措辞（造型为设计裁决，剧本未给外形）：

- 林警探：四十多岁男性，短发花白，白衬衫袖口卷起，深色领带松开，神情疲惫而强硬。
- 许然：三十多岁男性，深色立领外套（带内袋，L9 需要）覆盖灰色衬衫，姿态克制平静。
- 周岚：约三十岁女性，深绿色圆领毛衣，头发束起。
- 周成：六十多岁男性，灰白头发，褐色旧开衫毛衣，背微驼。
- 顾言：四十岁上下男性，深色大衣内穿正装衬衫，无领带，随身有卡片式工作证（L38 需要，正面全片不示人）。
- 米娅：三十岁上下女性，浅米色风衣配深色围巾，在深色包厢中是唯一亮色主体。
- 阿泽：二十多岁男性，荧光黄雨衣式快递制服（雨夜追逐中的追踪色），怀抱浅灰色防水文件袋。
- 追赶者×2：深色湿雨夹克与深色长裤，始终成组出现，不给可辨识面部特写——匿名是设计意图，也控制多人脸生成风险。

关系线总约定：场景1-3 发起方画左、回应方画右，跨场形成韵律；场景4 以银幕方向翻转代替对话关系；全片所有关键物体动作统一右手执行。

### 场景级关系变化

- **场景 1** (审讯室): 林警探画左施压、许然画右应对；警徽落桌（L9）后权力反转，视觉主导从林警探压照片的手转移到许然的静止；景别由双人建立收紧到单人反拍与桌面插入，L13 收手是反转的可见句点。
- **场景 2** (老旧厨房): 高度差承载权力与亏欠——立（周岚，画右）对坐（周成，画左）；沉默段两人视线不接触（周成看蒸汽，L21）；钥匙推出后关系沿桌面重新连通，周岚移近一步拿起钥匙（L26）完成选择性接受，信留在两人之间。
- **场景 3** (夜行列车包厢): 对坐均势僵持；米娅右手夹卡扣留（L34）使画右暂时占优；工作证翻扣（L38）是画左的让步动作；交换在桌面中央会合，均势以两件物体并置的方式恢复。
- **场景 4** (多层停车楼): 追逐的前后与上下关系代替对话关系——阿泽与追赶者保持约一层的垂直差（L42）；转角投放（L44）后人与物分离，追赶者只认背影（L45）并继承阿泽的银幕方向；顶层只剩单人，关系对象变为画外声源（L47）。

## 3. 色彩、光比与稳定性变化

全片节奏弧线：静、更静、最窄、爆发、静——三场室内逐场收窄（制度空间→家庭空间→车厢最窄），第四场释放为垂直运动，顶层回到静止。每场只允许一个主导视觉变化维度，其余维度保持稳定，避免逐镜堆叠技法。

- **场景 1** (夜, 审讯室): 色彩路径=冷绿制度色恒定，顶灯光池即竞技场，人物探入光池面部可读、退出沉入暗部；光比=约1:8；稳定性=固定机位为主，唯一摄影机运动保留给警徽落桌前后；主导变化维度=灯池内手与物的尺度；主导情境=conversation_power，桌面插入镜用 investigation_object 逻辑。
- **场景 2** (清晨, 老旧厨房): 色彩路径=暖中性怀旧色，低角度晨光从水槽上方窗进入，蒸汽受光，信是桌面最亮白色块；光比=约1:2.5；稳定性=固定或微移；主导变化维度=蒸汽与晨光中的高度差；主导情境=conversation_power 与 investigation_object。
- **场景 3** (夜, 夜行列车包厢): 色彩路径=车厢内暖阅读灯恒定对窗外冷蓝城市光流，隧道段窗层转纯黑、内景对比升高，光的中断与恢复绑定谈判的僵持与成交；光比=隧道外约1:3、隧道内约1:6；稳定性=贴桌小幅机位；主导变化维度=窗层亮灭；主导情境=conversation_power 与 suspense_reveal。
- **场景 4** (雨夜, 多层停车楼): 色彩路径=钠光橙与荧光冷绿逐层交替，湿地面反光，雨在逆光中可见，顶层开放夜空冷蓝收尾；光比=光池与暗区交替的高反差约1:8；稳定性=手持/跟随为主，唯一静点是 L44 投放插入镜——运动流中唯一的静点就是误导点；主导变化维度=运动与静止；主导情境=action_chase 与 suspense_reveal。

## 4. 关键空间拍摄逻辑

- **审讯室**（场景1）：金属桌与两椅相对；门在林警探身后画左深处；无单面镜。摄影可用区域=桌轴两侧的反拍区与桌面俯角插入位；保持林警探画左、许然画右不越关系线，桌面插入镜保持中性俯角。照片推动方向为左→右；警徽为垂直落下（放置，无横向行程）。
- **老旧厨房**（场景2）：水槽与窗在画右一侧，小餐桌在画左，灶台在周成一臂之内（支撑 L21 坐姿关火）。摄影可用区域=厨房开阔一侧与桌端；保持周成画左、周岚画右；窗光方向恒定为画右来光；钥匙推动方向为左→右。
- **夜行列车包厢**（场景3）：对坐软座夹窄桌，窗在桌端；摄影机保持走廊一侧不越关系线；窗层作为背景信息层只承载光流与黑暗。顾言画左、米娅画右；存储卡最终由画右一侧的手放入桌面中央。
- **多层停车楼**（场景4）：上行坡道；排水沟横贯坡道与转角平台交界；转角停货车（L44）；转角位于顶层下一层；顶层开放夜空，边缘有矮护墙。坡道段跟随与迎面机位沿坡道轴布置；转角前阿泽向画右上方奔跑，转角后翻转为向画左上方——可见的转角让方向翻转合法，翻转本身标记"人与物分离"；追赶者沿同一路径继承同样翻转；顶层收束为静止。

## 5. 视觉母题与使用边界

- **母题：表面上的权力**。桌面（场景1-3）与地面（场景4）是权力棋盘，物体落点语法全片一致：推向中央=施压/摊牌（L5、L38 的桌面中央）；放在旁边=对等反制（L9 照片旁）；推向对方=移交（L21-L22）；翻面扣下=抵押承诺（L38）；滑入底部=藏匿误导（L44）；留在原处=拒绝全盘接受（L26 信留桌上）。横向推动是施压，垂直落下是定论。
- **使用边界**：母题只通过剧本写明的物体动作呈现，不发明额外物件动作；桌面/地面插入特写只服务上述剧本动作；母题不用于回答剧本未回答的问题（警徽归属、"她"的身份、货车驾驶者）。
- **平面证物规则**：关键剧情信息不依赖生成可读文字——照片用模糊影调加人物反应表意；信用撕开的信封与折痕表意；工作证靠翻面扣下（正面永不示人）；文件袋用颜色与形状识别；钥匙用彩色塑柄，不给可读编号。
- **反光与透明控制**：审讯室不设单面镜；列车玻璃只承载光流与黑暗，不要求清晰倒影；停车楼积水反光作色块处理，不作镜像。
- **生成与时间纪律**：每个 Shot 是独立 SD2.0 生成单元，时长大于 0 秒且不超过 15 秒；一条视觉时间线，首末节点必为 [SB]；视频取全部节点，故事板只取 [SB] 节点；每场 N 个镜头配 N+1 个共享 Boundary，四场 B0 均为全新完整建立（无上场继承）；全片 text_only，参考资产写"无"，身份靠第 2 节规范措辞逐字复用；场景1-3 以 event_nodes 为主（对话与凝视不逐秒机械填充），场景4 以 second_nodes / half_second_nodes 覆盖起势、启动、行进、投放、越过、登顶各阶段；场间交接一律 post_production 硬切，由前场 BN 交出状态与后场 B0 建立状态各自完整承担，不做跨生成单元的镜内变形。
- **预计密度（非约束，Master 阶段裁决）**：场景1-3 各 4-6 镜，场景4 约 5-7 镜。
