## 1. 场景设计

场景前状态：与场景3无实体继承。雨夜多层停车楼，雨持续；阿泽已在坡道上奔跑，文件袋在他双臂怀中；两名追赶者在下一层；深色厢式货车停在顶层下一层的转角平台。
戏剧变化：追逐中的误导投放——阿泽被两人追赶（L42），跨过排水沟后在转角把文件袋滑进货车底（L44）；追赶者只认背影、越过藏点继续追（L45）；他到达顶层边缘停下，下方传来货车发动声（L47）：物体脱离所有人的视线与控制。
信息策略：投放瞬间观众比追赶者知道得多（看见滑入，追赶者只见背影）；结尾引擎声让观众与阿泽重新对齐为"都不知道"——只给声音，不给下方画面，货车驾驶者保持未答。追赶者全场匿名，不给可辨识面部。
场景后状态：阿泽独自立于顶层边缘，两手空，俯视下方黑暗；文件袋在画外货车底随车；雨持续；引擎声为全集最后一个声音事件。
场景空间：多层停车楼外景：上行坡道逐层盘升；排水沟横贯坡道与转角平台交界；转角平台位于顶层下一层，深色厢式货车停于转角；顶层为开放雨夜天空，边缘有矮护墙；混凝土立柱与层灯分布各层。
关系线：转角之前阿泽沿坡道向画右上方奔跑，追赶者继承同一方向；转角处以可见的转身完成银幕方向翻转，此后向画左上方；顶层收束为静止，关系对象变为画外下方声源。
人物路径：阿泽：下层坡道—跨排水沟—转角滑停投放—转身上行—顶层—护墙边停定；追赶者二人：下一层冲上—沿同一路径越过货车—转上上行坡道（此后画外）；货车全场静止，仅在结尾以画外引擎声存在。
摄影可用区域：坡道侧固定大全景位、坡道内手持跟拍带、转角平台地面高度固定位与略高固定位、顶层固定大全景位与边缘侧面近景位；所有运动沿坡道真实可通行路径。
视觉策略：手持/跟随为主的运动镜头链中嵌入唯一静点（投放插入镜）；钠光橙2200K与荧光冷绿4500K逐层交替，顶层开放夜空冷蓝6500K收尾；光比坡道光池1:8、顶层1:4；雨在逆光中可见；主导变化维度=运动与静止。
镜头拆分理由：大全景交代层级追逐关系后切入跟拍；跨沟落地是动作峰值切点；投放必须以静止插入独立成镜；追赶者越过藏点单独成镜完成误导；登顶减速转入静止；最后的引擎声反应独立成镜收束全集。
场间关系：自场景3桌面静帧硬切进入，首帧即奔跑踏水（全集最大静动反差）；结尾静止人影与雨声渐弱收束至黑场，为全集终点。
场景蓝图：[D] 雨夜多层停车楼外景，钠光橙与荧光冷绿在各层交替成光池，雨丝在灯前成串，湿地面映出色块反光；阿泽（二十多岁男性，荧光黄雨衣式快递制服，全身湿透）双臂抱着浅灰色防水文件袋沿坡道向上奔逃，两名深色雨夹克的追赶者成组紧随；转角平台的深色厢式货车底部吞下文件袋，顶层开放的冷蓝夜空下，追逐终结于一个听着下方引擎声的静止背影。
声音基调：[D] 持续雨声与楼体排水声铺底，踏水脚步与喘息是最近的声音；全场无对白，以声音事件为节拍；结尾画外货车引擎发动声带楼体回声，是全集最后一个声音事件。
