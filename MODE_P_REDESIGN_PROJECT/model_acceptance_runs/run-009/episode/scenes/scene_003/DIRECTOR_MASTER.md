## 1. 场景设计

场景前状态：与场景2无实体继承。夜行列车行进中；存储卡在米娅风衣口袋，工作证在顾言大衣内袋；桌面空。
戏剧变化：信息交换的谈判——顾言开价（L32），米娅夹卡扣留并反开价（L36），僵持在隧道内；驶出隧道后顾言以工作证翻扣作抵押（L38），米娅才把存储卡放到桌面中央，交换达成。
信息策略：观众与谈判双方全程同步；隧道黑暗是节奏器而非信息遮蔽——扣留在暗场清晰可见，交换在驶出隧道的亮场完成。单一隧道段裁决：L30 进入（窗层转黑），L38 驶出（光流恢复），两句对白都发生在隧道内。工作证正面全场不示人，存储卡内容保持未答。
场景后状态：存储卡在桌面中央，工作证背面朝上在顾言一侧桌面，两人对坐各自收手；列车已出隧道，窗外城市光流恢复。
场景空间：夜行列车包厢：两排软座相对，中间夹窄桌；车窗在窄桌外端（窗侧墙），暖阅读灯在窗端上方；走廊在另一侧，为摄影机一侧；车体持续轻微晃动。
关系线：顾言坐车头侧座（走廊视角画左）面向车尾方向，米娅坐车尾侧座（画右）面向车头方向；关系线沿窄桌轴；全部机位保持走廊一侧，不越线。
人物路径：两人全场保持对坐；位移只在手部——米娅右手自口袋取卡夹于指间、最终放到桌面中央；顾言右手自大衣内袋取工作证翻面扣于自己一侧桌面。
摄影可用区域：走廊侧横向机位带（双人位、两个过肩单人位）、桌面上方斜俯近摄位；空间狭窄，无移动调度。
视觉策略：全场固定机位、贴桌小景别；车厢暖阅读灯3200K恒定，窗层为第二光层——城市光流、隧道纯黑、光流恢复；光比隧道外1:3、隧道内1:6；主导变化维度=窗层亮灭，绑定谈判的僵持与成交。
镜头拆分理由：隧道黑定格后切开价者；话音落切被夹持的卡（回应以物出现）；卡静止后从物切人说反开价；话音落反应切回双人；出隧道与两次落桌在同一镜内连续完成，成交必须同框。
场间关系：自场景2静帧硬切进入，轮轨声接住水壶鸣叫余韵（声音桥由剪辑执行）；离场以桌面中央存储卡的结束静帧硬切场景4的踏水奔跑，构成全集最大静动反差。
场景蓝图：[D] 夜行列车包厢，暖阅读灯（3200K）从窗端上方照亮窄桌与两人面部内侧，桌端车窗上城市灯光拉成光带自画左向画右掠过；顾言（四十岁上下男性，深色大衣内穿正装衬衫，无领带）坐画左，米娅（三十岁上下女性，浅米色风衣配深色围巾，深色包厢中唯一亮色主体）坐画右；列车进入隧道后窗面转为纯黑，谈判在黑窗前僵持，驶出隧道的光流中，一张翻扣的工作证换来桌面中央的一张存储卡。
声音基调：[D] 轮轨声恒定铺底，隧道内声压升高变闷、出隧道骤然开阔；包厢混响小而近；两句对白干声；工作证扣桌与存储卡落桌是先后两个干脆的物件声。
