## 1. 场景设计

场景前状态：全集开篇，无上游继承。夜，审讯已在进行中；模糊的停车场照片在林警探手边桌面，警徽在许然外套内袋。
戏剧变化：审讯权力反转——林警探以照片施压（L5）并质问（L7），许然以警徽反制（L9、L11），林警探停住收手（L13）。
信息策略：观众与林警探同步。警徽出现前观众只看见许然的静止；反制物出现的惊讶落在林警探身上，反转由他的收手动作确认，全程无解释性对白。警徽归属保持未答，画面不作裁决。
场景后状态：照片与警徽并列于桌中央光池内，林警探双手离桌坐直，许然静坐；质问中断。
场景空间：封闭审讯室，无窗墙面沉暗；金属桌东西向，两把椅子相对；门在西北深处林警探身后；无单面镜；顶部审讯灯是唯一光源，在桌面投下圆形光池。
关系线：林警探坐西侧（画左）面向东，许然坐东侧（画右）面向西；关系线沿桌面东西轴；全部机位保持桌南侧一侧，桌面插入镜为中性俯角，全场不越线。
人物路径：两人全场保持就座，位移只发生在手部——林警探右手推照片至桌中央并压住直到 L13 收回；许然右手自外套内袋取警徽落于照片旁后收回桌沿内侧。
摄影可用区域：桌南侧弧线（双人位、过肩单人位各一侧）、桌面高度近摄位、桌面正上方俯拍位；无绕轴与穿越调度。
视觉策略：固定机位为主，全场唯一摄影机运动是 Shot 3 的缓慢推近；景别从双人中景收紧到单人近景与桌面特写再落回俯拍定局；4300K 冷绿顶光、光比 1:8 全场恒定；主导变化维度=灯池内手与物的尺度。
镜头拆分理由：L7 话音落定切许然的反应；许然右手起动切桌面动作；警徽落定切回其面部说 L11；L11 话音落反应切林警探；收手完成结果切俯拍定局。
场间关系：黑场硬切进入，灯声先于画面；离场以俯拍桌面物件（照片+警徽并列）硬切场景2晨光桌面的信，构成桌面物件图形押韵。
场景蓝图：[D] 夜间审讯室，一盏顶部审讯灯在金属桌面投下唯一的圆形冷绿光池（4300K，光比1:8），四壁沉入黑暗；林警探（四十多岁男性，短发花白，白衬衫袖口卷起，深色领带松开，神情疲惫而强硬）坐画左，许然（三十多岁男性，深色立领外套覆盖灰色衬衫，姿态克制平静）坐画右，隔桌相对；一张模糊的停车场照片与一枚金属警徽先后进入光池中央，本场全部变化发生在桌面光池内的手与物之间。
声音基调：[D] 审讯灯低频电流声为恒定底噪，室外隐约夜风；小空间短混响，两句对白干而近；警徽金属触桌声是全场最响的单音。
