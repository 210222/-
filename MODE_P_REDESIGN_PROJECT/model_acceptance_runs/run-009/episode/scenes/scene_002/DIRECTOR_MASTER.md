## 1. 场景设计

场景前状态：与场景1无实体继承（人物、道具、空间全部更换）。清晨老旧厨房：已拆开的信在桌上，水壶在灶上冒蒸汽，灶火燃着；储物柜钥匙在周成开衫口袋。
戏剧变化：沉默的父亲以物代答——周岚质问（L19），周成以蒸汽与沉默拖延（L21），水壶鸣叫触发决定：关火、推出钥匙（L21-L22）并说明（L24）；周岚拿钥匙、留信（L26），完成选择性接受。

场景后状态：钥匙在周岚右手，信仍摊在桌面，灶火已关、蒸汽散尽；父女之间的账未清但交接已完成。
场景空间：老旧厨房：水槽与窗在东侧（画右），窗上方进晨光；小餐桌在西侧（画左）；灶台在餐桌东北角、周成一臂之内，水壶置其上；信摊在桌面西侧。

人物路径：周成全场保持就座，右手完成关火与推钥匙两个动作；周岚全场立于水槽旁，仅在 L26 向餐桌东端移近一步拿起钥匙后直起身。
摄影可用区域：厨房南侧开阔面（全景位、单人位、低位深焦位）、餐桌东端桌面高度近摄位；无穿越调度。
视觉策略：全场固定机位；景别从全景收到单人与桌面近摄；3400K 低角度暖晨光、光比 1:2.5 恒定，蒸汽为受光可见元素；主导变化维度=蒸汽与晨光中的高度差（立着的女儿对坐着的父亲）。
镜头拆分理由：L19 话音落切父亲的沉默侧脸；水壶鸣叫爆发以声音切进桌灶动作；钥匙停在桌缘切开说 L24 的深焦双人；话音落、视线相接切她的拿取；拿取完成静止收尾。
