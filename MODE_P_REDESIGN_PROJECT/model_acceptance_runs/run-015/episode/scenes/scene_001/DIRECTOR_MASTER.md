## 1. 场景设计

```text
场景前状态：（本集首场，无继承。林警探与许然已在审讯室内隔桌对坐，审讯进行中。林警探持有停车场照片。）
戏剧变化：林警探以照片指控许然，处于审讯者权力高位。许然不回应照片，反手取出一枚警徽置于照片旁并反问——审讯关系瞬间逆转，林警探从进攻者变为被质疑者，收手停住。
信息策略：观众与林警探共享信息位——开场以为许然是被审者（L7），许然取出警徽（L9-L10）时观众与林警探同时被反制，共同进入"不知道"的状态。揭示由物件（警徽）承载，不依赖对白解释。
场景后状态：审讯室内两人隔桌相对，桌上留有停车场照片和警徽。林警探手已收回。权力关系已逆转，但问题未解决——警徽的来源未被回答。（本集独立短篇，不传至下一场。）

场景空间：矩形审讯室，无窗。一张金属或复合材质矩形桌居中，桌两侧各有一把椅子。天花板荧光灯为唯一光源。人物身后为墙壁，门在人物身后画外或虚化远景处。
关系线：沿桌面长轴建立 180 度线。林警探在桌一侧，许然在另一侧。视线方向互补：林警探看许然为画面左→右，许然看林警探为画面右→左。
人物路径：林警探——手从桌面照片上收回（L13），身体无位移。许然——右手从桌面不动移至外套内袋（L9），取出警徽后放回桌面（L10），身体无位移。
摄影可用区域：桌面两侧外反拍机位（林警探肩后拍许然、许然肩后拍林警探）；桌面正上方高角度俯拍；贴近桌面的低角度沿桌面拍摄。

视觉策略：冷白荧光顶灯、高光比（约 4:1）、去饱和冷调。固定机位，缓慢推进承载揭示压力。景别从双人中景（建立关系）经许然单人近景（揭示动作）至林警探单人特写（反应与反转）。警徽出场时由低角度手部特写承载——物件替代人脸成为视觉重心。
镜头拆分理由：三个戏剧节拍——指控（L5-L7）、反制（L9-L11）、反应（L13）。每个节拍改变权力关系和画面信息重心，各需一个镜头。
场间关系：本场从黑场/前一独立短篇硬切进入（post_production），以林警探收手的静止画面结束。桌上照片和警徽为本场最终可见状态。

场景蓝图：[D] 夜间封闭审讯室。冷白荧光从天花板垂直落下，桌面反射硬光。两人上半身在桌两侧，面部半阴半亮。桌面为视觉轴线，物件（照片、警徽）的推放和位置改变是权力转移的唯一可见证据。窗外无光，空间封闭压抑。
声音基调：[D] 荧光灯微弱交流声（持续环境底噪）。房间声学干燥、近场，无混响。对白声音清晰直接，无背景环境声干扰。无音乐。
```
