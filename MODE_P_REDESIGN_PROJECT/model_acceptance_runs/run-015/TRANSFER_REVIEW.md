# TRANSFER REVIEW (D4) — run-015

## D4: Cross-Scene Knowledge Transfer (跨场景知识迁移)

D4 evaluates whether the Director applies knowledge differently across scenes rather than mechanically repeating the same solution.

### Table-as-Power-Mediator Pattern

All three interior scenes (1, 2, 3) use a table as the central object mediating power relationships, but each deploys it differently:

- **Scene 1 (审讯室):** Table as confrontation axis — objects (photo, badge) travel across the table surface to track power reversal. The table is metallic, reflective, under cold institutional light (4000K). Camera stays in over-shoulder / single closeup positions. The table IS the battlefield.

- **Scene 2 (老旧厨房):** Table as domestic separation — the letter and key occupy the table surface between 周岚 and 周成, but the kettle/steam is the actual emotional mediator. The table is wooden, warm, under morning window light (5000K). Camera starts wide (establish space), pushes in for key transfer, pulls back for departure. The table is a staging ground for what's left behind.

- **Scene 3 (夜行列车):** Table as negotiation surface — narrow train table where storage card and work badge are the stakes. Movement is vertical (card held between fingers above table, badge placed face-down on table). Light changes dramatically (tunnel → emerging) rather than subtly. Camera includes window as second visual element (city lights, tunnel). The table is a temporary deal-making surface.

**Transfer analysis:** The Director recognized the common "table as power mediator" spatial pattern but adapted it to each scene's dramatic needs — institutional cold vs. domestic warmth vs. transactional urgency. Light temperature, camera stability, framing strategy, and object choreography all differ.

### Object-as-Reveal Pattern

Two scenes use a physical object reveal as the dramatic turning point:

- **Scene 1:** 许然 pulls the badge from inside his coat (L9-L10). The badge is kept hidden until Shot 2. Camera uses a closeup on 许然's hand exiting the coat, then the badge entering the desktop light zone. The cold metal reflects the fluorescent top-light — institutional authority made visible.

- **Scene 3:** 米娅 holds the storage card between two fingers but doesn't release it (L34). The card is a withholding tool. Camera stays on 米娅's face during negotiation; the card becomes visible only when she's ready. 顾言必须 first surrender his work badge before the card is placed on the table (L38).

**Transfer analysis:** Both scenes use a hidden-then-revealed object to drive the power shift, but the visual strategy differs: Scene 1 uses the object's sudden appearance in light as the reveal mechanism; Scene 3 uses the object's deliberate withholding and eventual placement as a mutual exchange ritual. The Director did not copy Scene 1's "coat pocket → table light" pattern for Scene 3.

### Chase vs. Static Action Design

- **Scene 4 (停车楼):** Uses staged action phases across 5 shots — running, obstacle crossing, hidden slide, pursuer miss, stopping at edge. Action verbs dominate the visual timeline. The sodium/rain complementary light scheme is entirely different from the three interior scenes.

**Transfer analysis:** Scene 4 is the only exterior action scene. The Director deployed a completely different visual vocabulary (handheld, complementary color scheme, vertical spatial axis, action_chase profile) rather than adapting an interior-conversation pattern. This demonstrates genuine cross-domain knowledge transfer rather than template reuse.
