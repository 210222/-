场景前状态：无前场继承。独立叙事线，从黑场建立雨夜停车楼。
戏剧变化：快递员阿泽被两名追赶者追逐。他利用停车楼的空间结构完成一个战术欺骗——在转角处将文件袋滑入货车底部藏匿，自己继续向顶层跑引开追赶者。追赶者只看到他的背影——越过货车继续追，错过了文件袋。阿泽到达顶层边缘后停下，听到下方货车发动的声音——第三方力量的引入。文件袋安全了，但阿泽被困在顶层。追逐从身体对抗转为空间策略——阿泽用智慧赢得了文件袋的安全，但付出了自己被暴露的代价。
信息策略：观众比追赶者知道得更多——我们看到文件袋被滑入货车底部。追赶者越过货车时的"错过"制造了信息差的悬念满足。货车发动声是新的未知——观众也不知道是谁在开车。无对白——全部信息通过身体动作、空间关系和环境声音传达。
场景后状态：阿泽在顶层边缘静止，呼吸从急促减缓。文件袋在货车底部暗处——安全但不可见。追赶者仍在坡道上方追逐（已越过货车）。雨持续。货车引擎声从下方传来——新的力量被引入。开放结局——阿泽的处境未解决。

场景空间：多层螺旋停车楼。坡道连接各层，约3-4m宽。混凝土立柱、排水沟、停车位。一辆白色货车停在坡道转角处的停车位。顶层是开放边缘（矮墙或无边）。每层高度约2.5m。荧光灯管（4000K）和钠灯（暖橙）提供斑驳照明。地面水迹反射灯光。雨夜。
关系线：阿泽的运动方向是从画面右下向左上（沿坡道上升）。追赶者在阿泽后方。阿泽在货车转角处的俯身滑入动作是方向转折——从向上跑转为向下俯身再恢复向上。保持银幕方向连续性——阿泽始终从左向右运动（观众视线方向）。
人物路径：阿泽：沿坡道上跑→跨排水沟→俯身滑文件袋入货车底→起身继续向顶层跑→顶层边缘停下。追赶者：从下层冲上→沿坡道上跑→越过货车→继续向顶层追。
摄影可用区域：坡道入口（广角纵深远景）、坡道中段跟拍（阿泽背后或侧面）、货车转角后方（文件袋藏匿）、货车后低角度（追赶者越过）、顶层边缘（阿泽背影+停车楼下层俯瞰）。手持/肩扛摄影机。

视觉策略：action_chase主导。手持/肩扛摄影与阿泽的运动同步——运动中的抖动是追逐的身体感。橙钠光与混凝土灰的冷暖交替——跑过明亮灯管区和暗柱区形成斑驳光比。广角建立纵深（坡道入口），中焦跟拍动作（跨沟、藏匿、跑动），长焦压缩顶层（阿泽在边缘与下层空间的关系）。雨水全程——地面反射、立柱湿润、人物头发和外套湿透。顶层停下后：摄影机也静止——从追逐视觉转为观察视觉。
镜头拆分理由：Shot 1广角建立坡道纵深和追逐——阿泽在前跑，追赶者从下层冲上，空间方向和速度差建立。B1切在阿泽接近转角。Shot 2跟拍阿泽跨沟和藏匿文件袋——这是全场核心战术动作，需要跟到文件袋滑入暗处的完整过程。B2切在阿泽起身继续跑、追赶者接近转角。Shot 3从货车后方低角度——追赶者越过货车没发现文件袋，愚弄完成。B3切在追赶者远去。Shot 4阿泽到达顶层——停下，听到引擎声。四镜对应建立→藏匿→愚弄→暂停。
场间关系：从黑场建立（SCENE_ENTRY），以阿泽在顶层边缘静止、引擎声传来、雨持续的开放状态交出（SCENE_EXIT）。独立叙事线，无连续性传递。

场景蓝图：[D] 多层混凝土停车楼，雨夜。阿泽（22-28岁，快递制服/运动装束、深色速干面料、抱着棕色文件袋）沿坡道上跑。两名追赶者（25-35岁，深色便服/工装、体型宽大）从下层冲上。橙色钠灯和冷色荧光灯在湿混凝土表面形成斑驳冷暖光区。白色货车停在转角处停车位。雨水持续——地面反光、立柱湿润。广角建立纵深→手持跟拍动作→低角度愚弄镜头→顶层静止背影。无对白——全部信息通过动作、空间和声音传达。
声音基调：[D] 持续雨声——雨滴打在混凝土上的白噪音。脚步声——阿泽的轻快步频，追赶者的重踏步——在混凝土结构中混响。排水沟水流声。文件袋滑过水泥地面的沙沙摩擦声。追赶者喘息和溅水声。货车柴油引擎发动声（点火、启动、怠速）从下方传来。顶层雨声更开阔。无对白。无音乐。
