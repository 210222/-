## 1. 全片戏剧与信息释放弧线

**fact: director_choice**

四场独立场景的并列本身构成戏剧弧线。每场结尾交出未完全解决的开放状态。

**Scene 1 出口**: 林警探收回手，许然未再说话。警徽和照片留在桌上——谁赢了？两人都没有离席。权力已经易手，但新的秩序尚未建立。

**Scene 2 出口**: 周岚拿走了钥匙，信留在桌上。父亲坐在原位。这不是和解——是一个人决定独自上路。母亲的存在从秘密变成了任务。

**Scene 3 出口**: 存储卡在桌面中央，工作证扣在桌上，列车继续行驶。交易完成了，但两人都不轻松。

**Scene 4 出口**: 阿泽在顶层边缘停下，呼吸，倾听货车发动声。文件袋安全了。但阿泽被困在顶层——他的故事在这里暂停。

**从权力戏剧到生存动作的强度弧线**: Scene 1 的静止权力博弈 → Scene 2 的沉默情感决裂 → Scene 3 的密室谈判与光变转折 → Scene 4 的全力身体追逐与空间策略。节奏从静止到激烈，从室内到室外，从言语到行动。

整体信息释放策略：每场以物件作为权力和信息的载体，摄影机围绕物件的移动和交换来建立视觉弧线。人物之间的关系变化通过物件传递来视觉化——谁持有物件、谁放下物件、谁拿走了什么、谁留下了什么。观众在每个瞬间知道的和人物一样多或更少，悬念来自看见交换的动作，而非被隐藏的事实。

每场的视觉弧线核心：
- Scene 1: 林警探持有"证据" → 许然出示更具毁灭性的"证据" → 权力静默反转。
- Scene 2: 周岚面对"谎言" → 父亲交出"钥匙"但不给"解释" → 周岚选择带走行动而留下话语。
- Scene 3: 顾言要求"交出" → 米娅提出"交换" → 双方各放下一个象征物，在列车穿出隧道的白光中达成交易。
- Scene 4: 阿泽被追逐 → 阿泽用空间判断藏起"文件" → 阿泽到达边界，听到未知的"引擎声"。

## 2. 人物视觉关系

### 2.1 林警探 (Inspector Lin) — Scene 1

**fact: script_fact, source L5-L13**

- **Identity**: 警探，审讯主导者，开场处于权力高位，随后被许然反制。
- **Age impression**: 35-45岁，从警十年以上的职业感。
- **Physicality**: 中等身材，肩背挺直，习惯性地占据桌面空间。手指压照片时稳定果断，但收回手时有可见的迟疑——手从照片上缓慢撤回，指节轻微弯曲。
- **Costume**: 便衣警探装束——深色夹克外套，内搭衬衫。外套可容纳内袋（许然的警徽来源线索）。整体色调偏暗灰/藏青。
- **Key action**: 将照片推到桌中央 → 手压在照片上 → 被许然反击后停住，收回手。
- **Relationship to Xu Ran**: 开场为审讯者-被审讯者的高低关系。许然出示警徽后权力反转——林警探的"收回手"是权力放弃的肉体证据。两人隔桌对坐，物理距离未变，但关系距离已经不可逆地改变。

### 2.2 许然 (Xu Ran) — Scene 1

**fact: script_fact, source L5-L11**

- **Identity**: 被审讯者，但身份存疑——持有林警探的警徽，掌握了信息优势。
- **Age impression**: 30-40岁，有体制内背景，姿态沉稳不迫。
- **Physicality**: 面对审讯者的压力保持不动。没有碰照片是一个关键表演细节——身体不向前倾，不接对方的邀请，而是从他的空间里取出更强的物件。动作慢而精确。
- **Costume**: 整洁便装，外套有内袋。颜色与林警探形成对比——可偏浅灰或棕褐，暗示两人并非同路。
- **Key action**: 没有碰照片 → 从外套内袋取出警徽 → 将警徽放在照片旁。
- **Relationship to Lin**: 被审视者变为质问者。警徽是他逆转关系的武器——他从被观察的位置进入观察者的位置。

### 2.3 周岚 (Zhou Lan) — Scene 2

**fact: script_fact, source L17-L25**

- **Identity**: 女儿，发现父亲隐瞒母亲仍在世的真相。开场站立——姿态对抗，靠近水槽却不使用它，说明她在对话前就已停下手头的事。
- **Age impression**: 25-32岁，成年女儿回到父亲住处。
- **Physicality**: 站在水槽旁，身体没有完全朝向父亲——可能是半侧身，一个准备好离开的姿态。拿起钥匙的动作利落，但将信留在桌上——两个动作形成对比，表达对实物的选择和对谎言的拒绝。
- **Costume**: 日常便装，清晨在家的随意感。不化妆或淡妆，面容有睡眠不足的痕迹。
- **Key action**: 质问后等待 → 水壶鸣叫时未动 → 拿起钥匙但把信留在桌上。
- **Relationship to Zhou Cheng**: 女儿与父亲，信任已被"信"击碎。周岚选择站着（物理上高于坐着的父亲），但这不是权力的胜利——是距离的建立。

### 2.4 周成 (Zhou Cheng) — Scene 2

**fact: script_fact, source L17-L25**

- **Identity**: 父亲，保守了一个关于妻子/周岚母亲仍活着的秘密。用沉默、蒸汽和钥匙作答，而非语言辩解。
- **Age impression**: 55-65岁，劳动者气质，手部可见年龄痕迹。
- **Physicality**: 坐着，身体重心后靠。不回应女儿质问时看的是水壶蒸汽，不是女儿——这是回避，也是无力面对。关火、推钥匙的动作比说话更有力。
- **Costume**: 老旧家居服或旧衬衫，袖子可能卷起。与厨房的老旧感融为一体。
- **Key action**: 看蒸汽，沉默 → 水壶鸣叫后关火 → 把钥匙推向周岚。
- **Relationship to Zhou Lan**: 拥有信息但失去信任的父亲。沉默是对女儿愤怒的回应——他没有为自己辩护的资格，只交出"钥匙"作为唯一的答案。

### 2.5 顾言 (Gu Yan) — Scene 3

**fact: script_fact, source L30-L38**

- **Identity**: 接头人/办案人员，持工作证。开场要求米娅交出存储卡，被拒绝后通过翻扣工作证完成权力交换。
- **Age impression**: 30-38岁，职业干练，有街头经验。
- **Physicality**: 隔着窄桌坐，身体前倾——距离近，压迫感强。翻扣工作证的动作是全场转折：不是递出、不是摊开，而是翻面扣下——意味交出身份掩饰。
- **Costume**: 深色外套或风衣，便于移动的职业着装。工作证藏在衣内，取出时观众才确认他的身份。
- **Key action**: 要求存储卡 → 等待米娅讨价 → 翻扣工作证在桌上 → 看着米娅将存储卡放到桌面中央。
- **Relationship to Mia**: 保护者与证人的谈判关系。米娅不信任他，他也不完全信任米娅。两人隔着窄桌——距离比审讯室更近，但信任更薄。

### 2.6 米娅 (Mia) — Scene 3

**fact: script_fact, source L30-L38**

- **Identity**: 证人，持有关键证据（存储卡）。不被动——她拥有顾言需要的东西，并以此谈判自身安全。
- **Age impression**: 25-33岁，紧张但计算清晰，有自我保护的本能。
- **Physicality**: 将存储卡夹在两指之间却不递出——这是全场表演核心。两指夹卡的姿态既是展示又是保留，身体语言在说"你看见了吗？但你不给条件就拿不到"。列车出隧道后光线变化伴随她的决定：把卡放到桌面中央。
- **Costume**: 旅行装束，低调不引人注目。外套或有口袋（存储卡的来源），色调偏向暗色，便于在人群中消失。
- **Key action**: 夹住存储卡不递出 → 提出交换条件 → 在顾言翻扣工作证后将存储卡放到桌面中央。
- **Relationship to Gu Yan**: 被保护者但并非无力——她持有顾言需要的东西。她的筹码让她在这场谈判中具有对等的议价权。

### 2.7 快递员阿泽 (Courier A Ze) — Scene 4

**fact: script_fact, source L42-L46**

- **Identity**: 被追赶的快递员，抱着重要文件袋。敏捷、果断，在追逐中用空间判断力甩开追赶者。
- **Age impression**: 22-28岁，年轻体力劳动者，经常跑楼的体型。
- **Physicality**: 跑动中仍能保护怀中的文件袋。跨过排水沟的动作精确而有弹性。将文件袋滑入货车底部的动作是瞬时判断——俯身、推滑、转身继续跑一气呵成。到达顶层边缘后突然停下，呼吸急促但控制住，倾听下方声音。
- **Costume**: 快递制服或功能性运动装束——速干面料、深色或反光条，适合全天候跑动。可能有公司标识，但雨夜中不甚可辨。
- **Key action**: 沿坡道向上跑 → 跨过排水沟 → 将文件袋滑入货车底部 → 继续向顶层跑 → 在顶层边缘停下倾听。

### 2.8 追赶者甲、乙 (Two Pursuers) — Scene 4

**fact: script_fact, source L42-L44**

- **Identity**: 两名追赶阿泽的人。身份不明（可能是竞争对手快递员、讨债者或敌对势力），但目标明确——抓住阿泽或截获文件袋。
- **Age impression**: 25-35岁，强壮，比阿泽体型大一号。

- **Costume**: 深色便服或工装，雨夜中几乎融入停车楼的暗色。
- **Key action**: 从下一层冲上来 → 只看见阿泽背影 → 越过货车追上去（未发现文件袋）。

## 3. 色彩、光比与稳定性变化

**fact: director_choice**

### 3.1 总体策略

四场独立故事的共同视觉策略：以物件作为权力和信息的载体，摄影机围绕物件的移动和交换来建立每场的视觉弧线。每场使用不同的光线风格来建立独立的世界，但在物件交叉的瞬间使用相似的近摄语言——手的特写、物件接触桌面的声音、人物对手上动作的反应——形成跨场的视觉母题连贯。

手持或轻微浮动感用于追逐场景 (Scene 4)，其余三场使用固定或缓慢推轨的摄影机，让表演和物件传递承担动力。镜头选择偏中长焦 (35mm-85mm 等效) 以隔离人物和物件，广角仅用于空间建立 (Scene 4 的停车楼结构) 和有限的特写强调。

无 verified 资产卡。全片使用 `text_only` 生成模式。

### 3.2 场景色彩与光比

**Scene 1 (审讯室)**
- **色彩**: 冷调——灰蓝与金属银。荧光灯光在白色桌面上的冷反光。警徽的金色是唯一暖色，成为一个异质点。整体低饱和度，偏冷。
- **光源**: 头顶荧光灯管或单盏吊灯，色温偏冷（约5000K），在桌面形成高光，人脸落于顶光的自然阴影中。
- **光比**: 高光比——桌面亮区与人物面部阴影形成强对比。权力反转无光变——光保持恒定，变化在构图和表演中完成。
- **稳定性**: 全固定镜头。摄影机如同审讯记录仪般静止，不参与叙事。

**Scene 2 (老旧厨房)**
- **色彩**: 暖灰与晨蓝——清晨冷光从窗户射入，与灶火暖光和木质家具的棕色调混合。蒸汽的白柔软了画面。整体饱和度中等偏低，温暖但不鲜艳。
- **光源**: 窗外清晨自然光（色温约6000K），柔和的侧逆光从窗户落在水槽区域；灶火和水壶蒸汽提供暖色点缀。关火后灶台光熄灭，空间冷一度。
- **光比**: 中等光比——晨光提供柔和的包围光，灶火增添局部暖点。关火是关键光变：暖光源消失，空间整体转冷。
- **稳定性**: 固定或极慢推轨。镜头数量少，每镜停留时间长——让沉默和蒸汽承担节奏。

**Scene 3 (夜行列车包厢)**
- **色彩**: 琥珀与深蓝——车内暖色阅读灯光，窗外变幻的冷色城市光和偶尔的暖色路灯。隧道中是单色暖调包裹。出隧道时窗光恢复带来冷色逆光。整体饱和度随光环境变化。
- **光源**: 包厢顶部的暖色阅读灯（约3200K），窗外变动的城市灯光（混合色温）。入隧道时窗外光消失，空间光比变平；出隧道时窗外光恢复，形成逆光轮廓。
- **光比**: 动态光比——入隧道时变平（全空间受暖灯均匀照明），出隧道时恢复纵深（人物成为冷色逆光下的剪影-轮廓）。光变与谈判节拍同步。
- **稳定性**: 固定机位为主，匹配列车的持续微震。镜头随列车晃动产生自然的微妙浮动，但不主动运镜。

**Scene 4 (多层停车楼)**
- **色彩**: 橙钠光与混凝土灰——暖色钠灯和冷色荧光灯在湿润表面上形成冷暖交错。雨夜的深蓝黑色调作为底色。文件袋的棕色是唯一非建筑色。整体饱和度低，高对比。
- **光源**: 停车楼内固定荧光灯（色温约4000K，有频闪感）和少量钠灯（暖橙），雨夜使灯光散射。顶层边缘可能受到外部城市光的微弱影响。地面水迹创造移动的高光。
- **光比**: 斑驳光比——跑过明亮灯管区和暗柱区交替。人物在亮区和暗区之间进出创造追逐节奏。
- **稳定性**: 手持或肩扛摄影，与阿泽的运动同步呼吸。运动中的抖动不掩饰——它是追逐的身体感。顶层停下后镜头也静止，呼吸感转向听觉关注。

## 4. 关键空间拍摄逻辑

### 4.1 审讯室 (Interrogation Room) — Scene 1

**fact: director_choice, scene L3-L14**

- **Spatial layout**: 矩形密闭空间，无窗。一张金属桌居中，两侧各一把椅子。门在林警探身后（暗示权力：他距离出口更近，但在转折后这个距离失去了意义）。墙面为素色或浅灰，可能有单面镜（不强调，仅以微光暗示）。
- **Dimensions**: 约4m x 3m，天花板标准高度2.5m。桌面约1.2m x 0.8m，两人伸手可及。
- **Visual character**: 冷峻、剥离、无装饰。唯一的视觉焦点是桌面上的两个物件——照片和警徽。光源单一（顶灯或桌面灯），使空间上部明亮、边缘沉降到暗部。
- **拍摄逻辑**: 开场用一个双人平视镜头建立空间与人物关系线——林警探在画面左侧（推照片），许然在右侧。用内反拍建立各自的单人世界。许然从内袋取出警徽时，切回双人镜的微调版本（位置不变但权力已变）。最后镜头回到林警探的手从照片上收回——手的运动形成闭合。摄影机不越过关系线，桌面作为两人的"战场"始终位于画面中央下方。

### 4.2 老旧厨房 (Old Kitchen) — Scene 2

**fact: director_choice, scene L15-L27**

- **Spatial layout**: 矩形厨房，水槽靠墙，小餐桌在厨房中央或靠另一面墙。灶台上有水壶。自然光从一侧窗户射入。空间紧凑——餐桌和水槽之间的距离约1.5m，两人隔着一段可跨越的距离但无人跨越。
- **Dimensions**: 约3.5m x 3m，老旧公寓尺度。橱柜表面有年代感，油漆剥落或木纹磨损。
- **Visual character**: 温暖但陈旧。清晨的蓝灰自然光主导，蒸汽增添一层柔软的氛围。桌面空荡——只有信和即将出现的钥匙。信纸已拆开，折痕和可能的泛黄暗示这封信已经反复阅读。
- **拍摄逻辑**: 开场从周岚的视角看水槽和窗户，转身或侧头时展现桌前的父亲。父亲看蒸汽的镜头从周岚的视角拍摄，使观众与她共享"被回避"的感受。钥匙推过桌面的运动需要至少一个桌面的平视镜头——钥匙从画面右侧滑向左侧（周岚侧）。最终镜头：周岚拿走钥匙离开画面，信留在空桌中央——静物般的停留。

### 4.3 夜行列车包厢 (Night Train Compartment) — Scene 3

**fact: director_choice, scene L28-L39**

- **Spatial layout**: 软卧或硬卧包厢改装的面对面座位。窄桌固定在窗侧，两侧各有一排座椅。窗外是夜间城市与郊区的过渡带。包厢门在走廊侧。空间狭窄——两人膝盖几乎相触，增加了密室般的身体压力。
- **Dimensions**: 约2m x 2m内部空间，桌面宽约0.5m。天花板低（约2.1m），增强封闭感。
- **Visual character**: 人造光源下的封闭空间。列车震动是持续的低频存在。隧道是视觉转折——入隧道时窗外光消失，空间变成纯室内灯照明的密室；出隧道时城市光重新涌入，标志着交易的完成。桌面是小世界的中心——存储卡和工作证在上面交换位置。
- **拍摄逻辑**: 开场双人镜包含窗外城市光和包厢内部暖光，建立封闭但仍在移动的空间感。入隧道时，一个顾言的单人镜随窗外光消失而变暗——这是压迫感的视觉化。米娅夹卡不递的镜头需要手部近特写（约在桌面高度），存储卡在两指之间的微小空隙是全场悬念中心。出隧道时，从窗外逆光角度拍双人镜：两人成为光亮背景前的暗色剪影——光恢复，但两人的身份都被隐去（工作证已扣下、存储卡已交出）。最后用俯角拍桌面中央的存储卡和工作证——两个物件并置，完成了交换的视觉陈述。

### 4.4 多层停车楼 (Multi-Level Parking Garage) — Scene 4

**fact: director_choice, scene L40-L47**

- **Spatial layout**: 多层螺旋上升结构。坡道连接各层，每层有混凝土立柱、排水沟和停车位。货车停在转角处——位置关键：它遮挡视线，使追赶者无法看见阿泽俯身滑入文件袋。顶层是开放边缘，无栏杆或只有矮墙，可俯瞰下层和出口。
- **Dimensions**: 每层高度约2.5m，坡道宽约3-4m，可容一辆货车和步行者并行。垂直落差至少4-5层——货车发动声音从下方清晰可闻。
- **Visual character**: 粗粝、实用、迷宫式。混凝土柱和坡道形成强烈的几何线段，重复的结构既是路线也是视觉节奏。雨夜增加反射面——地面水迹反射远处灯光，立柱表面湿润。橙色钠灯或荧光灯管提供斑驳的照明，暗区和亮区交错。
- **拍摄逻辑**: 开场用广角建立坡道和追赶的空间纵深——阿泽在画面远景上跑，追赶者从中景入画。跨排水沟时用跟拍保持阿泽在画面右侧的运动方向。货车转角是关键：摄影机停在转角后方，阿泽跑入画面，俯身将文件袋滑入货车底部——这个动作需要从阿泽的肩后或低角度跟拍才能看见文件袋滑入黑暗的过程。追赶者越过货车时，摄影机留在原位（货车后面），让观众看见追赶者离开而文件袋留在暗处的视觉反讽。阿泽到达顶层时，从阿泽身后向下方拍摄——他的背影在画面左侧，右下方是停车楼的下降空间，引擎声从中传来。最后镜头停留在他静止的背影和雨中的停车楼上。

## 5. 视觉母题与使用边界

每个场景围绕一个或多个物件的传递展开。物件承载信息、权力和决定，是场景的视觉中心。

### 5.1 停车场照片 (Parking Lot Photo) — Scene 1

**fact: script_fact, source L5**

- **Visual**: 5x7英寸彩色照片，轻微模糊，显示夜间停车场的某辆车。纸张有光泽，推过桌面时产生微弱摩擦声。
- **Narrative meaning**: 林警探的武器——一份指控性证据。模糊本身就是信息不对称的视觉化：林警探以为照片是王牌，但它的模糊暗示了不确定性。
- **Use boundary**: 照片不展示正面内容给观众——观众只看到照片背面或林警探的手压在其上一角。观众与许然共享信息：我们也不知道照片的具体内容，只能通过权力交换的结果推断。画面中不依赖照片上的可读文字。

### 5.2 警徽 (Police Badge) — Scene 1

**fact: script_fact, source L9**

- **Visual**: 金色或银色的金属警徽，有磨损但干净。从许然外套内袋取出——内袋位置暗示他对此物的珍视或隐藏。放置在照片旁时产生视觉对比：模糊的纸 vs 清晰的金属，武器 vs 反制。
- **Narrative meaning**: 权力反转的物证。许然不是被审讯者——他掌握了可以毁掉林警探的信息。警徽本身是权威的象征，它出现在错误的人手中，一切都不对了。
- **Use boundary**: 警徽放在照片旁后，成为桌面构图的焦点。拍摄时确保金属反光可读，表明这是真实物体而非道具。不依赖警徽上的可读文字（编号等）。

### 5.3 信 (The Letter) — Scene 2

**fact: script_fact, source L17, L19, L23, L25**

- **Visual**: A4或信纸大小的纸张，已经拆开，折痕明显。可能有些泛黄——信不是新到的。字迹可辨认但不被强调（SD2.0文字不可靠，依赖折痕、纸张质感和人物的对待方式传达其重要性）。信被周岚留在桌上——这是最后的构图：空桌、信、离开的人。
- **Narrative meaning**: 秘密的物理容器。信揭开了母亲仍活着的真相，它是周岚愤怒的来源。周岚的最终动作——拿走钥匙，留下信——说明她选择追寻母亲，而不再依赖父亲给的信息。
- **Use boundary**: 信不展示可读文字。通过纸张质感、折痕的陈旧感、人物对待信的方式（父亲看着蒸汽不敢看信，女儿拿起钥匙却让信留在远处）来传达它的分量。颜色、折痕、泛黄程度和人物对待纸张的手势替代文字成为信息载体。

### 5.4 储物柜钥匙 (Locker Key) — Scene 2

**fact: script_fact, source L21, L23, L25**

- **Visual**: 一把小型金属钥匙，有编号标签或挂绳。老旧，可能有轻微锈迹。被周成从自己那侧桌面推向周岚——推的动作带着终结的意味：我不再说更多，你去找吧。
- **Narrative meaning**: 通往真相的通行证。钥匙指向"她留下的东西"——一个尚未揭开的未来。与信不同，钥匙是可以被拿走的、有明确去处的物件。周岚拿起钥匙是接受了这个任务。
- **Use boundary**: 钥匙在桌上滑行的轨迹和停下的位置是重要视觉——它跨越了父女之间的空间，停在周岚那侧。推钥匙的动作需要从侧面或低角度桌平线拍摄，使桌面空间成为情感距离的物理映射。钥匙的金属质感在推开后成为桌上唯一的硬质闪光点。

### 5.5 存储卡 (Memory Card) — Scene 3

**fact: script_fact, source L32, L34, L38**

- **Visual**: 小型SD或microSD存储卡，黑色，边缘有品牌标识。在两指之间被夹住时，它微小却不可忽视——整个包厢的注意力都集中在这一点塑料和金属上。最终被放在桌面中央——两个人都可以拿到，但它是米娅主动放下的。
- **Narrative meaning**: 证据与筹码。存储卡包含了什么？不重要——重要的是谁持有它、谁需要它。夹在两指之间不递出是全场表演的高峰：保有而不给予。
- **Use boundary**: 存储卡在两指之间的镜头需要近到观众能看见指甲和指纹的尺度。从夹住不递到放在桌面中央的过渡，由列车穿出隧道的城市光恢复来标记。存储卡是微小物体——拍摄时确保足够的画面占比，不让它消失在杂乱的桌面背景中。不依赖存储卡上的标签文字。

### 5.6 工作证 (Work ID) — Scene 3

**fact: script_fact, source L38**

- **Visual**: 标准尺寸的证件卡，有照片、姓名和机构标识。翻面扣下——这个动作意味着照片和姓名被隐藏，身份被主动抹去。扣在桌面上的声音是清脆的塑料碰触声。
- **Narrative meaning**: 身份的交付。顾言翻扣工作证是他在这场谈判中付出的代价——不是物理的，是信任和权力的交换：我交出我的身份，你交出你的证据。
- **Use boundary**: 翻面扣下的动作需要清晰可见——手翻转、证件落到桌上的完整过程。扣下后证件背面朝上，成为一个不可读的承诺。不依赖工作证上的可读文字——观众不需要看到名字，需要看到的是"翻面扣下"这个动作本身。

### 5.7 文件袋 (Document Envelope) — Scene 4

**fact: script_fact, source L42, L44**

- **Visual**: 棕色牛皮纸文件袋，A4尺寸，有一定厚度——里面有内容。可能用绳扣封闭。在阿泽跑动中被紧抱在怀里，受压形成褶皱。滑入货车底部时与水泥地面摩擦产生沙沙声，最终停在轮胎后方暗处。
- **Narrative meaning**: 追逐的动机。文件袋里的内容从未被说明——它是麦高芬。重要的是阿泽愿意为它被追逐，并聪明地把它藏好。文件袋的安全高于阿泽自身的安全。
- **Use boundary**: 文件袋滑入货车底部的动作是场景的核心节拍。从阿泽俯身、手臂伸展、文件袋贴地滑行到停住——这个时间需要足够长，让观众理解这个战术：阿泽牺牲了自己的逃跑速度来确保文件袋不会被截获。文件袋是哑光表面，在暗处几乎不可见——这正是它的保护色。不依赖文件袋上的可读标记。
