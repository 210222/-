当前 R1.4 不是规格要求的“真实 Golden 结构 runner”。它能用 canonical
SHA-256 拒绝任意字节变化，但大量结构变异只触发 `*_HASH_MISMATCH`，负责该问题的
`format/timing/cuts/responsibilities/forbidden_routes/homology` 仍返回 `True`。
因此当前实现更接近“精确文件校验器”，不是可以解释结构偏差的“结构验证器”。

控制器当前仍报告 `audit: 0 issues`、`completed_tasks` 包含 R1.4、
`next_task: R2.1`。这是控制状态内部自洽，不是 R1.4 质量真实通过。R1.4 注册命令
只执行 worker 可修改的测试文件，锁定外部门控没有被 controller 执行或绑定。

## 6. 根因树

### RC-1：全局 SHA 掩盖分类器空洞

`_validate_integrity()` 能拒绝 artifact 字节变化，因此 `all_valid=False`。但
R1.4 规格要求六类 category 分别解释结构问题。当前 worker mutation 多数只断言
`all_valid` 或 `HASH_MISMATCH`，使 category 没有实际覆盖也能“全绿”。

相关位置：

- `structural_runner.py:963-1008`
- `test_v8_3_structural_runner.py:615-633`

### RC-2：expectation 丢失 R1.3 权威拓扑

`CaseExpectation` 只有粗粒度 count、cut times、duties、section、artifact hash，
没有：

- R1.3 `contract_fingerprint`；
- `semantic_sources_sha256`；
- segment identity；
- 每节点 ID/kind/temporal kind/start/end/phase/shot/camera；
- upload ID→target；
- Storyboard refs；
- HOLD/audio/transition 拓扑；
- 关键 semantic anchor fingerprints。

R1.3 已提供完整 `DualOutputContract` 和 `FrozenNode` 权威字段：
`storyboard_projection.py:48-146`。R1.4 没有消费这些 authority。

## 7. 已排除的替代解释

### H1：测试环境或编码损坏

排除。正常 worker、两代 R1.3 门、V5、baseline、registry、compileall 全绿。

### H2：R1.3 artifact 已漂移

排除。controller audit 验证 R1.3 已绑定的 16 个 artifact hash，全无 drift；
R1.3 external 27/27。

### H3：只要全局 hash 能拒绝就足够

排除。R1.4 规格明确要求六个 category 实际计算，并用于解释未来非 Golden 输出；
hash 只能证明字节不等，不能说明错误属于时间、切点、职责还是同源关系。

### H4：只是枪管 HOLD 的个案

排除。四组相同的 segment/ref/phase/shot/motion/description/section 变异均复现。

### H5：controller audit 0 等于任务质量通过

排除。audit 只检查 state/evidence/已申报 artifact 的一致性；不会重跑任务命令，
也没有 R1.4 锁定 gate 绑定。

## 9. 必须采用的修复顺序

### 阶段 A：控制面重新绑定

不能仅失效 R1.4 后继续修 parser。否则修复完成后 controller 仍然可以再次假绿。

控制面必须新增：

1. task registry 的 `locked_verification_inputs`；
2. claim/complete 时校验锁定 gate SHA；
3. machine state 记录 `verification_input_hashes`；
4. audit 持续检查锁定输入 drift；
5. R1.4 registry 直接执行 worker、第一锁定门和深层锁定门；
6. claim 前 workspace manifest 与 complete 时实际 delta；
7. actual delta 必须全部包含在 Evidence declared paths 中，且全部匹配 allowed
   paths；declared 允许额外列出需重新绑定但本轮未改变的 artifact；
8. cache、state、lock、Evidence 等确定性排除规则；
9. 行为测试证明未申报/越界改动阻止 complete。

由于 registry 和 controller 是 R0.1 已绑定 artifact，必须使用正式反向失效和顺序
重验证，不能直接编辑造成 audit drift。

### 阶段 B：R1.4 结构 runner 修复

1. 构建 strict artifact AST；
2. 未知/无法解析/空 section 失败；
3. expectation 固定 R1.3 contract/source fingerprints；
4. 固定完整 ExpectedNode topology；
5. VP per-second panel coverage；
6. interval/HOLD/audio/transition bounds；
7. Boundary ID/kind/time/order；
8. upload ID→target→duty；
9. Storyboard refs 与 Video refs；
10. 禁止项正向泄漏检测；
11. segment、phase、shot、motion、description、handoff、transition 同源；
12. 公开 expectation fingerprint 与 computed/authority 三方一致；
13. 每个 category 独立失败，不得只依赖 integrity。
