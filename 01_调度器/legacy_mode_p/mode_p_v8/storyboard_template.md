# 故事板提示词模板

> 架构设计基于: 导演手册视觉叙事原则 + SD2.0正向描述铁律 + 逐镜逐秒精确控制

## 模板

```

空间: [从空间地图提取·房间/室外·关键特征]
人物: [角色名: 关键外貌特征2-3条·每行一个]
情绪弧线: [开头→中段→结尾的情绪变化·一句话]

[0s] [画面内可见物的精确描述·正向语言]
```

## 设计原则

### 画面描述
- 只描述画面内可见的: 人的动作·物体的位置·光的变化·空间的呈现
- 正向语言: 说"画面稳定"·不说"不要抖动"
- 精确: 说"上唇与下唇间距约5mm"·不说"嘴微微张开"
- 不描述: 情绪(悲伤/愤怒)·内心活动(他在想)·文学比喻(像幽灵一样)·摄像机(推/拉/摇属于运镜段·不在画面段)

### 运镜指示
- 类型+速度(S0-S8)+轨迹+起止状态
- 静态也是决策: "固定·S0·三脚架锁定"
- 速度匹配空间: <2m空间只用S0-S3

### 构图指示
- 景别+角度+视觉重心+深度分层
- 视觉重心明确: "Isabela在右1/3交点·视线向左·留2/3呼吸空间"

### 光影指示
- 主光源位置+类型+色温K+光比
- 光源锚定: "窗光·6500K·主光源来自空间地图标注的东侧落地窗"

### 转场指示
- 入点和出点各注明类型
- 匹配剪辑需注明视觉锚点: "镜1→2: 匹配剪辑·锚点: Isabela右手入画→镜2右手手枪特写"
