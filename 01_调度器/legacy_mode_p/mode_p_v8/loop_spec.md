# MODE:P v8.0 — 重构规范

> 本文件是 loop 重构程序的蓝图。每次迭代对照此规范检查进度。

---

## 目标架构

```
剧本 → [导演Agent] → 场景设计(含故事板+视频提示词)
                         ↓
                    [DP Agent] → 自然语言反馈
                         ↓
                    导演修改 → DP再审 → ... → DP:"没问题" → 交付
```

**只有两个Agent。只有两个产出文件。没有其他任何东西。**

---

## 文件清单 & 完成标准

### P0: director_loop.md — 循环调度器
**职责**: 编排导演↔DP的对话循环
**内容**:
- 循环逻辑: 导演出稿 → DP反馈 → 导演修改 → DP再审 → 交付
- 不包含: max_rounds·block_count·F1-F7·收敛算法·Agent调用声明格式
- 循环控制: DP说"没问题"就交付。DP有问题导演就改。自然结束。
**完成标准**: 文件中无任何算法伪代码·无计数变量·无路由表·无声明模板

### P1: director_agent.md — 导演
**职责**: 读剧本 → 设计场景 → 产出故事板提示词+视频提示词
**知识**: system prompt嵌入 `03_知识库/导演手册_视觉叙事决策框架.md`
**思考方式**: 原则驱动的直觉。看到双人对话→本能地想外反拍接内反拍。看到试探→本能地想把镜头推得更近。不是查规则。
**输出**: 一个完整文档，包含:
  - A部分: 故事板提示词
  - B部分: 视频提示词
**不包含**: YAML格式约束·技术决策摘要表·KB规则ID引用·结构化字段要求
**完成标准**: 文件中无"输出格式"的YAML/JSON示例·无字段列表·无"每镜必须包含X项"的检查清单

### P2: dp_agent.md — 摄影指导
**职责**: 读导演的场景设计 → 给自然语言反馈
**知识**: system prompt嵌入 `03_知识库/导演手册_视觉叙事决策框架.md`
**思考框架**(内化在system prompt中·不作为输出格式):
  - 空间可行性: 机位穿墙？运镜越界？光源有锚点？
  - 视觉连续性: 关系线同侧？动作方向一致？视线匹配？
  - 运镜审查: 运动有动机？速度匹配空间？起止稳定？
  - 构图审查: 景别合适？视觉重心清晰？深度分层成立？
  - 光影审查: 光源锚定？色温匹配情绪？光比连贯？
  - SD2.0兼容: 正向描述？≤15秒？多人面部≤2？
**输出**: 自然语言。例如:
  "镜3的推进轨迹会被桌子挡住——房间实际深度只有2米。镜5的主光源方向在参考图里找不到锚点。镜2→3的动作方向反了。其他没问题。"
**不包含**: 结构化审查报告(blocks/warnings/suggestions)·block_count·YAML输出·severity字段·六个维度的分类标题
**完成标准**: 文件中无YAML/JSON输出模板·无block_count·无severity枚举·无分类表

### P3: 故事板提示词模板
**架构设计原则**:
  1. 场景级上下文在前: 空间·人物·情绪弧线·视觉基调
  2. 逐镜展开: 每镜=画面描述+运镜指示+构图指示+光影指示+转场指示
  3. 画面描述: 逐秒·仅画面内可见物·正向语言·无否定词·无情绪标签·无文学修饰
  4. 格式简洁: 人能读懂·SD2.0能解析·无元数据·无审计信息
**参考**: `EP2_storyboard_auto.md` 的黑白线稿故事板格式(取其逐镜结构·去其Seko特定格式)
**完成标准**: 模板中无Seko格式·无@图片引用·无KB规则ID·无禁止清单·无元数据声明

### P4: 视频提示词模板

## 架构铁律（任何文件不得违反）

1. **KB内化**: Agent的system prompt嵌入导演手册。Agent不读KB文件·不引用规则ID·不做合规检查。
2. **只有两个Agent**: 导演(创作) + DP(审查)。无运镜/构图/光影/切换独立Agent。
3. **只有两个产出**: 故事板提示词 + 视频提示词。无审计报告·无YAML·无Gate 0报告。
4. **循环是自然的**: DP说"没问题"就交付。DP有问题导演就改。无收敛算法。
5. **SD2.0约束内化**: 导演本能地用正向语言·不用否定词·不写情绪标签。DP自然地指出"这里有个'不要'"。
6. **所有输出是自然语言**: 人能读懂的导演台本。不输出YAML/JSON/表格给下游Agent消费。
