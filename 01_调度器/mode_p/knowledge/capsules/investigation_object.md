# 调查、证据与物体揭示

## 适用信号
场景以发现、检查或揭示特定物体为核心戏剧动作。人物通过手、视线和身体姿态与物体互动。

## 核心问题
物体是什么状态？发现过程分几个阶段？观众在哪个时刻获得哪个信息？手、眼、物之间的空间关系如何建立？

## 可用手段
- 手部特写 + 物体状态的近距离展示。
- 人物视线引导 → 切到被看物体。
- 焦点在人物面部反应和物体细节之间切换。
- 层层推进的揭示：整体环境 → 物体位置 → 物体细节 → 关键证据特写。
- 从遮挡到暴露：先遮挡物体让观众好奇，再揭示满足期待。

## 变化路径
- 从环境建立到聚焦物体的景别渐进收紧。
- 调查发现前后的光线变化（增加局部高光或对比度）。
- 手部动作速度变化：缓慢检查表达仔细，快速操作表达紧迫。

## 空间条件
- 物体必须与人物手部在同一焦平面或可清晰切换。
- 物理光源应从观察者方向打向物体，使细节可见。
- 如果证据是平面文件（信件、照片），需考虑 SD2.0 文字限制。

## SD2.0 适配
- 手与物体的接触关系容易暴露形体或连续性错误；动作阶段、握持方式和物体朝向要清楚，必要时使用参考。
- 关键剧情信息不只依赖生成的可读文字；同时用颜色、形状、血迹、折痕、人物反应或声音提供可辨认线索。
- 单一焦点物体 + 简化背景降低复杂度。
- 避免复杂的反射表面或透明物体，除非使用全能参考素材严格控制。

## 常见失败
- 物体太小或与背景融为一体，观众看不清。
- 焦点在人物和物体之间跳转时不稳定。
- 让剧情理解完全依赖生成信件或屏幕文字的准确性。
- 揭示过程太短（少于一秒），观众来不及注册信息。

## 对比示例
弱：一个全景镜头中 Detective 拿起桌上的文件"检查"。
强：全景建立桌面 → 手部特写打开文件夹 → 手指沿一行文字滑动 → 切到 Detective 抬眼的反应 → 回到手部，红色血迹从文件夹边缘渗出。
