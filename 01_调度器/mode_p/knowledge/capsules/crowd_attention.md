# 多人对话与注意力交接

## 适用信号
场景中有三个或以上人物同时在场，存在对话交替、权力转移或注意力焦点切换。

## 核心问题
在多人物场景中，观众的注意力应该如何被引导？谁在说话、谁在听、谁的反应更重要？清晰面孔越多，身份与注意力稳定风险越高，但不存在固定的“两张脸平台硬上限”。

## 可用手段
- 发言者 + 主要听众的双人景别组合。
- 过肩镜头建立空间关系后转到单人反应。
- 群体全景建立层次，然后单人/双人中景传达关系变化。
- 注意力通过视线、身体朝向和景别变化来交接。
- 反应链：A 发言 → B 反应 → C 观察 B 的反应。

## 变化路径
- 发言权转移时改变机位或景别。
- 群体共识形成时收紧景别（从全景到中景到特写）。
- 权力分散到集中时减少镜头内的有效面孔数量。

## 空间条件
- 需要明确的关系线和摄影可用区域，使群体朝向和视线方向一致。
- 多人场景先建立关系线；人物或摄影机改变关系时，用中性机位、可见运动或新建立镜头重新说明空间。
- 当面孔、动作和对白同时竞争时，可通过层次、遮挡、景深或拆镜降低当前镜头需要清楚辨认的主体数量。

## SD2.0 适配
- 优先让当前发言者、行动者或关键反应者清晰可读，其余人物可作为空间和关系层。
- 三人以上并非必须拆镜；当身份、动作或视线开始漂移时，再用单人/双人镜头接力注意力。
- 远景建立群体存在感，中近景具体化关系，特写强调关键反应。
- 模糊、剪影或背影可以暗示第三人的存在，不要求 SD2.0 解析五官。

## 常见失败
- 一个镜头让过多人物同时承担身份、动作与表情信息，导致主体漂移。
- 注意力引导混乱：观众不知道该看谁。
- 群体镜头中人物变成不可辨认的模糊色块。
- 反应链中断：某角色的关键反应被遗漏。

## 对比示例
弱：五人围坐会议桌，单镜头正面全景。
强：全景建立空间 → 发言者中景 → 主要对手双人中景 → 关键第三者单人反应特写。
