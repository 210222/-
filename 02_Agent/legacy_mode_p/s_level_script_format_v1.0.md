## §2 S-Level vs C/M-Level 关键差异

| 差异项 | C/M-Level | S-Level |
|--------|----------|---------|
| 产出者 | Prompt Composer独立Agent | Scene Designer直接 |
| 【设计依据】块 | 有 | **无** |
| 空间描述 | 每镜可重复 | **只写一次(C2)** |
| 运镜论证 | 每镜展开 | **静态快速通道一句话** |
| PLAN TIME_SKELETON | 独立文件 | **无** |
| 对白 | 通过PLAN | **直接嵌入音轨** |
| 总输出 | ~800-1500行 | **≤600行** |
| Auditor路径 | Phase 0→1→2→3 | **跳过Phase 1·Phase 2降级** |

## §3 Gate 0 兼容性

使用与标准台本**完全相同**的块头标记:
- 【场景级共享锚点】【镜头参数卡】【生成指令】【禁止】【段末转场设计】【音轨】【传入参考图】
- Gate 0 R01-R15无修改扫描·R08块头匹配规则不变
