- 无抒情性转场需求(本场景不含时间跳跃/回忆/梦境)

**建议:** 保持当前设计。全硬切在悬疑短片(≤40秒)中是标准手法。在故事板阶段确认硬切的视觉连续性(相邻镜的色调/构图衔接)不出跳跃感。

## 设计亮点 (非裁决项·观察记录)

1. **三重色温系统 (3500K/4500K/5500K):** 车内暖金(秘密空间)→巷口暖亮(外部威胁)→巷内冷灰(观察者空间)形成色温叙事层。每个空间有独立色温标识，且全部有物理锚点。设计严密。

2. **Pedro低角度约束 (0.3m~1.2m):** 全程限制在儿童眼高以下。最低30cm(追球起幅·地面视角)、最高1.2m(Pedro站立眼高)。低角度系统性地承载了"儿童视角+脆弱性"的叙事功能。

3. **巷道物理约束的运镜解:** 巷宽<2m完全禁横移/环绕 → 100%纵向运动(前跟拍+极慢前推)，无妥协设计。零横移不是"避免使用"而是"物理不可能"——空间约束被转化为美学特征(巷道纵深成为天然推轨)。

4. **遮蔽POV的信息控制 (镜#4):** >30%画面被桶沿遮挡·配合f/2.8浅景深 —— 观众与Pedro共享"看不清"的焦虑。这是C-AJS-03(小窗口法)与C-FI2-NS-27(前景遮挡+负空间)的教科书级实施。

5. **球影替代法 (镜#5):** Rico的POV扫描最终停在足球的影子上而非足球本身 —— 用影子作为"Pedro存在的痕迹"，同时制造"Rico是否意识到有人"的悬念。这是C-FI-06(剪影轮廓)在叙事层的升维应用。

6. **情绪-运镜反差的正当化:** 5/7镜情绪值≥2但运镜=S0(固定)。Movement Designer为每一个"反差"提供了清晰的例外理由(信息密集/空间受限/情感沉浸)，而非简单声明"悬疑需要静止"。
