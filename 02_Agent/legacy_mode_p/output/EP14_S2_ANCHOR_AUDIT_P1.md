## 2. 跨场景连续性评估

### 2.1 场景关系判定

```
场景A: 内景 圣保罗刑警总部·案情室（日·早晨/上午）
场景B: 外景 山丘贫民窟·巷道（午后）+ 轿车内

空间关系: 不同空间
  - 场景A: 全封闭室内·人工照明·制度空间
  - 场景B: 露天窄巷+轿车内·自然光+侧逆光·城市底层空间
  - 无任何物理连接（门/走廊/楼梯/街道不直接连通）

时间关系: 时间跳跃
  - 场景A: 日间·早晨/上午（Miguel离开时）
  - 场景B: 午后
  - 时间跳跃: 数小时（上午→午后）
  - 叙事: 双线平行——Miguel调查线（场景A）+ Rico行动线（场景B）·时间重叠但地点独立

人物关系: 无同角色跨场景
  - Miguel: 场景A离开→去Rico工作室（不在场景B）
  - Rico: 场景A=照片+名字（信息存在）→ 场景B=真人在车内行动（物理存在）
  - Pedro: 仅场景B·全新引入
  - Vincent: 仅场景A·不出现在场景B
  - 司机(金丝眼镜): 仅场景B·全新引入

场景关系类型: 不同空间·时间跳跃（独立场景切换）
```

### 2.2 独立场景切换风险点评估

```
风险点1 — 快照格式不完整 vs 低继承需求:
  由于场景A→B为独立场景切换:
    - 无角色需从场景A继承到场景B（Miguel不在B·Rico从照片变真人）
    - 无道具需跨场景追踪（场景A道具全在案情室·场景B道具全在巷道/车内）
    - 无空间状态需继承（物理空间完全不同）
    - 时间跳跃为合理叙事·需确认标注是否清晰
  
  → 快照格式不完整的实际影响: 低
  → 但格式问题仍需记录（影响后续连续空间场景的审计）

风险点2 — 时间跳跃标注:
  场景A结尾: "日间" / 场景B开头: "午后"
  剧本中场景B标题明确标注"(午后)" → ✅ 时间标注存在
  跳越幅度: 约3-5小时（上午→午后）→ ✅ 叙事合理
  快照中未记录精确时间 → ⚠️ 不利于精确时间跳跃审计

风险点3 — 空间跳转无过渡:
  剧本为直接硬切（场景A→场景B）:
    "△ Miguel停了一下。门框挡住了他的脸。"
    "CV Miguel：我只是去——'叙旧'。"
    ↓ 直接切到 ↓
    "场景：外景 山丘贫民窟·巷道（午后）"
  
  这是标准的平行剪辑/场景切换 —— 无需过渡描述 → ✅
  但需确认场景B的叙事独立性

风险点4 — Rico从"照片"到"真人"的视觉锚点衔接:
  这是本场景过渡中唯一的"隐形锚点"问题

裁决: ⚠️ 独立场景切换风险可控·主要关注点仅Rico视觉锚点衔接
```
