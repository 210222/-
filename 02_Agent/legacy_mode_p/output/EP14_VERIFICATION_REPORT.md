### 1.4 与"典型判定"的矛盾分析

complexity_router §2.4 中EP14场景A的示范走查声明F5=false、判定S-Level。但实际产出的导演台本中，镜#A2明确标注"极慢前推(0.05x)·直线·沿光轴·垂直于白板表面·匀速·行程约20cm·4秒"——这是明确的动态运镜。两种解释:

| 解释 | F5值 | 合理性 |
|------|:--:|------|
| MODE:A方向卡原始标注为"固定"·Movement Designer后续自行添加了推近（设计Agent越权） | false | F5应从MODE:A方向卡提取·设计Agent不应违反方向卡运镜意图。如果方向卡说"固定"而Movement Designer改为"推近"，这是Movement Designer的越权行为。S-Level正确。 |
| MODE:A方向卡原始标注含"推近"意图 | true | M-Level正确。场景属于M-Level中等复杂度·应使用4-7 Agent管道而非2 Agent。 |

**裁决:** 取决于MODE:A方向卡中镜#A2的实际运镜标注。如果方向卡标注为"固定"，则是Movement Designer越权添加了推近——此时场景本质仍是S-Level，推近是冗余设计。如果方向卡原本含推近，则是M-Level。建议以MODE:A方向卡为准做最终裁决。

出于保守原则（复杂度路由"不确定降级"规则），本报告后续分析按两种路径并行展开：**路径S（假设方向卡为固定·S-Level）** 和**路径M（假设方向卡含推近·M-Level）**。
