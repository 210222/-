## §C 空间地图摘要

### 场景1 · 圣保罗刑警总部·案情室 (内景·日)

| 维度 | 描述 |
|------|------|
| 空间类型 | 现代极简办公/案件分析室，封闭内景无窗 |
| 尺寸估算 | 约 6m(宽) × 5m(深) × 2.8m(高)，中小型会议室/分析室 |
| 可放置区域 | 白板前1-2m (主表演区)、合并办公桌后 (坐姿工作区)、门口 (进出通报区)、角落电脑位 (次要人物区) |
| 禁入区 | 白板至墙面之间（间距过窄无法站人）、桌子与白板之间若要求正面构图则不宜遮挡白板线索 |
| 关键锚点 | **白板线索墙**: 5名死者照片+红线+酒店平面图(201红圈)+弹道报告——画面视觉重心；**合并办公桌**: 笔记本电脑+卷宗+笔记本+签字笔+咖啡杯——工作状态物证；**红色图钉+红线**: 逻辑连接符号，与整体冷灰调形成强反差 |

### 场景2 · 山丘贫民窟·巷道 (外景·午后)

| 维度 | 描述 |
|------|------|
| 空间类型 | 圣保罗贫民窟内部窄巷，两侧砖墙夹道，头顶电线交错，碎石地面 |
| 尺寸估算 | 巷长约20m，宽度不足2m，形成极强的纵向压缩透视 |
| 可放置区域 | 巷口外部道路 (轿车驶入、Pedro追球)、巷中段垃圾桶后 (Pedro躲藏位)、巷中段车道 (轿车停靠位Rico)、巷尾另一端出口 (备用路径)、墙根/排水管旁 (次要躲藏) |
| 禁入区 | 巷道宽度仅<2m，车辆占据后两侧仅余极窄缝隙，人物无法从侧面正常通过车辆 |
| 关键锚点 | **垃圾桶**: Pedro的躲藏遮蔽物，决定他能否看到车内交易、能否被发现；**巷口/巷尾双光源**: 形成自然明暗渐变，巷口明亮区=外界/未知的隐喻；**头顶电线网格**: 空间"笼感"的视觉符号 |

#### 轿车内部空间 (场景2子空间)

| 维度 | 描述 |
|------|------|
| 空间类型 | 老旧黑色轿车内部，皮面皲裂、仪表台积尘、挡风玻璃覆沙——年代久远+疏于打理 |
| 可用座位 | 驾驶座(金丝眼镜男)、副驾驶座(Rico)、后排(空，可作摄影机位或扩展角色) |
| 人物位置关系 | 驾驶与副驾驶并排，距离约0.6-0.8m——适合近距离秘密交接（信封+手机） |
| 关键锚点 | **副驾驶车窗**: Pedro透过此窗看到Rico——信息传递的关键界面；**后视镜**: 可同时反射前排+后排+车后街景，增加空间纵深；**磨损细节**: 方向盘/座椅皮面皲裂、仪表台灰尘——无声交代阶层与年代 |
| 光影特征 | 侧逆光从驾驶座左侧射入，暖金色+深黑高反差，明暗交界线清晰，胶片质感 |
