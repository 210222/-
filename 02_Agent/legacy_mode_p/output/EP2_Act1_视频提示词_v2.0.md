4s  摄影机以极慢速度向右摇摄。POV扫过工作台面——枪管哑光、弹簧暗银、螺丝散布。金属表面在2800K暖黄下呈现暖金反光。工具架——扳手、螺丝刀、油壶。摇摄速度匹配审视节奏。

5s  摇摄短暂停住。视线落在扳机的一道细微划痕上——金属表面的浅线，光线在划痕边缘形成微细高光。停0.5秒。

6s  摄影机以慢速继续向右摇摄，速度微增。POV离开工作台最亮区域，画面变暗。移向房间右边的洗手池区域。在半明半暗中，一块白色织物进入视线边缘。

7s  摇摄落定。特写。视线停在洗手池边——灰色毛巾搭在池子边缘，自然下垂。毛巾中央一片暗红血迹，手掌大小。血迹中心深红发黑，边缘变成浅红褐色。毛巾灰色棉质纹理清晰。毛巾后的洗手池和墙壁虚化——聚焦在毛巾上。

10s 甩镜。摄影机急速右转——半秒内画面里所有东西变成水平模糊条纹。门板、手、墙壁被拉成横线。走廊冷白4000K和门缝暖黄2800K在甩镜中混合成暖冷光带。持续0.5秒——模拟听到脚步声后骤然转头140至160度的生理反应。

    ——对应故事板格13

11s 走廊从近到远延伸——上半墙白色，下半墙灰色，远处有扇关着的门。走廊空无一人。头顶日光灯微微闪烁，发出细微嗡嗡声。
    ——对应故事板格14

12s 脚步声停了——到达了某处，但画面里始终没有人出现。她从头到尾没有发出任何声音。保持凝视，面部僵持。
    ——对应故事板格15
