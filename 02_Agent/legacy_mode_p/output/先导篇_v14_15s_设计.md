## §B 故事板

```

镜3: 水洼·踏步 (0.6s) @Rico
格1.75s ECU·24mm·固定·地面高度。一只黑色军靴踏进水洼——水花向四周炸开·每滴水中反射着不知来源的橙色光。靴子抬起——第二只靴子踏进·水花更高。摄像机贴在地面——靴底的花纹·水洼中的倒影:Rico的身影·枪口向下·正在前进。步幅稳定·不疾不徐。
  🔴→ 军靴踏入→抬起→第二只踏入·水花逐次炸开 🟢地面高度·靴子从画面上方踏入·水洼占满画面 🟠水花反射枪口焰橙·闪电白·警灯红蓝 ⚫t=1.75s

镜4: Isabela·封锁线 (0.5s) @Isabela
格2.2s CU·85mm·固定。Isabela站在警察封锁线后面。雨水沿她的棕长卷发滴落·头发贴在额角和面颊上。绿眼睛——不是在看对峙·是已经看到了结局。嘴角微向下。她没有喊。没有哭。只是在看。身后警灯红蓝旋转·把她的轮廓切成红色和蓝色交替的剪影。一个警察试图拉她后退·她甩开了那只手。
  🔴→ 静止·雨水滴落·警察拉她·她甩开手 🟢面部居中·背后警灯·封锁线黄色横贯画面下方 🟠警灯红蓝交替在她脸上·雨水反光·闪电白 ⚫t=2.2s

镜5: 子弹·消防栓 (0.7s) @Rico
格2.75s CU·50mm·慢动作。Rico的子弹击中街边的红色消防栓。慢动作:弹头穿透铸铁——铁皮向内凹陷→裂纹扩散→炸开。水柱喷涌而出——在慢动作中水柱像白色的固体·从消防栓顶部向上喷发·然后被重力拉弯·散成水雾。水柱在闪电中变成纯白柱体·在警灯中变成红蓝交替的喷泉。Rico的身影从水柱后方走过——他的轮廓被水柱折射扭曲。
  🔴→ 子弹击中·铸铁炸裂·水柱喷涌·Rico身影从后走过 🟢消防栓画左·水柱垂直向上→弯散·Rico画右后景 🟠闪电白·水柱透明·警灯红蓝在水雾中 ⚫t=2.75s

镜6: Miguel·换弹 (0.6s) @Miguel
格3.3s ECU·85mm·固定。Miguel的手——空弹匣从警用配枪中坠落·弹匣在雨中翻转·砸在水洼里·溅起泥水。新手掌拍入新弹匣——"咔嗒"——套筒复位。手指回到扳机护圈——湿的·沾着血(他自己的还是别人的·不可辨)。食指搭在扳机上。雨水从指关节滴落。手指收紧。
  🔴→ 弹匣坠落·新弹匣拍入·套筒复位·手指回扳机 🟢双手居中·枪垂直·弹匣下方水洼可见 🟠闪电白·金属冷反光·手指血痕红 ⚫t=3.3s

镜7: 瞄具·十字 (0.8s) @Miguel @Rico
格3.9s ECU·135mm·固定。⚠️从Miguel的瞄准具看向Rico。准星和照门——三点一线——背景中·Rico站在50米外·正在举枪。准星切口中的Rico很小·但清晰:他在雨中·枪口正对回来。准星在晃动——不是手抖·是Miguel的呼吸。准星稳定——Rico被锁定在准星缺口中央。然后Rico的枪口焰炸开——在准星中·一束白光吞没了Rico的轮廓。Miguel的准星跳了一下。
  🔵→ 准星微晃→稳定→枪口焰炸开·准星跳动 🟢准星和照门在前景·Rico在远景·三点一线 🟠闪电白·枪口焰在准星中放大·Rico冷蓝剪影 ⚫t=3.9s

镜8: Isabela·张嘴 (0.4s) @Isabela
格4.35s ECU·85mm·固定。Isabela的嘴——张开——在喊。但没有声音。镜头极近:下唇在颤抖·雨水从唇边流入嘴角·牙齿可见·舌头在口腔中——她在喊一个名字。Rico。或者Miguel。或者是"不要"。口型只做了一半——时间停在这里。她的眼睛在画面上方·刚刚被切掉。
  🔴→ 嘴张开·下唇颤抖·雨水流入·无声 🟢嘴占满画面·鼻尖在画面上方边缘 🟠冷蓝雨水·嘴唇血色正在退去 ⚫t=4.35s

镜9: 对峙·双枪 (1.5s) @Miguel @Rico
格5.25s WS→MS·35mm·固定。闪电——保利斯塔大街·暴雨。Miguel画左·Rico画右·20米·不是50米·更近了。两人都在移动——Miguel从轿车掩体后走出·Rico从消防栓的水柱旁走出。两人同时举枪。枪口相向。雨丝在他们之间密集。水柱在画左喷涌·Miguel的轿车车窗全部碎裂·玻璃渣在雨中闪光。闪电再次——这次能看到:Rico的衬衫胸口有一个深色的湿痕·雨水在湿痕周围形成更深的颜色。是汗·还是血——不确定。Miguel的左臂·夹克袖子撕开了一道口子·也是湿的。两人之间——20米·雨·水柱·玻璃渣·弹壳。枪口对准彼此。
```
