## 1. 策略匹配精度分析

### 1.1 10个策略的"语义描述→参数映射"差距

量化每个策略的语义信息损失率（0% = 语义完全表达, 100% = 参数丢失所有语义）:

| # | 策略 | 语义描述 | 参数映射 | 信息损失 | 关键丢失 |
|---|------|---------|---------|:-------:|---------|
| 1 | 感官剥夺 | 极窄景别·浅景深·观众只看到细节·**与角色共享视角局限** | 大特写/100mm/f1.4/侧光 | 25% | "共享视角局限"作为POV连接的意图没有参数表达 |
| 2 | 标准对话三角形 | **标准三角形机位**·外反拍+内反拍·**观众客观观察** | 中景/35mm/f5.6/眼平 | 35% | 三角形几何约束未参数化; 外反拍/内反拍选择规则丢失; OTS规格缺失 |
| 3 | 冷暖色温交界 | 两个空间在**交界处碰撞**·**冷暖光同时可见** | 中景/35mm/双色温(无坐标) | 50% | "交界位置"是构图核心但零坐标; 色温差值未参数化 |
| 4 | 非人化→常化 | 从底光非人化**过渡**到眼平常化 | 近景/50mm/底光过渡(无时序) | 40% | "过渡"是核心行为但参数无时间维度; 过渡easing/时长未定义 |
| 5 | 空间建立 | 展示全貌·建立空间坐标系 | 全景/24mm/深景深f/8-11 | 15% | 较高一致 |
| 6 | 证据/屏幕展示 | **观众看到角色正在看的东西** | 特写/35mm或85mm/二选一景深 | 45% | 屏幕vs实物二选一在参数中模糊; POV连接意图丢失 |
| 7 | 沉默中的情绪转折 | 角色**什么都没说**·但观众知道**有什么变了** | 近→特/50→85mm/极慢推近0.03-0.05x | 55% | "沉默"不能通过"极慢推近"表达; 推近时机(何时开始/停止)才是关键 |
| 8 | 运动/动作中的揭示 | 通过**运动**来**揭示**新信息或空间关系 | 中景→中全景/24-35mm/摇臂/跟拍 | 60% | 运动路径和揭示时机是核心但完全空白; 摇臂vs横移vs跟拍选择规则缺失 |
| 9 | 人物出场/退场 | 角色**进入**或**离开**空间·**注意力转移** | 全景/24mm/深景深/眼平 | 50% | 出场和退场参数完全相同; "注意力转移"的视觉引导缺失 |
| 10 | 空镜收尾 | 人物离去后的空间·证据或光线**替代表演**·观众自行消化 | 全景/24mm/单向光 | 35% | "替代表演"的意图没有参数化——现公式只是"全景+暗" |

**平均信息损失率: 41%** — 语义描述和参数映射之间有显著鸿沟。

### 1.2 参数去重分析: 10个策略还是7个参数簇?

检查default_params中实际不同的组合:

```
参数簇A: 全景/24mm/深景深/眼平/固定 ← 空间建立, 人物出场/退场, 空镜收尾 (3策略共用)
参数簇B: 中景/35mm/f5.6/眼平/固定     ← 标准对话三角形, 冷暖色温交界 (2策略共用)
参数簇C: ECU/100mm/极浅/侧光/固定~慢推 ← 感官剥夺
参数簇D: 近景/50mm/中浅/底光过渡        ← 非人化→常化
参数簇E: 特写/35或85mm/深或浅/正面     ← 证据/屏幕展示
参数簇F: 近→特/50→85mm/浅/极慢推     ← 沉默中的情绪转折 (LLM)
参数簇G: 中→中全/24-35mm/中/动态      ← 运动/动作中的揭示 (LLM)
```

**10策略 → 7参数簇** (复策略占3个, 真实参数多样性仅70%).
其中2个LLM簇(F, G)的默认参数无实际意义——LLM必须重新设计全部参数。

即有意义的"确定性参数映射"只有5个参数簇覆盖8个策略, 占策略数的60%。

### 1.3 tuning_params覆盖缺口

tuning_params描述了什么条件下调整什么参数。检查覆盖率:

| 策略 | tuning_params | 场景变异是否覆盖 |
|------|:------------|:---------------:|
| 感官剥夺 | 对象尺寸→焦距, 景深→f值 | ⚠️ 半覆盖: 背景距离/镜头物距未覆盖 |
| 标准对话三角形 | 角色间距→景别, 情绪强度→焦距(50mm更压迫) | ✅ 较好 |
| 冷暖色温交界 | 交界位置→构图, 色温差值→对比强度 | ⚠️ 缺少色温绝对值锚定 |
| 非人化→常化 | 过渡时长→镜头长度, 非人化程度→底光角度 | ⚠️ 缺少过渡easing/角色面部转度 |
| 空间建立 | 空间大小→焦距微调, 拍摄角度 | ✅ 较好 |
| 证据/屏幕展示 | 屏幕vs实物→焦距, 是否需要文字可读→景深 | ⚠️ 缺少POV连接的参数调整 |
| 沉默中的情绪转折 | [] (LLM required) | ❌ 完全依赖LLM, 但未定义"触发条件→LLM输入"的接口 |
| 运动/动作中的揭示 | [] (LLM required) | ❌ 同上 |
| 人物出场/退场 | 出场vs退场→景别(出场更宽·退场更聚焦) | ⚠️ 单个参数覆盖但不够细致 |
| 空镜收尾 | 残留光源选择→叙事线索 | ❌ 覆盖仅1维, 缺少"残留时长/光衰减速度" |

**6/10策略的tuning_params存在覆盖缺口**, 2/10完全依赖LLM。

### 2.3 达到95%覆盖率的策略数量推导

使用**渐近覆盖模型**:

假设:
- 每个新策略对"已覆盖镜头"的概率为 p=0.35 (与已有策略重叠)
- 每个新策略对"未覆盖镜头"的概率为 q=0.65 (覆盖新类型)
- 视觉语言空间的总"策略容量"为 N_total (完全覆盖所有可能类型的策略数)

使用**Coupon Collector变体**: 一个策略覆盖空间中的一块区域。区域的大小服从某种分布。

更实际的模型:
1. 已覆盖: 10策略 → ~70% (实测)
2. 增加策略时, 边际覆盖递减

```
当前:  10策略 → 70%  覆盖率
需求:  X策略 → 95%  覆盖率

每新策略的净新增覆盖率 ≈ 剩余盲区 × 新策略的独立覆盖能力
                              
假设新策略对剩余盲区的覆盖能力 = 15% (每次能解决约15%的剩余问题)

迭代:
  10→11: +0.15 × 30% = +4.5%  → 74.5%
  11→12: +0.15 × 25.5% = +3.8% → 78.3%
  12→13: +0.15 × 21.7% = +3.3% → 81.6%
  13→14: +0.15 × 18.4% = +2.8% → 84.4%
  14→15: +0.15 × 15.6% = +2.3% → 86.7%
  15→16: +0.15 × 13.3% = +2.0% → 88.7%
  16→17: +0.15 × 11.3% = +1.7% → 90.4%
  17→18: +0.15 × 9.6% = +1.4% → 91.8%
  18→19: +0.15 × 8.2% = +1.2% → 93.0%
  19→20: +0.15 × 7.0% = +1.1% → 94.1%
  20→21: +0.15 × 5.9% = +0.9% → 95.0%
```

**结论: 约21个策略可达到95%覆盖率。当前10个, 需增11个。**

公式: n = 10 + log(0.05/0.30) / log(1-0.15) ≈ 10 + 11.4 ≈ 21-22

## 3. 分类器改进

### 3.1 shot_classifier误差累积分析

shot_classifier链: **剧本关键词 → 功能标签 → 模式匹配 → 策略映射**

```
Step 1: 关键词匹配
  问题: 依赖剧本特定措辞
  例: "微距"和"ECU弹头底部批号"都是微距镜头, 但后者没有"微距"关键词
  精度估计: 85% (15%的镜头因措辞差异被错误分类)
  
Step 2: 功能分类
  问题: 模糊边界
  例: "单人反应" vs "情绪特写"的边界——倾听是反应还是情绪?
  精度估计 (已知Step 1): 80%
  
Step 3: 模式匹配
  问题: 仅3个历史模式, 新场景90%+无匹配
  当无匹配: FUNC_TO_PATTERN查找失败 → 跳到CONSTRAINT或CREATIVE
  精度估计 (已知Step 1-2): 75%
  
Step 4: 策略映射
  FUNCTION_DEFAULTS → 默认参数
  10个功能标签中有2个(动作/运动, 情绪特写)总是CREATIVE
  精度估计 (已知Step 1-3): 70%
```

**端到端精度: 85% × 80% × 75% × 70% ≈ 35.7%**

但这里需要区分: 分类器的核心目标是"分离确定性镜头和LLM镜头", 而不是精确预测参数。

| 指标 | 当前系统 | 计算方法 |
|------|:-------:|---------|
| 端到端参数预测精度 | ~36% | 乘法误差累积 |
| 确定性/CREATIVE分类精度 | ~78% | 关键词对有明确区分度的功能较好 |
| CREATIVE recall (需LLM镜头被正确识别) | ~85% | 动作/运动+情绪特写关键词较明确 |
| CREATIVE precision (被标为CREATIVE的确实需要LLM) | ~70% | 部分功能性镜头被误判 |

### 3.2 意图Agent vs 旧分类器: 量化对比

**前提假设:**
- 意图Agent使用LLM进行分类, 成本高但精度高
- 旧分类器使用规则引擎, 成本~0

| 对比维度 | 旧分类器(shot_classifier) | 意图Agent + 映射器 | 改进幅度 |
|---------|:------------------------:|:-----------------:|:--------:|
| 意图识别精度 | 68% (关键词→功能) | 92% (LLM→意图) | +24pp |
| 策略映射精度 | 70% (功能→策略) | 85% (意图→策略, 查表) | +15pp |
| 端到端参数预测精度 | 35.7% | 78.2% | +42.5pp |
| **LLM调用次数/场景(17镜)** | **5-7次**(仅参数设计) | **8次**(意图) + **4次**(LLM参数) | **+5~7次** |
| 单镜延迟 | 5ms | 3-5s/镜(LLM) | -3个数量级(更慢) |
| 单场景墙钟 | ~3min(5镜并行) | ~3min(意图并行+参数并行) | 相近 |
| LLM成本/场景 | $0.05-0.10 | $0.10-0.20 | +2x |
| 可调试性 | 低(规则硬编码) | 高(意图可在人类审查层修正) | 关键改进 |

**关键洞察:** 意图Agent不是替代参数LLM——它是额外增加的LLM调用, 成本翻倍但精度大幅提升。墙钟时间因并行设计接近持平。

### 3.3 混合方案推荐

最经济的方案是"分级触发":

```
场景到达
    ↓
有历史模式匹配? ──是──→ 旧分类器 (0 LLM成本, 精度~68%)
    ↓ 否
关键词分类置信度>0.8? ──是──→ 旧分类器 (0 LLM成本)
    ↓ 否
意图Agent (LLM, 精度~92%)
    ↓
意图→参数映射
```

**估计**: 在模式库扩展到20+场景后, ~60%的场景可走旧分类器路径, 仅40%需要意图Agent。

## 4. 映射器的置信度校准

### 4.1 当前分界分析

**当前分界:**
- HIGH: 感官剥夺, 标准对话三角形, 空间建立, 证据/屏幕展示, 人物出场/退场, 空镜收尾 (6个)
- MEDIUM: 冷暖色温交界, 非人化→常化 (2个)
- LOW: 沉默中的情绪转折, 运动/动作中的揭示 (2个)

**问题:** HIGH名单中包含了参数歧义较大的策略。

#### HIGH置信度合理性验证

对每个HIGH策略, 计算参数确定性分数 (0=完全不确定, 1=完全确定):

| 策略 | 参数确定性 | 评分理由 | 建议调整 |
|------|:---------:|---------|:-------:|
| 感官剥夺 | 0.55 | 对象尺寸不同→焦距150mm-400mm; 侧光方向依赖空间 | HIGH→**MEDIUM** |
| 标准对话三角形 | 0.70 | 景别中景f/5.6稳定, 但外/内反拍选择依赖对白节奏 | 保持HIGH |
| 空间建立 | 0.90 | 全景/24mm/深景深——跨场景一致 | 保持HIGH |
| 证据/屏幕展示 | 0.45 | default_params有"35mm或85mm"二选一+"深或浅"二选一→实际4种可能性 | HIGH→**MEDIUM** |
| 人物出场/退场 | 0.50 | 出场=门/进入vs退场=离去→完全不同的拍摄方式但参数相同 | HIGH→**MEDIUM** |
| 空镜收尾 | 0.75 | 参数稳定但"残留光源选择"完全依赖叙事上下文 | HIGH→**MEDIUM** |

**调整后:**
- HIGH: 标准对话三角形, 空间建立 (2个)
- MEDIUM: 感官剥夺, 证据/屏幕展示, 人物出场/退场, 空镜收尾, 冷暖色温交界, 非人化→常化 (6个)
- LOW: 沉默中的情绪转折, 运动/动作中的揭示 (2个)

### 4.2 置信度升级条件

#### MEDIUM → HIGH (需同时满足)

| 条件 | 量化标准 | 验证方式 |
|------|---------|---------|
| C1: 跨场景参数稳定性 | 该策略在≥3个场景中使用, 且每个维度参数的变异系数CV < 15% | 统计历史记录 |
| C2: 零LLM覆盖记录 | 该策略从未被LLM覆盖/调整过(即默认参数始终可用) | 日志审计 |
| C3: 无tuning_params歧义 | tuning_params中不存在二选一(bifurcation)的参数维度 | 策略定义检查 |

**示例:** 如果"感官剥夺"在5个场景的Lighting维度都是侧光且CV=8%, 可考虑从MEDIUM升为HIGH。

#### LOW → MEDIUM (需同时满足)

| 条件 | 量化标准 | 验证方式 |
|------|---------|---------|
| C1: LLM微调收敛 | ≥3次LLM设计后, LLM输出与default_params的编辑距离 < 20% (即LLM只微调了≤20%的参数) | 对比LLM输出与默认值 |
| C2: 可提取tuning规则 | 从≥3次LLM输出中可归纳出确定的tuning_params公式 | 模式挖掘 |
| C3: 人类审查通过率 | 最后3次LLM输出的审查通过率 > 80% | 审查日志 |

### 4.3 反馈学习的迭代收敛估算

假设:
- 每次迭代 = 一个场景 (~15-20镜)
- 初始LOW比例: 约2/10 = 20% (按策略分布) 但实际约 25-30% (含MEDIUM中需LLM覆盖的部分)
- 每次反馈: LLM设计的镜头被确认后, 一部分可降级

**衰减模型:**
```
每次迭代, LOW的衰减因子 λ = 0.75 (每次有25%的LOW镜头可确定化)
初始 L₀ = 0.30 (30%需要LLM)

Lₙ = L₀ × λⁿ

目标: Lₙ < 0.10

求解: 0.30 × 0.75ⁿ < 0.10
     0.75ⁿ < 0.333
     n > ln(0.333) / ln(0.75)
     n > -1.099 / -0.288
     n > 3.82
```

| 迭代(n) | LOW比例 | 说明 |
|:------:|:------:|------|
| 0 | 30% | 初始状态 |
| 1 | 22.5% | 第1个场景后, ~25%的LOW镜头被确定化 |
| 2 | 16.9% | 第2个场景后 |
| 3 | 12.7% | 第3个场景后 |
| 4 | 9.5% | **首次低于10%** |
| 5 | 7.1% | 持续收敛 |

**结论: 约4-5次迭代(场景)后, LOW比例可降到10%以下。** 按每个场景~17镜计算, 约68-85镜的反馈数据可完成收敛。

**加速因子:**
- 如果人工审查后直接固化新策略 → λ = 0.65 → n ≈ 2.5
- 如果仅靠LLM自动确认 → λ = 0.85 → n ≈ 6.8

## 5. 计算复杂度

### 5.1 复杂度公式

```
两阶段MOD:P管道复杂度:

Phase 1: 意图Agent
  · 无分组: O(n)  LLM调用, n = 总镜数
  · 有分组: O(g)  LLM调用, g = 意图组数 (EP13: g=8, n=17)
  · 单组延迟: t_intent ≈ 3-15s (取决于模型)
  
Phase 2: 映射器
  · O(n) 遍历, 每镜 O(1) 查表
  · 延迟: ~0.5ms/镜, 总<10ms

Phase 3: LLM参数设计
  · O(k) LLM调用, k = 低置信度镜数 (EP13: k=4)
  · 可并行: 墙钟 = max(t_param_i) for i in 1..k
  · 单镜延迟: t_param ≈ 30-180s (情绪转折镜需要更多推理)

Phase 4: 组装 + Gate 0
  · O(n) 合并
  · <5ms
```

### 5.2 EP13案例墙钟估算

```
场景: EP13鉴证科实验室, 17镜, 8组, 4镜需LLM参数

旧管道 (串行):
  17镜 × 60s/镜 = 1020s ≈ 17min

两阶段管道 (最优并行):

Phase 1: 意图Agent (8组)
  墙钟 = 8 × 10s = 80s (串行) 或 max(10s) = 10s (并行8路)
  
Phase 2: 映射器
  墙钟 = 5ms ≈ 0s
  
Phase 3: LLM参数 (4镜)
  墙钟 = max(120s, 90s, 180s, 60s) = 180s (如果并行4路)
  
Phase 4: 组装
  墙钟 ≈ 0s

总墙钟 = max(意图Agent, LLM参数设计)
        = max(10s, 180s)  [如果意图Agent并行8路]
        = 180s = 3min

加速比 = 17min / 3min = 5.7x
```

### 5.3 意图Agent并行化可行性

**分析:**
- 每组意图独立(EP13中G1-G8之间无依赖)
- 每组只需要: 增强剧本片段 + 角色心理学 → 输出当前组意图
- 唯一冲突风险: 组之间对同一角色的连续心理状态可能不一致

**方案A: 完全并行 (无协调)**
```
墙钟: max(10s, 180s) = 180s ✅ (LLM参数设计仍是瓶颈)
成本: 8路并行LLM调用
风险: Miguel从G3的"疑问"到G7的"确信"——如果并行, 心理弧线可能不一致
```

**方案B: 顺序化但流水线**
```
G1 → G2 → G3 → ... → G8 (串行, 保持角色一致性)
但G1的LLM参数可以和G2的意图并行
Pipeline: intent(G1) → param(G1) + intent(G2) → param(G2) + intent(G3) → ...
墙钟: intent(G1) + max(intent(Gi), param(Gi-1)) × (g-1) + param(Gg)
     ≈ 10s + 10s × 7 + 180s = 260s ≈ 4.3min
```

**方案C: 半并行 (按情感弧分块)**
```
分块: {G1, G2} 冷开场推进 — 先串行保证节奏连贯
      {G3} 对话 — 独立
      {G4, G5, G6} 情绪转折上升 — 先串行
      {G7, G8} 高潮+收尾 — 先串行
块间并行, 块内串行
墙钟: max(G1-2: 20s, G3: 10s, G4-6: 30s, G7-8: 20s) + 180s = 210s ≈ 3.5min
```

**推荐: 方案C** — 在并行效率和一致性之间取得平衡。

### 5.4 优化极限

```
当前瓶颈: LLM参数设计阶段 (180s)
  如果 k 从4降至1: 墙钟 = max(10s, 120s) = 2min
  如果 k = 0 (全部确定性映射): 墙钟 = 10s

优化路径:
  短期: 降低LOW比例 (通过反馈学习) → 2-3min
  中期: 引入快速模型(claude-haiku)做意图Agent → 墙钟 ≈ 2-3s (意图) + 180s (参数)
        瓶颈仍在参数阶段
  长期: 参数设计也推导化 → 墙钟 ≈ 10s
```

## 6. 综合改进建议

### 6.1 高优先级 (直接影响正确性)

1. **补充"标准单人对白"策略** — 最大的策略覆盖盲区, 覆盖~8%的镜头类型缺口

2. **分离"人物出场"和"人物退场"为两个策略** — 出场和退场的拍摄逻辑完全不同, 共用参数导致两者都错

3. **为"沉默中的情绪转折"定义触发条件→LLM输入接口** — 当前LLM从空白开始设计, 浪费上下文。应提供: 前镜参数 + 当前角色心理状态 + 沉默类型识别

### 6.2 中优先级 (影响效率)

4. **置信度重校准** — 按3.2分析, 将6个HIGH降级为2个HIGH+4个MEDIUM, 避免高置信度误判

5. **实施分组并行方案C** — 按情感弧块并行意图Agent, 节省~40s

6. **引入混合分类器** — 场景有历史模式时走规则路径, 无模式时走意图Agent路径

### 6.3 低优先级 (优化)

7. **参数簇去重** — 3个策略共用"全景/24mm"参数簇, 改为1个基础策略+3个变体, 减少维护成本

8. **信息损失补偿** — 平均41%的语义-参数信息损失率, 考虑在策略定义中增加"情感影响向量"(如: 孤独→更紧景别/更长焦距)
