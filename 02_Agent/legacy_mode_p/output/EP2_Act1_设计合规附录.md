## §6 设计流程走查 (7步)

### Step 1: 场景类型识别 ✅
```
判定: 悬疑/单人探索
人数: 1(伊莎贝拉·单人) + 画外(Vincent·VO·走廊脚步声)
空间: 2(楼道·Rico工作室室内)
对白: 1句VO("Rico...")
→ 核心类型: 悬疑(§2.4) · 单人探索 · POV主观
```

### Step 2: 空间建立 ✅
```
镜#A1(ECU→MCU·3s): 空间入口建立——锁孔→门开→暖光涌出
  - 可放置区域: ①门外·②门口内·③走廊·④工作台前
  - 禁入区: 墙体内·洗手池下方
  - 光源锚点: L1(吸顶灯4000K·格6)·L2(吊灯2800K·格1-6)·L3(门缝暖光·格5)
  - 关系线: 伊莎贝拉↔门(走廊↔室内分界线)·A侧(锁孔侧)
✅ 第一镜建立了空间——观众知道"在哪里"
```

### Step 3: 机位序列 ✅
```
镜#A1: ECU锁孔(悬念入口·§2.4-#2未知之惧) → MCU门半开(揭示)
镜#A2: POV全景(探索·§2.4-#6危险逼近·主观视角) → CU毛巾(发现·视觉惊吓)
镜#A3: ECU手(紧握→松开·§2.4-#9恐惧延时释放) → 甩镜(§2.4-#7视觉惊吓) → CU面部(首次露脸)
镜#A4: 全景空镜(§2.4-#4空无之惧) → dolly back(§2.4-#1轻微后退) → ECU手抖锁门(闭合·§2.4-#8无路可逃的逆转)
✅ 从悬念入口→探索→发现→恐惧→退出→闭合·完整弧线
```

### Step 4: 运镜动机 ✅
```
镜#A1: 固定 — 信息密集(锁孔+钥匙+门开·§1.1固定·观察者视角)
镜#A2: 间歇摇摄POV — 揭示式探索(§1.1摇摄·间歇=几个注意中心各停留)
镜#A3: 固定→甩镜→固定 — 甩镜=惊吓反应(§1.1甩镜·从一个注意中心快速甩到另一个)
镜#A4: 固定→dolly back→固定 — 后退=观众被"拉走"的不安(§2.4-#1轻微后退)
✅ 每个运镜有叙事动机·不穿墙·静→动→静三段式
```

### Step 5: 构图与光影 ✅
```
镜#A1: ECU封闭→MCU开放 · 2层深度(门板+走廊) · 冷暖交界线(L形)
镜#A2: POV全景·光锥对角线切割 · 3层深度(门框+工作台+后墙) · chiascuro
镜#A3: ECU手→面部CU · 双色温同框(左暖2800K+右冷4000K·沿鼻梁分界)
镜#A4: 全景走廊一点透视→ECU锁孔 · 暖光矩形缩小→消失
✅ 每镜≥2层深度·主体在引导线终点·影调匹配情绪
  影调: 镜#A1低调→镜#A2高对比(chiaoscuro)→镜#A3中调→镜#A4低调
```

### Step 6: 剪辑点 ✅
```
①→② 硬切: 门开暖光涌入→室内POV·空间连续(门=过渡元素)
②→③ 硬切: 毛巾特写→手部ECU·情感高点(发现血迹后的反应)
③→④ 甩镜过渡: 面部CU→走廊空镜·转头=剪辑动机(人物动作驱动切点)
✅ 情感优先·动作匹配(甩镜方向=转头方向)·视线匹配(POV对应)
```

### Step 7: 自检 ✅
```
[✓] 每个镜头都有叙事功能
[✓] 每个运镜都有动机(已标注)
[✓] 180度线未被跨越(全场景A侧·无越轴)
[✓] 空间可行性已验证(摄影机在可放置区域·不穿墙)
[✓] 视觉波浪: 低(镜#A1ECU)→升(镜#A2光锥高对比)→高潮(镜#A3双色温+甩镜)→释放(镜#A4冷白闭合)
[✓] 静→动→静: 镜#A2(静→摇→停顿→摇→落定)·镜#A4(静→dolly back→静)
```
