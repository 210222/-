# §A 场景类型判定

📐 场景类型 = [对话+悬疑混合] · 角色数 = [2]人(Vincent + Miguel) · KB加载章节 = [§1.1-1.3 双人对话(~52条) + §2.3 悬疑惊惧(10条) + P0安全规则(始终加载)]

判定依据:
  - 核心叙事驱动力: 双人对话——Vincent向Miguel揭示弹道证据
  - 悬疑成分: 证据从微观(弹头膛线)→宏观(杀手签名)→人名(Rico)的逐层揭示，带有犯罪调查的紧张感
  - 混合格式: 对话主导(约60%) + 悬疑揭示节奏(约40%)
  - 无打斗/追逐动作

覆盖策略: 对话8机位模板(Katz简约法则精简为7位置·15镜)
  - 8机位模板适配本场景: 保留全部8种功能但合并为7个物理摄影机位置
    · 双人全景(Establishing)   → Segment ③ 门侧主镜头
    · 单人A(Single A·Vincent)  → Segment ② 走道Vincent单人
    · 单人B(Single B·Miguel)   → Segment ⑥ 走道Miguel单人
    · 过肩A(OTS A)              → Segment ④ 屏幕侧过肩(从Vincent身后拍屏幕)
    · 过肩B(OTS B)              → Segment ⑤ 双人中景(走道看两人)
    · 插入(Insert)              → Segment ① 台面极特写(弹头/照片)
    · 反应(Reaction)            → Segment ⑥ Miguel反应(复用单人B位置)
    · 再交代(Re-establishing)   → Segment ⑦ 摇臂升起(窗→城市)
  - 精简原则: Katz简约法则——7个位置覆盖全部15镜的叙事需求
  - 悬疑叠加: 在对话模板基础上叠加A-SUS-02(未知之惧)·A-SUS-03(紧张期待)·A-SUS-09(恐惧延时释放)

# §B 空间结构与180度线设定

## B.1 鉴证科实验室坐标系

```
空间边界: ~8m(深·南北) × ~5m(宽·东西) × ~3m(高)
朝向定义:
  北(N) = 尽头LED大屏(3D弹道模拟)·距门~8m
  南(S) = 门入口(灰色金属消防门·推断·宽~1m·高~2.1m)
  东(E) = 窗墙(百叶窗·半开·3500K午后暖金窗光)
  西(W) = 物证橱窗墙(玻璃橱窗·证物箱码放)

人物可放置区域:
  ① 工作台前(Vincent坐姿·显微镜操作区): 距门~5m·画面中央偏东
  ② 走道(站姿·1-2人): 实验台间·宽~2.5m·南北向
  ③ 门前区域(Miguel入室): 距屏最远端·门内侧
  ④ 窗前区域(站姿·1-2人): 百叶窗前·距工作台~3m
  ⑤ 复合工作站前: 多连屏前

禁入区:
  ❌ 实验台内部/上方
  ❌ 物证橱窗内部
  ❌ 墙体内部
  ❌ 天花板
```

## B.2 关系线与180度线

```
关系线(Line of Interest): 穿过Vincent头部↔Miguel头部
  - Vincent: 工作台前坐姿·面朝北(屏幕方向)·位置在房间中央偏东
  - Miguel: 站姿·Vincent右侧(东侧·近窗)·面朝北(屏幕方向)
  - 两人为"肩并肩"构型(D-DUO-06): 同方向注视屏幕·非面对面
  - 关系线走向: 大致东西向(从Vincent位置到Miguel位置)

180度线划分:
  ┌─────────────────────────────────────────────┐
  │  N(屏幕)                                     │
  │                                              │
  │  W(橱窗)  ←──[关系线]──→  E(窗户·窗光)       │
  │           Vincent─Miguel                     │
  │           (坐)    (站)                       │
  │                                              │
  │  S(门)                                       │
  └─────────────────────────────────────────────┘

选定侧: 关系线南侧/西侧(走道侧)
  - 机位 ②③⑤⑥⑦ 全部位于走道(西侧)·面朝东拍摄
  - 机位 ① 和 ④ 为轴线上的中性位(沿视轴·不改变关系线侧)
  - 无跨线需要·全程保持同侧

选择理由:
  - 走道空间充足(宽~2.5m·纵深~8m)·机位可自由移动
  - 从西侧拍摄·窗光(3500K暖金)位于人物背后→形成逆光/边缘光
  - 橱窗(西墙)为背景·避免光源直射镜头
```

## B.3 视线方向映射

```
人物朝向(面朝北·看屏幕时):
  - 从西侧(走道)拍摄 → 人物面朝画面右侧(东/北方向)
  - Vincent坐姿看屏幕: 视线朝右(frame-right)
  - Miguel站姿看屏幕: 视线朝右(frame-right)

对话时视线匹配(E-MTC-04):
  - Miguel在Vincent右侧(东侧)
  - Vincent看向Miguel: 视线朝右(extreme frame-right) ← 面向东
  - Miguel看向Vincent: 视线朝左(frame-left/center) ← 面向西
  - Vincent视线右 vs Miguel视线左 → ✅ 相反·满足视线匹配铁律

电话对话(Shot #4):
  - Vincent独白时视线朝右(看证据/屏幕方向)
  - 在Miguel出场前建立Vincent的银幕方向
  - Miguel出场后维持一致方向(同侧·同朝向)
```
