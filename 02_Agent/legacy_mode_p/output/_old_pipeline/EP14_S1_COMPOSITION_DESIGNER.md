## 1. 场景光影系统设计

### 1.1 主光源系统：天花板方形格栅灯

```
光源锚点: 天花板四个方形格栅发光顶灯（参照参考图上排·空间布局描述）
锚定依据: 参照画布宪法第三条·空间锚定·光源锚定于参考图上排·格栅灯可见于场景结构描述
色温: 5000K·冷白
质量: 柔光·大面积均匀扩散·无影灯设计
覆盖范围: 全室（~6m深×~4m宽）·从天花板向下全覆盖照明
光比: 低光比·约1:1至1:2（均匀无影·无戏剧性阴影）

制度隐喻:
  无影灯设计 = 制度的"透明"假象——声称一切可以被看见和分析
  但红线网络的存在提醒观众：看见的不是全部
  光影的均匀性 = 制度的冷酷理性·不偏袒·不选择·无差别照射

KB规则:
  L-CT-01（色温与情绪绑定）: 4300K(荧光灯·中性)=办公/医院/疏离——
  本场景5000K冷白接近此区间·制度空间的疏离感
  L-3PT-02（侧光/斜侧光塑造立体感）: 格栅灯为顶光均匀照明·非侧光——
  人物面部缺乏方向性立体感·扁平化·制度中的人=功能而非个体
  L-SCN-04（日间室内场景）: 本场景无窗户自然光·全人工照明·模板适配需调整——
  主光=天花板格栅灯(5000K)替代窗户光·补光=格栅灯自身的均匀扩散
```

## 2. 场景色彩策略

### 2.1 冷酷基色系统

```
主基色比例分布（参照参考图色彩总评）:
  灰色系（墙面·桌面色调）: ~40%  → 制度·中性·无感情
  白色（白板·天花板·纸张）: ~30%  → "透明"·理性·客观·空白画布
  黑白（照片·文件文字·阴影）: ~20% → 证据·事实·过去
  ─────────────────────────────────────────
  冷酷基色合计: ~90%  → 参照COL-PRI-06·冷色调营造疏离/制度氛围

KB规则:
  COL-PRI-06（冷色调营造未来/神秘/清冷氛围）: 以冷色统一画面基调营造疏离感——
  本案情室的灰/白/黑白=去色化的冷酷
  COL-PRI-28（中性背景最大化主体饱和度）: 白色/中性灰背景通过同时对比使
  彩色主体的感知饱和度最大化——本案中红线的饱和度被白板最大化放大
```

### 2.2 冲撞色系统：正红=血管隐喻

```
冲撞色: 正红（红线·红图钉·红圈注）
占比: ~5-10%（在~90%冷酷基色中=高度集中的视觉冲击）
功能: "血管"或"逻辑流向"——在冷灰白底色中引导观众视线追踪案件因果

红色在构图中的三维功能:
  1. 引导功能: 红线从人物照片→辐射连接→汇聚至201房间红圈 = 视觉流路径
     → 参照C-FI-03（视觉流引导）+ VS-LS-04（引导线）
  2. 隐喻功能: 红线缠颈=被缠住的Rico·“血管”=案件的生命线·流动的逻辑
     → 参照C-FI-05（每个视觉元素必须服务于叙事）
  3. 冲撞功能: 正红在冷灰白基色中=唯一的"活"色——制度的冷酷vs暴力的红色
     → 参照COL-PRI-01（互补色对比突出主体）·红在灰白中自动成为视觉焦点

KB规则:
  COL-PRI-01（互补色对比突出主体）: 暖色主体+冷色背景——
  红线(暖色·正红系)在白板(冷白)背景上形成最强视觉冲击
  COL-PRI-03（主色调统一）: 主色调=灰白冷(70%)+辅色=红(15%)+强调色=
  Miguel肤色棕褐+金色警徽+深藏青夹克(15%)——三色比例符合60-70/15-30/5-10原则
```

### 2.3 Miguel肤色作为"色温计"

```
Miguel棕褐肤色在不同色温下的表现（参照ANCHOR_BASELINE Miguel肤色-光源对应）:

  5000K冷白(格栅灯·制度内):
    → 肤色偏灰偏蜡·棕褐色被冷白压制
    → "分析者"状态——制度中的人·审视证据·理性运转
    → 镜#A1/#A2/#A3/#A5/#A6适用

  3500K暖黄(走廊光·制度外):
    → 肤色皮下散射深橙金·棕褐色回暖
    → "行动者"状态——离开制度·走向外部世界·准备行动
    → 镜#A7适用（右半身冷白/左半身暖黄=过渡中的人）

肤色变化的叙事弧线:
  镜#A1-A6: 灰蜡色→"分析者"状态·制度内·审视·钉照片·回应
  镜#A7: 半灰蜡半暖金→"分界线上的人"·制度到行动的过渡
  镜#A7延续(走向走廊): 全暖金→"行动者"·离开制度·走向Rico工作室

KB规则:
  COL-PRI-25（面部三区色彩变化）: Miguel面部在5000K冷白下三区差异被压平——
  正常棕褐肤色的额头(暖黄)/脸颊(红润)/下巴(冷蓝灰)三区过渡在冷白光下趋于一致偏灰
  → 制度光线的"去个性化"效果
```

### 2.4 色彩跨镜一致性

```
同场景·同光源条件下的色温约束（参照画布宪法第二条·跨镜零引用原则·每镜独立描述色温）:

  镜#A1/#A2/#A3/#A5: 5000K冷白主光·一致
  镜#A4: 5000K冷白(室内半脸) + 3500K暖黄(走廊半脸)·混合色温·叙事理由充分
  镜#A6: 5000K冷白主光 + 6500K冷蓝(笔记本屏幕微光)·同冷色系叠加
  镜#A7: 5000K冷白(右半身) + 3500K暖黄(左半身)·冷暖交界·叙事理由充分

色彩锚定验证:
  ✅ 全部色温有物理光源锚点（格栅灯/笔记本屏幕/走廊暖黄光）
  ✅ 冷暖混合均有叙事理由（门口=制度交界处）
  ✅ 无凭空编造的色温变化
  ✅ 参照画布宪法第三条·空间锚定·全部光源可追溯参考图或标注物理属性
```
