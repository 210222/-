```

  B侧 = 东侧（不使用）

  关系线定义为"Miguel ↔ 白板中心（南北向）"——将人物与静态物体之间的
  空间关系作为180度线基准。在经典电影语法中·180度线通常建立在两个

  ② Miguel与Vincent的对白极短（两句）
  ③ 维持统一轴线的视觉一致性优于为短暂互动切换轴线
```
