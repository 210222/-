### SHOT 01 -- ECU · 锉刀在枪管上

```

```

【画面空间结构】
  前景: 锉刀刀片——占据画面中央下2/3·刀齿纹理清晰·金属表面微反光
        钢制枪管——横贯画面中下部·锉刀在枪管上往复·金属碎屑散落
  中景: 台面木纹——浅景深虚化·暖棕色木纹+磨损痕迹·隐约可见其他零件散置
  背景: 深褐暗区——光锥外的台面边缘·几乎全黑·形成天然负空间画框
  构图策略: 锉刀与枪管构成画面唯一视觉焦点·刀齿纹理为画面内唯一"活跃"元素
           负空间(C-FI-01)最大化——深褐背景占据画面~60%·迫使视线聚焦锉刀接触点

【光影方案】
  主光源: 天花板工业吊灯(2800K暖黄)·唯一光源
  光比:   高光比~1:8（光锥内锉刀+2EV vs 光锥外暗区-3EV）
  色温:   2800K暖黄·纯室内·chiaroscuro
  阴影形态: 刀齿之间=锐利微阴影·枪管曲面=柔和高光过渡·金属碎屑=点状暖色反光
  关键效果: 锉刀钢面反射暖金高光(L-3PT-09硬光突出金属质感)
           枪管黑色氧化层吸收光线·仅曲面边缘有暖黄轮廓线(L-3PT-07微边缘光)
           金属碎屑在台面木纹上呈金色微点·光锥内可见·光锥外不可见

【KB规则引用】
  C-FI-01: 负空间与主体强化——大面积深褐暗区与锉刀金属形成高对比 [P1]
  L-3PT-09: 硬光/强光突出质感——锐利阴影适合金属表面 [P1]
  COL-PRI-03: 主色调统一——2800K暖黄覆盖画面80%·深褐阴影15%·金属反光5% [P0]
  C-AJS-05: 黑暗压光法——暗部占画面~60%·仅光锥内锉刀/枪管被充分照明 [P2]

    背景: 洞洞板后墙——挂满工具/枪管/配件·墙面脏旧灰泥质感

【光影方案】
  主光源: 天花板工业吊灯(2800K暖黄)
  光比:   光锥区(Rico+台面)+2EV vs 暗角(保险柜/门附近)-3EV≈高光比~1:10
  色温:   2800K暖黄主导·纯室内·无冷光渗入（门闭合状态）

    - 吊灯光锥形状清晰可见——台面上一个暖黄椭圆亮区
    - Rico背部=光锥中心·暖黄光从上方照向肩部和后脑·轮廓边缘=暖金边缘光
    - 洞洞板墙面=光锥外·深褐阴影·工具仅轮廓可辨
    - 保险柜区域=最深阴影·完全消失在暗角中
    - 地板=从光锥中心向外逐渐变暗·距离越远越暗
  关键效果: chiascuro——暖黄光锥+深褐阴影=强烈明暗对比
            空间信息通过"被照亮的区域"逐步揭示——观众视线从光锥→洞洞板→门→保险柜
                (C-DEP-05景深调度——前景暗/中景亮(光锥)/背景暗)

【KB规则引用】
  C-FI-02: 景框深度分层——前景(门)·中景(Rico+工作台+光锥)·背景(洞洞板+保险柜) [P1]
  C-DEP-01: 线性透视(一点透视)——工作台/洞洞板的平行线条向单一消失点汇聚 [P1]

  L-3PT-05: 阴影硬度与氛围匹配——锐利光锥边缘=硬朗/紧张氛围 [P0]
  COL-PRI-03: 主色调统一——暖黄60%·深褐30%·金属反光/工具细节10% [P0]
  A-GEN-02: 空间建立优先——此镜为全场景第一镜·全景交代空间 ✓ [P0]

### SHOT 03 -- MS · 门被推开·影子入侵

```
脚本节拍: 第4行后半+第5行 "此刻门被推开...Miguel站在门口...他的影子先于他的人投在Rico的背上"

【画面空间结构】
  三层景深:
    前景: Rico背影（画面右侧·坐姿·光锥笼罩·暖黄光包裹肩部和后脑）
          工作台边缘在画面底部·零件散落
    中景: 地板暗区——光锥外·深褐·从Rico脚下延伸到门口
          Miguel的影子——从门口方向延伸·穿过地板暗区·投在Rico背上
          影子=冷光方向（4000K楼道光）投射的影子·投在暖光区
    背景: 门被推开——深木门向内开~60-70°·形成天然景框中景框
          门口=Miguel站姿剪影——逆光·面部完全不可辨·仅身体轮廓
          门外=冷白楼道荧光(4000K)涌入·形成冷暖交界线（门框平面）
  视线留白: N/A（Rico背影·Miguel面部在逆光中不可辨·无眼神交互）
  构图策略: 景框中景框(C-FI-14)——门框=天然画框·框住Miguel剪影
            剪影构图(C-FI-06)——Miguel逆光形成纯剪影·剥离细节·仅保留基本形态
            隐藏与揭示(C-FI-16)——Miguel面部被逆光完全隐藏·推迟观众对其面容的认知
            影子构图——影子比真人先入画·影子=威胁的预告

【光影方案】
  主光源: 双重光源同时存在
    - 吊灯(2800K暖黄): 照亮Rico背部·工作台·前中景区域
    - 楼道荧光灯(4000K冷白): 在门口形成冷光涌入·照亮Miguel背面·投射冷光方向影子
  光比:
    - 光锥内(Rico背部): 2800K·+2EV
    - 地板暗区: ~0EV
    - 门口冷光区: 4000K·+1.5EV（楼道较亮·但距离远·衰减后约+1EV vs 室内暗区）
    - Miguel剪影: -3EV（正面完全无光·逆光强度+1.5EV减去面部朝向=纯黑剪影）
  色温:
    - 2800K(暖黄) + 4000K(冷白) = 混合色温 (L-CT-02激活)
    - 叙事理由: 冷白入侵暖黄=制度入侵私人领域·门框=两个世界的分界线
  阴影形态:
    - Miguel的影子=冷光方向·边缘微偏冷偏蓝·投在Rico暖黄背上
    - 影子边缘=半影(penumbra)·因楼道荧光灯为面光源(非点光源)
    - 影子在Rico背上的色温=偏冷·与Rico暖黄背部形成对比
    - 门开口投射冷光矩形光斑在地板上(约Y=0→1.5区域)
  关键效果:
    - L-CT-02混合色温: 门框=冷暖交界线·2800K vs 4000K
    - 影子的色温对比: 冷影子(4000K方向)投在暖背(2800K方向)上
      = 叙事视觉化: Miguel的威胁(Rico甚至还没看到他的脸·但他的影子已经在Rico身上了)

【KB规则引用】
  C-FI-14: 嵌套构图/景框中景框——门框框定Miguel剪影 [P2]
  C-FI-06: 剪影与轮廓——逆光将Miguel转化为剪影·剥离细节聚焦形态 [P1]
  C-FI-16: 隐藏与揭示——推迟Miguel面容·控制信息透露 [P2]

### SHOT 05 -- MS · Miguel关门·靠门框·扫视

        门框作为天然画框(C-FI-14)——框住Miguel全身
  扫视路径的空间对应:
    画面左侧外→改装枪列阵位置（头向左转·枪墙在画面左外·通过转头动作暗示）

    画面右侧→保险柜暗角（头向右转·视线停在保险柜方向·画面右远景）
  构图策略: C-FI-14嵌套构图——门框=景框中景框·框定Miguel
