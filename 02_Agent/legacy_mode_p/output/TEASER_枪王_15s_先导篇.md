## §A 概念设计

### 核心意象（5个）

1. **枪** — 击锤·膛线·枪口焰·弹壳
2. **雨/血/下水道** — 保利斯塔大街雨夜·血被雨水冲向排水格栅
3. **圣母像/烛火** — 蓝色瓷像·五支白蜡烛·母亲的手
4. **咖啡杯（有缺口）** — 白色瓷杯·半月形缺口·血滴沿杯壁滑入缺口
5. **棒球帽男人 + 旧足球** — 帽檐遮眼·泥泞足球在水洼中

### 节奏设计

```
情绪曲线: ═══════════════════════════════════════
          建立→第一个呼吸→加速→高潮→释放→闭环

情绪层级:  压抑暗涌   意象叠加   冲突爆发   坠落·死亡   沉默·余韵

```

画面描述: 旧足球在水洼中。足球位于画面下三分之一正中央——经典黑白五边形图案·严重磨损。皮革表面开裂·从裂缝中露出内层灰色织物。球体被泥水浸透——泥浆沿着皮革缝合线渗入·黑白图案因泥色而模糊。足球半沉在一个水洼中——水洼直径约80cm·水深约2cm。水面反射远处酒吧霓虹招牌——绿色和粉色的模糊光带倒映在水面·随雨滴落下的涟漪扩散和扭曲。一只小孩的赤脚——泥泞·肤色深·脚趾短·指甲有泥——出现在画面上方边缘（画面外·仅脚入画）。脚掌踩在水洼边缘的湿石板上。足球没有任何运动——静止·被遗弃。背景：窄巷·两侧砖墙·地面石板缝隙中有积水·延伸至远处·柔焦·雨中蓝色灰雾。
