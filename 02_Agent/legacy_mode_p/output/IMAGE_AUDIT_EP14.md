- **辅助光源**: 笔记本电脑屏幕光——局部冷蓝补光，照亮人物面部下侧

- **光影特征**: 均匀柔和，无明显硬阴影；白板区域为画面最亮区域（视觉重心），桌面区域相对略暗

#### 可拍摄角度
1. **巷口外部·引入视角**: 从外部道路看向窄巷入口——适合Pedro追足球跑向巷口的开场镜头、轿车驶入/停靠的远景
2. **巷内纵深·主视角**: 摄像机在巷内中段，朝向巷尾/巷口——交代空间逼仄感，两侧墙面透视收窄
3. **巷内回看巷口·逆光视角**: 人/车从明亮巷口进入时的剪影效果——适合轿车抵达的戏剧性镜头
4. **巷中段·核心表演区**: 垃圾桶附近的侧拍角度——Pedro躲藏、Rico转头的主镜头
5. **低角度·Pedro视角**: 摄像机降至孩童高度（~1m），仰拍——增强压迫感和偷窥感
6. **墙根贴面·偷窥视角**: 紧贴墙面侧拍，以垃圾桶为前景遮挡——Pedro偷看的主观视角
7. **仰视一线天**: 强调空间封闭感，可用于转场或情绪过渡

#### 光源分析
- **主光源**: 自然日光——阴灰天空（参考格8描述），整体为散射柔光
- **光线分布**: 巷口和巷尾两个开口为主要进光方向；巷内中段为暗区（自然减光）
- **色温**: 阴天日光 ~5500K-6500K，偏冷灰
- **光影特征**: 
  - 巷口→巷内形成从明到暗的自然渐变
  - 逆光视角（格3）：人物/车辆以剪影呈现，戏剧性强
  - 墙面形成柔和侧光，凸显砖墙/水泥纹理
  - 头顶电线在墙面/地面投下网状淡影
- **积水反光**: 地面水洼可反射天光，形成局部高光点

2. **副驾驶侧窗外向内**: 从车外透过车窗拍摄副驾驶位的Rico——Pedro视角看到车内交易

4. **车内双人中景**: 摄像机在后排或中控台位置，同时框入驾驶员(金丝眼镜男)与副驾驶(Rico)
5. **过肩·副驾看驾驶**: 以Rico后脑/肩为前景，聚焦金丝眼镜男递信封的动作

#### 光源分析
- **主光源位置**: 驾驶座左侧或前方——侧逆光射入
- **光源类型**: 自然日光，午后暖色
- **色温**: 暖调 ~3200K-4000K，金色/琥珀色
- **光影特征**: 
  - 强烈的明暗交界线——光切面在座椅侧面、方向盘顶部、中控台边缘清晰可见

  - 胶片质感浓烈，立体感强
