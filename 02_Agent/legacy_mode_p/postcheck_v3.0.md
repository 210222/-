# 🆕 5F. 覆盖策略验证（对应审计11）

验证增强输出的覆盖方案是否完整执行：

```
逐场验证:

1. 覆盖模板对照:
   ┌─ 对话场景 → 检查8机位(或最小4机位豁免)是否全部有对应分镜
   ├─ 动作场景 → 检查6机位是否全部有对应分镜
   └─ 悬疑场景 → 检查5机位是否全部有对应分镜

2. 覆盖完整性:
   每种要求的机位类型 → 至少1个分镜分配？
   全部有 → ✅
   缺失机位 → 🛑 [场景N]缺[机位类型]覆盖·返回§2F补充

3. 插入/反应镜头完整性:
   对话场景(≥6行对白):
     反应镜头 ≥ 1？ → ✅/⚠️
     插入镜头 ≥ 1？ → ✅/⚠️
   情绪转折点 ±1镜:
     角色面部特写 ≥ 1？ → ✅/⚠️

4. Katz简约法则:
   实际镜头数 / 最小镜头数 ≤ 1.5？ → ✅
   实际镜头数 / 最小镜头数 > 1.5 且 无超额理由？ → ⚠️

输出格式:
📋 覆盖验证 · EP X
   场景1[对话]: 8机位模板 → 缺[OTS B][插入] → 🛑 补充
   场景2[动作]: 6机位模板 → 全部覆盖 ✅
   场景3[悬疑]: 5机位模板 → 全部覆盖 ✅
```

# 🆕 5H. 对白-运镜同步验证（对应审计13）

验证增强输出的对白同步标注是否准确：

```
逐场验证:

1. 到达点偏差:
   提取🎬对白同步标注的偏差值
   偏差 > 1.0s → ⚠️ 需调整📐速度
   偏差 > 2.0s且为关键情感台词 → 🛑 必须修复

2. Katz问答模式:
   提取🎬 Katz标注
   提问+拉远 → ⚠️ (不合理)
   沉默+剧烈运镜 → ⚠️ (打破沉默)

3. 对白间歇处理:
   对白停顿≥2秒的镜号 → 📐运镜是否合理？
   保持/微动/推近 → ✅
   拉远(无意图标注) → ⚠️
   突然剧烈(无意图标注) → ⚠️

输出格式:
📋 对白同步验证 · EP X
   到达点: ✅ #3 0.3s / ⚠️ #7 1.5s / 🛑 #11 2.3s(关键台词)
   Katz: #4 提问+推近 ✅ / #8 提问+拉远 ⚠️
   间歇: #5 停顿3s+静态 ✅
```

```

🎨 构图验证 · EP X

```
检查enhance输出中是否包含「摄影指导建议回应卡」:

对每一条摄影指导💡建议:
  □ 建议[#N] [P0/P1/P2] → enhance回应: [✅采纳/❌拒绝/⏸️延后/⚠️未回应]
  
  未回应建议数: ___ 条

```
对每条被拒绝(❌)的建议:
  □ 拒绝理由是否充分？

  拒绝理由不充分数: ___ 条
  ≥3条 → ⚠️ 系统性拒绝摄影指导建议且无充分理由

```

  P0建议: 总数___ · 采纳___ · 拒绝___ · 采纳率___%
