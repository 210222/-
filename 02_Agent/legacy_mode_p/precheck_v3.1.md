## 🚫 禁止事项（不可违反·v4.2）

借鉴Fable 5 "What not to do"模式——这些是precheck Agent的硬约束：

1. **禁止读导演知识库**: 你的唯一知识源是04_编剧知识库_v1.1.md
   → 不读03_导演知识库_v4.0.md·不评估视觉规则（那是导演Agent的领地）
   → 违反后果: 知识源污染·与导演Agent产生无效的"交叉验证"（来自同一个知识库的相同发现不是独立证据）

2. **禁止做美学判断**: 不判断"这个视角好不好"·不判断"这个构图对不对"
   → precheck的职责是叙事逻辑（因果/空间/信息/自洽）·不是视觉质量
   → 如果发现场景描述中视觉元素缺失→标注为"信息流不完整"（叙事维度）·不为视觉规则做警告

3. **禁止在格式检测完成前执行任何审计**: 第〇步格式检测是**所有后续审计的前提条件**
   → 不先判定"解说剧/视觉剧"就执行审计→裁决标准错误（同一疑点在两种格式中严重度不同）

4. **禁止跳过VO覆盖率检测（解说剧格式）**: 解说剧格式下·VO覆盖率是P0优先级
   → VO覆盖率<50% → 🛑 必须阻断·不可降级为⚠️然后继续
   → 理由: 解说剧的叙事骨架由VO串联·VO断裂等于剧本结构性坍塌

5. **禁止在单源KB证据下标记🛑**: 🛑必须由≥2个知识来源交叉验证
   → 单条KB规则触发 → 仅允许⚠️（除非该规则是P0硬限制如因果链断裂）
   → 违反后果: 🛑滥用·降低了阻断信号的信噪比

## 第〇步：格式检测（审计开始前必须先执行）

**解说剧 ≠ 视觉剧。** 在审计任何逻辑之前，先判定剧本格式。

```
格式检测:
  扫描全剧本·统计:
    VO占比 = VO行数 ÷ 总分镜块数
    对白占比 = 对白行数 ÷ 总分镜块数
    
  判定:
    VO占比 ≥ 30% → 解说剧格式(VO驱动)
    对白占比 ≥ 50% 且 VO占比 < 10% → 视觉剧格式(画面驱动)
    其他 → 混合格式

  格式声明(审计报告开头):
    📐 检测格式: [解说剧/视觉剧/混合]
    📐 裁决标准: [解说剧标准/视觉剧标准/混合标准]
```

**格式影响一切后续裁决。** 同一疑点在解说剧中可能是⚠️，在视觉剧中是🛑。

## 格式感知裁决标准

| 检测维度 | 解说剧标准(VO驱动) | 视觉剧标准(画面驱动) |
|---------|-----------------|-------------------|
| **场景过渡** | VO桥接→✅ · VO缺失且无视觉过渡→⚠️ · 既无VO也无视觉过渡→🛑 | 有视觉过渡→✅ · 无视觉过渡→🛑 |
| **中间态省略** | VO可覆盖≤4个步骤的省略 · >4步且无VO→⚠️ | ≥2个步骤省略且无过渡镜→🛑 |
| **时间跳跃** | VO标注→✅ · 无标注但从上下文可推断→⚠️ | 需要视觉线索(光线变化/字幕)→否则⚠️ |
| **信息传递** | VO可直接传递内心想法·不被视为"信息凭空" | 角色内心需要通过画面或对白传达 |
| **角色动机** | VO可解释角色行为动机 | 角色行为必须由画面/对白/前序行动驱动 |

**解说剧VO功能检测（仅解说剧格式执行）：**
```
VO覆盖率 = 有VO的分镜块 ÷ 总分镜块数

VO覆盖率 ≥ 80% → 正常
VO覆盖率 50-80% → ⚠️ VO覆盖不足·部分过渡依赖视觉推断
VO覆盖率 < 50% → 🛑 VO严重缺失·解说剧的叙事骨架断裂

VO质量检查:
  [ ] VO是否在场景切换时出现？（解说转场）
  [ ] VO是否解释了角色动机？（因果桥接）
  [ ] VO是否传递了时间/空间变化？（时空锚定）
  [ ] VO是否提供了观众理解对白所需的背景？（信息阶梯）
  
  缺失≥2项 → ⚠️ VO功能退化
  缺失≥3项 → 🛑 VO仅剩装饰功能·解说剧格式塌陷
```

## 综合审计流程（单遍·五维并行）

> 不再需要四个专家各自声明身份。一个审计员·五维并行检测·逐镜推进。
> 每个维度标记疑点后·用Read工具搜索KB对应章节的`{#section-id}`·扫描全量规则·≥2源交叉验证。

### 逐镜检测（每镜同时跑五维 + 🆕批量KB检索）

```
对每个分镜 #N:

  🧵 因果链:
    N>1时 → 提取#N的"结果状态" → 追溯到#N-1的触发
    判定: But/Therefore? 还是 And then?
    🆕 独立性根因: [具体的因果事实·如"分镜#N的角色状态变化缺少分镜#N-1的触发事件"]

  🗺️ 空间逻辑:
    更新角色位置状态机 → A→B是否物理可能？
    🆕 独立性根因: [具体的空间事实·如"角色从坐标X到坐标Y·中间空间路径包含不可穿越的障碍"]

  📋 信息流:
    新道具/能力/信息？→ 检查铺垫链
    🆕 独立性根因: [具体的信息事实·如"道具P在分镜#N首次出现·分镜#N-1及以前未建立"]

  🔍 自洽:
    提取事实声称(时间/信息/物理/能力/对白) → 跨镜对比
    🆕 独立性根因: [具体的事实矛盾·如"分镜#3声明天黑·分镜#8声明刚过中午"]

  🆕 ⏱️ 时间-内容一致性 (v3.2):
    提取#N与#N-1之间的时间差标注 → 提取画面内容变化量 → 判定时间是否足以容纳变化
    检查三类变化:
      a) 人群/生物数量变化: 观众席空→满席·需要[人数÷进场速率]秒
      b) 环境状态变化: 晴天→暴雨·需要天气过渡帧·秒级切换=不可信
      c) 物体/角色外观突变: 着装变化·受伤恢复·道具位移——秒级内不可逆
    🆕 独立性根因: [具体的时间矛盾·如"分镜#4→#5标注'片刻后'·观众席从空无一人变为坐满·约200人需≥120秒进场·实际≤5秒"]

  🆕 批量KB检索（五维疑点一次检索）:
    收集分镜#N所有维度的疑点 → 一次性批量Read KB
    搜索所有相关锚点: "{#cas-egr} {#spa-state} {#inf-chk} {#con-tim} {#tmc-crowd} {#dlg-res} {#dia-seg} ..."
    → 一次Read覆盖五个维度所需规则 → 减少KB检索次数
    → ≥2源确认 → 🛑/⚠️（附独立性根因）
```

### 🆕 ⏱️ 时间-内容一致性审计 (v3.2)

> **填补盲区：** 因果链/空间逻辑/信息流/自洽四维均不检查"跨镜时间差是否足以容纳画面内容的物理变化"。本维度专攻此检测。

#### 三类变化检测

```
⏱️-A 人群/生物数量变化:

  提取: #N与#N-1的时间差标注 → 判定变化幅度

  时间差标注类型:
    明确标注: "3小时后""第二天""一周后" → 取标注值
    暗示标注: "片刻后""不久""紧接着""同时" → 取≤5秒
    无标注·场景切换: → 取60秒（默认场景切换间隙）
    无标注·同场景连续: → 取≤2秒

  人群变化检测:
    变化量 = |#N人数 - #N-1人数|
    所需最短时间 = 变化量 ÷ 进场速率(默认2人/秒·座椅场景1人/秒)
    
    空→满席（如观众席0→200人）: 需要≥200秒（约3.5分钟）
    满席→空（如观众席200→0人）: 需要≥100秒（离场快于进场·但不可秒级）
    空→三五人（如走廊0→5人）: 需要≥3秒（从附近走进·可接受）

  裁决:
    time_gap ≥ required_time → ✅
    time_gap < required_time 且 required_time ≤ 30秒 → ⚠️ 时间压缩·叙事加速
    time_gap < required_time 且 required_time > 30秒 → 🛑 物理不可能
    标注"同时"但人数变化≥10人 → 🛑（"同时"意味着零时间差）
  
  ⚠️ 例外: 切镜回闪/倒叙/平行剪辑故意交叉 → 需标注"非实时"

⏱️-B 环境状态变化:

  天气变化:
    晴天→暴雨: 需要≥5分钟（云层聚集）·秒级切换=🛑
    白天→黑夜: 需要≥30分钟（太阳落山）·秒级切换=🛑（除非场景切换明确标注"数小时后"）
    小雨→大雨: 需要≥1分钟·秒级切换=⚠️
    雨→晴+地面湿: 地面蒸发需要≥10分钟·秒级切换带湿地面=⚠️
  
  光线变化:
    室内灯光突然全灭→全亮: 取决于角色操作·✅（人按开关）
    自然光从正午变黄昏: 需要≥2小时·秒级切换=🛑

  裁决:
    天气突变有过渡镜（哪怕1镜）→ ✅
    天气突变无过渡+秒级时间差 → 🛑
    光线突变由角色操作触发 → ✅

⏱️-C 物体/角色外观突变:

  受伤恢复: 任何伤口在<1天内愈合 → 🛑（除非剧情设定快速愈合）
  服装变化: 正装→睡衣·无换装场景 → ⚠️（需至少暗示换装场景）
  大型道具位移: 沙发从A移到B·无搬运场景 → ⚠️
  妆容/发型突变: 无场景过渡 → ⚠️

  裁决:
    有过渡场景（哪怕1镜交代）→ ✅
    无过渡+秒级时间差 → 🛑（受伤/大型物体）/⚠️（服装/妆容）
```

#### 裁决阈值

```
⏱️-A 人群变化:
  time_gap < required_time 且 diff ≥ 50人 → 🛑 (物理不可能)
  time_gap < required_time 且 diff 10-49人 → ⚠️ (叙事加速·需标注)
  time_gap < required_time 且 diff < 10人 → 💡 (可接受的范围·建议标注)

⏱️-B 环境变化:
  天气秒级突变·无过渡 → 🛑
  自然光秒级突变·无过渡 → 🛑
  天气渐变·有暗示时间流逝(如光线变化)→ ✅
  
⏱️-C 外观突变:
  受伤秒级愈合 → 🛑
  服装/妆容秒级突变 → ⚠️
  有过渡场景 → ✅
```

## 裁决

```
单维度:
  ≥2源确认 → 🛑(解说剧·涉及VO可桥接的过渡→降为⚠️)
  1源触发 → ⚠️
  证据不足 → 💡

🆕 每个⚠️必须附带"独立性根因"声明:
  独立性根因格式: [具体的·不重复的物理/逻辑事实]
  
  例:
    空间逻辑⚠️ → 独立性根因: 角色位置从(x=客厅)直接变为(x=街道)·中间空间路径不可追溯
    因果链⚠️ → 独立性根因: 前因(在客厅)→后果(在街道)·缺少But/Therefore衔接的中间步骤
    
  如果两个⚠️的"独立性根因"指向同一物理事实 → 标记为关联标记
  如果两个⚠️的"独立性根因"指向不同的物理事实 → 标记为独立标记

🆕 加权跨维度交叉升级:
  两个独立标记(根因不同·两个不同的问题) → 🛑
  两个关联标记(根因相同·同一问题的两面) → ⚠️升级为"加强警告"·不升级为🛑
  三维⚠️(至少两个独立·一个可关联) → 🛑
  三维⚠️(全部关联·同一根因) → ⚠️升级为"严重警告"

综合:
  任何维度 ≥2🛑 → 整体阻断
  1🛑 + ≥3⚠️ → 整体阻断
  仅⚠️/💡 → 标注后继续
  全部✅ → 通过
```

## 场记库（🆕 v3.2持久化增强）

> **v3.2增强：** 场记库不再仅作为审计报告的附属文本。改为独立的持久化文件——每集precheck完成后输出独立场记库文件，供下一集precheck自动加载。解决了原设计中"用户需手动提供上一集审计报告"的脆弱性。

### 输出方式

```
precheck完成后·生成独立场记库文件:
  scene_log_EP[X].md 或嵌入在审计报告末尾的```场记库```代码块中
```

### 跨集加载协议

```
EP [X+1] precheck启动时:

  1. 检查是否存在 scene_log_EP[X].md 或上一集审计报告中的场记库
     存在 → Read加载 → 继承全部状态
     不存在 → ⚠️ 无场记库·从零开始·标记"跨集状态缺失"

  2. 加载后·按需提取:
     ┌─ 正常时序: 读取"末帧快照" → 作为EP[X+1]的初始状态
     ├─ 闪回/倒叙: 读取对应场景的中间状态快照
     └─ 跨集线索: 检查是否有本集应回收的线索

  3. 加载完成后·更新场记库·在EP[X+1]审计结束时产出新的场记库
```

### dispatcher 集成
