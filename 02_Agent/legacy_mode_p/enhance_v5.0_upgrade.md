
## 变更4: 优先级响应
```
enhance在修复时必须遵循优先级:
  P0(🛑阻断) → 必须修复·不可降级
  P1(⚠️警告) → 应该修复·用户可覆盖
  P2(💡建议) → 可以修复·不必须
  P3(ℹ️风格) → 可选·用户意图优先

修复冲突时按 dispatcher §0 优先级铁律裁决
```
