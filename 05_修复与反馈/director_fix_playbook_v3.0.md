# FIX-01：场景切换无过渡镜

## 根因分析

**为什么这是问题：**
Seko 独立生成每个分镜。如果分镜#2结束在"门外"，分镜#3开始于"客厅内"，Seko 不知道中间发生了什么——它会凭空生成一个"客厅"画面，而没有"开门→进入"的视觉逻辑。结果是两个分镜在空间上割裂。

**知识来源：** SPA-CASE-01（跨场景无过渡）、SPA-CASE-02（穿越关闭的门）、SPA-MOVE-02（障碍物穿透检测）

## 修复方案

### 方案A：插入独立过渡镜（首选）

```
❌ 修复前:
#2 @公寓楼门口 → #3 @公寓客厅（跳）

✅ 修复后:
#2  @公寓楼门口 · @林月 的手放在门把手上——正要推门。
    运动状态：静止 · 手部微动——握住把手。
    📐 静态 · 0s · 中景 · 2秒

#2B 🆕 @公寓走廊/门口 · 门正在被推开——走廊的光从门缝中漏进昏暗的室内。
    @林月 的侧影轮廓出现在门口。她的一只脚跨过门槛。
    运动状态：门正在打开 · 中速。
    📐 缓慢推近 · 0.3x · 门缝→室内 · 3秒
    > 过渡镜——承载"门外→门内"的空间切换

#3  @公寓客厅 · 承接上一镜——@林月 刚走进客厅，身后门轻轻碰上。
    运动状态：正在步行 · 慢速 · 从门口向沙发。
```

**核心原理：** 过渡镜的第一帧 = 分镜#2末帧的下一个状态（手放在门把手上）→ 过渡镜的末帧 = 门已开、人已在门槛上 → 分镜#3首帧承接这个状态。

**适用场景：** 所有跨场景切换（门/走廊/电梯/楼梯/车窗）

### 方案B：利用离开/进入信号（过渡镜不可行时）

```
✅ #2末帧添加离开信号:
#2  @公寓楼门口 · @林月 推开门——她的背影被走廊光吞没。门在她身后缓缓闭合。
    📐 缓慢拉远 · 0.3x · 她的身影消失在门缝中 · 3秒

✅ #3首帧添加进入信号:
#3  @公寓客厅 · 门从内侧被推开——@林月 走进来。门在她身后轻轻碰上。
    承接上一镜——她刚从门外进来。运动状态：正在进入 · 慢速。
```

# FIX-02：180度跨线/轴线断裂

## 根因分析

**为什么这是问题：**
观众在心理中建立了一个"空间地图"——角色A在左、B在右。如果下一个镜头突然A在右、B在左，观众的大脑需要0.5-1秒重新建立空间关系。在这0.5秒内，观众不在故事里——在"重新定位"。

**知识来源：** D-TRI-02（首要规则：保持在关系线一侧）、D-F2F-01~09（九种机位变体）

## 修复方案

### 方案A：插入中性过渡镜（跨线前）

```
❌ 修复前:
#2 @公寓楼门口 · 林月从右入画（摄影机在关系线左侧）
#3 @公寓客厅 · 林月出现在画面右侧——跨线了（摄影机跳到了右侧）

✅ 修复后:
#2   摄影机在关系线左侧——林月从右入画
#2B  🆕 中性过渡镜: 林月的背影——她推开门的正面全身镜头。
     这个镜头没有"左侧/右侧"——只有"正面/背面"。
     → 中性镜头重置了观众的左右坐标系
#3   摄影机在关系线右侧——现在林月可以安全地出现在画面右侧
```

**中性镜类型：** 正面全身 / 背影 / 顶视 / 特写（不暴露左右关系） / 门把手转动 / 脚步

### 方案B：用角色移动重定义关系线

```
✅ #2B: @林月 转身面向门口——她的身体重新定向。
    关系线从"她与门的关系"变为"她与门内空间的关系"。
    → 角色移动 = 关系线移动 → 摄影机可以合法换侧
```

### 方案C：统一到一侧（最保险）

```
✅ 所有镜头保持在关系线同一侧。
    检查每个分镜中角色的画面位置——左/右保持一致。
    如果某个镜头必须换侧——插入方案A的中性镜。
```

# FIX-03：景别跳跃无动机

## 根因分析

**为什么这是问题：**
景别变化 = 导演在引导观众的注意力。全景→特写 = "注意这个"。如果跳了但没有叙事上的"注意理由"——观众会觉得镜头飘忽不定。

**知识来源：** §2A-A1（景别选择决策树）、§3A-A3（景别切换必须有动机）、C-COM-01（构图六要素）

## 修复方案

### 方案A：埋入动机（首选）

```
❌ 修复前:
#3 近景（两人对话） → #4 中景（无理由跳回）

✅ 修复后:
#3 近景 · @林月 站在门口。她的手指在背后握紧了。
    > 🎬 动机埋入: "手指在背后握紧"——这是下一镜景别变化的动机
#4 中景 · 承接上一镜——从 @林月 紧握的手指拉开，她整条手臂都是僵硬的。
    @陈浩 站起来朝她走了一步。
```

**动机类型速查：**

| 下一镜景别 | 可选动机 |
|-----------|---------|
| 近景→特写 | 微表情变化 / 眼眶泛红 / 嘴角抽动 / 吞咽 |
| 中景→近景 | 手部动作开始 / 身体前倾 / 转头 |
| 全景→中景 | 角色开始移动 / 有人进入空间 |
| 近景→全景 | 拉开揭示环境 / 有人从背后接近 |

### 方案B：删掉无动机跳跃

```
✅ 如果#3→#4的景别跳跃找不到任何合理的叙事动机 → 删除这个变化
   保持与上一镜同景别，或合并为一个镜头
```

# FIX-04：运镜类型单调/连续重复

## 根因分析

**为什么这是问题：**
3个分镜全是"极缓慢推近 0.3x"——观众在第4镜开始感到"怎么一直在往里推？"。视觉上的重复 = 情绪上的单调。

**但注意：** 不是所有重复都是问题。一段蓄力型对峙可以连续用极缓慢推近——因为叙事上情绪在持续升温。

**知识来源：** §2C-C2（运镜选择铁律）、§2C-C3（运镜×情绪联动）、K-MOV-03（推轨速度-情绪映射）

## 修复方案

### 方案A：用不同速度制造"呼吸"（连续推近时）

```
❌ 修复前:
#3 极缓慢推近 0.2x · 4秒
#4 极缓慢推近 0.2x · 4秒
#5 极缓慢推近 0.2x · 4秒
→ 三镜同类型同速度·单调

✅ 修复后:
#3 极缓慢推近 0.1x · 5秒  ← 最慢·蓄力
#4 静态 · 0s · 2秒          ← 停在最近处·让观众"呼吸"
    > 🎬 静态理由: "对峙临界点——下一秒就要打破平衡"
#5 快速推近 2x · 1.5秒      ← 爆发·释放蓄力
→ 三镜形成"蓄力→停顿→释放"的呼吸节奏
```

### 方案B：交替推近/拉远（对峙场景）

```
✅ #3 极缓慢推近（逼近一方） → #4 缓慢拉远（另一方退缩） → #5 极缓慢推近（再次逼近）
   推近/拉远交替 = 视觉上的"进退"——直接外化两人的权力拉锯
```

### 方案C：更换运镜类型（叙事不要求推近时）

```
✅ 如果叙事上没有"持续逼近"的需要→把其中一镜的推近换成:
   - 过肩极慢推近（保持推近但有视角变化）
   - 手持轻微晃动（增加不安感）
   - 缓慢横移（揭示空间中的其他元素）
```

# FIX-05：动作状态跨镜突变

## 根因分析

**为什么这是问题：**
这是 Seko 用户反馈 **#1 的视觉Bug**。前一镜车在高速跑 → 后一镜车已静止。Seko 独立生成每个分镜的视频，它不知道上一镜的运动状态。两个视频片段接在一起 → 车瞬停 → 观众出戏。

**知识来源：** M-STATE-01~03（动作状态标注格式）、M-BRIDGE-01~03（桥接格式）、§3A-A2（动作状态接力系统）

## 修复方案

### 方案A：插入减速/加速过渡镜（首选·不可跳过）

```
❌ 修复前:
#6 @公寓客厅 · 两人在扭打·运动状态：正在扭打·快速
#7 @公寓客厅 · 林月已拿到钥匙站到窗边·运动状态：静止
→ 🛑 扭打→静止·无过渡·动作状态突变

✅ 修复后:
#6  @公寓客厅 · 两人扭打·运动状态：正在扭打·快速
    📐 手持晃动·剧烈

#6B 🆕 过渡镜 · @公寓客厅 · @林月 的手抓住了钥匙——钥匙从 @陈浩 的指间被扯出。
    @陈浩 失去平衡，后退了半步。@林月 踉跄着退向窗边。
    运动状态：扭打正在结束·减速中 · @林月向窗边退·中速。
    📐 手持晃动·轻微 → 缓慢拉远 · 2秒+2秒
    > 过渡镜承载了整个状态变化: 扭打(快)→钥匙易手→两人分离(减速)→林月退到窗边(静止)

#7  @公寓客厅 · 承接上一镜——@林月 已经退到窗边，背靠窗户，紧握钥匙贴在胸前。
    运动状态：静止（刚从上一镜的退后中停住）。
```

### 方案B：在📐中描述状态变化（无法加镜时）

```
✅ #6 📐 视频运镜：手持剧烈→缓慢停止 · 3秒扭打+2秒减速分离 · 5秒
   → 将"从运动到静止"的整个过程装入同一个镜头的运镜中
   → Seko 在这个镜头内完成状态过渡
```

### 方案C：承接声明（同一镜头内无变化但跨镜时）

```
✅ #7 【画面：承接上一镜——两人刚分开。@林月 退到窗边……
    运动状态：刚停止移动 · 静止。
    → "刚停止"三个字 = Seko 知道这个角色不是"一直站在这"而是"刚退到这儿"
```

# 🆕 FIX-05B：道具跨场景突现（空间不一致穿帮）

> **v3.1新增 · 审计7D触发 · 严重度: 🛑(关键道具) / ⚠️(重要道具)**

## 根因分析

**为什么这是问题：**
这是 Seko 的第二个高频视觉Bug（仅次于动作状态突变）。Seko 独立生成每个场景的每个分镜，不共享跨场景状态。场景4的【画面：…】写"桌面放着一把黑色手枪"——Seko生成手枪在桌面上。但场景1（同一客厅、同一桌面）的【画面：…】没写手枪——Seko生成空桌面。观众切回场景1的闪回/重访镜头时 → 手枪"凭空消失" → 穿帮。

**与FIX-05的区别：** FIX-05解决的是"同一场景内相邻分镜的运动状态接力"——时间维度上的连续性。FIX-05B解决的是"同一空间跨场景的道具存在一致性"——空间维度上的连续性。两者互补。

**知识来源：** M-STATE-01~03（状态标注）· M-BRIDGE-01~03（桥接）· §7D（跨场景道具反向溯源）· §4A 动作状态接力· OnlyShot #8 道具不一致失败模式

## Plan A：前置场景预埋道具（推荐·治本）

**适用条件：** 道具在时间线上"应该一直存在"（非新购入/非他人刚带来/非场景变化引入）

**操作：**
1. 找出道具首次被提及的场景（场景B·道具出现在空间S）
2. 回溯到空间S首次出现的场景（场景A·同一空间S）
3. 在场景A的【画面：…】中补充该道具的描述
4. 如果场景A和场景B之间有"该空间"的其他场景 → 逐场景补充

```
❌ 修复前（穿帮）：
场景1 · 客厅·白天
分镜#1 【画面：@客厅 · 日 · @李峰 坐在沙发上，茶几空无一物……】

场景4 · 客厅·夜晚（同一客厅）
分镜#12 【画面：@客厅 · 夜 · @李峰 伸手拿起茶几上的黑色手枪……】
→ Seko场景1生成空茶几 → 场景4生成茶几上有手枪 → 穿帮！

✅ Plan A修复后：
场景1 · 客厅·白天
分镜#1 【画面：@客厅 · 日 · @李峰 坐在沙发上，茶几右角放着一把黑色手枪——枪口朝外。茶杯在左，手枪在右。Anchor——茶几·黑色手枪·本空间所有场景跨镜头存在……】

场景4 · 客厅·夜晚（同一客厅）
分镜#12 【画面：@客厅 · 夜 · 承接——茶几右角黑色手枪仍在原位。@李峰 伸手拿起茶几上的黑色手枪……运动状态：手枪从桌面被拿起·移向角色手中】
→ Anchor锁定+运动状态桥接 → Seko两场景生成一致
```

## Plan B：添加道具引入事件（治标·当道具确实不应在前置场景出现时使用）

**适用条件：** 道具在场景A时确实不存在，被角色在场景B时带入

**操作：**
1. 在道具首次出现的场景之前，添加一个"道具引入"分镜
2. 或者在对白中显式交代道具的来源

```
✅ Plan B（道具被带入）：
场景3 · 客厅门口·傍晚
分镜#9 【画面：@客厅门口 · @王磊 推门进来，右手提着一个黑色工具箱。他走到茶几前，打开工具箱，取出一把黑色手枪放在茶几右角。运动状态：手枪从工具箱→被放置到桌面·静止。Anchor——茶几·黑色手枪·本空间所有场景跨镜头存在。】

场景4 · 客厅·夜晚
分镜#12 【画面：@客厅 · 夜 · 承接场景3——茶几右角黑色手枪仍在。@李峰 伸手拿起……】
```

## Plan C：仅前置场景最近一次出现时补充（缩减方案·场景太多时使用）

**适用条件：** 空间S在剧集中出现≥5次，逐场景补充成本太高

**操作：** 仅在"场景B的前一个包含空间S的场景"中补充道具描述。中间场景如果道具不可见（如被其他物体遮挡/不在镜头内）→ 在🚫负面中标注"xx道具不在本镜画面内"以避免Seko随机生成。

## 关键决策表

| 道具类型 | 前置场景缺失 | 引入事件存在 | 裁决 | 修复方案 |
|---------|------------|------------|------|---------|
| 🔫关键道具 | 是 | 否 | 🛑 | Plan A·必须逐场景预埋 |
| 🔫关键道具 | 是 | 是 | ✅→⚠️ | Plan B·检查引入事件的视觉呈现 |
| 📖重要道具 | 是 | 否 | ⚠️ | Plan A或C·建议预埋 |
| 📖重要道具 | 是 | 是 | 💡 | Plan B·确认即可 |

# FIX-06: 运镜速度曲线过山车

## 根因分析

**为什么这是问题：**
静态(0) → 手持剧烈(5) → 静态(0) → 快速推近(5)。观众的身体感受从"不动"直接跳到"被猛摇"再回到"不动"再跳到"被猛推"——在30秒内被甩来甩去四次。这不是"节奏快"——是"没有节奏"。

**知识来源：** §2C-C3（运镜×情绪联动）、§2C-C5（Katz运动-情绪映射）、K-MOV-03（推轨速度的三种情绪效果）

## 修复方案

### 方案A：插入速度缓冲镜

```
❌ 修复前:
#5 静态(0) → #6 手持剧烈(5) → 跳变5级·过山车

✅ 修复后:
#5   静态(0) · 特写·钥匙转动
#5B  🆕 手持轻微晃动(1) · @林月 的眼神从钥匙移到 @陈浩 的脸
      → 缓冲级: 0→1
#5C  🆕 手持晃动·中等(3) · @林月 的身体前倾·准备冲
      → 缓冲级: 1→3
#6   手持剧烈(5) · 两人扭打
      → 到达级: 3→5
```

**核心原理：** 速度变化每步不超过 2 级。0→5 拆成 0→2→3→5 三步。

### 方案B：用"变速运镜"承载过渡

```
✅ #5 📐 视频运镜：静态→极缓慢推近→快速推近 · 0→0.2x→2x变速
   → 一个镜头内完成速度爬坡
   → Seko 生成这个镜头时内部有加速过程
```

### 速度变化安全区间

```
安全:  级差 ≤ 2（如: 0→2, 2→3, 3→5）
警告:  级差 = 3（如: 0→3, 2→5）
危险:  级差 ≥ 4 → 必须拆镜或使用变速运镜
```

```
✅ 修复后:
```

# FIX-09：视觉能量流断裂/过载

## 根因分析

**为什么这是问题：**
Block 七组件理论：相邻分镜间七个视觉组件（空间/线条/形状/影调/色彩/运动/节奏）的变化量 = 观众的"视觉冲击量"。

- 变化量 = 0 连续多镜 → 视觉疲劳·观众觉得"画面没变化"
- 变化量 ≥ 4 连续多镜 → 视觉过载·观众觉得"画面太乱"

**知识来源：** BLK-01~12（七视觉组件与对比/亲和力）、C-VIS-01~07（视觉组件与对比度）、§1B（对比与亲和力）

## 修复方案

### 方案A：为"疲劳区间"注入变化

```
❌ 修复前:
#3→#4→#5 三个镜头: 
  空间: 深·深·深 | 影调: 低调·低调·低调 | 色彩: 暖·暖·暖
  → 变化量 = 0·连续3镜 → 视觉疲劳

✅ 修复后:
#3 深空间 + 低调 + 暖色（台灯） + 静态
#4 🆕 改一个组件: 平空间 + 低调 + 暖色 + 极慢推近
    → 变化量 = 2（空间从深变平 + 运动从静态变推近）
    → 进入健康区间
#5 深空间 + 中调 + 暖色 + 手持轻微
    → 变化量 = 2 → 继续健康区间
```

**最小修改原则：** 只改 1-2 个组件的对比度等级，不需要重新设计整镜。

### 方案B：为"过载区间"降低变化

```
❌ 修复前:
#6→#7: 空间(深→平) + 影调(低调→中调) + 色彩(暖→冷) + 运动(剧烈→静止)
  → 变化量 = 4 → 过载

✅ 修复后:
#6 深空间 + 低调 + 冷色 + 手持剧烈
#7 深空间 + 低调 + 冷色 + 静态
  → 只改运动组件（剧烈→静止），其他三个保持不变
  → 变化量 = 1 → 健康
  → 观众只感受到"动作停了"——而不是"整个世界都变了"
```

### 变化量速查

| 变化量 | 判定 | 操作 |
|:---:|------|------|
| 0 | 完全静止 | 连续≥3镜 → 增加1个组件的变化 |
| 1-2 | ✅ 健康 | 微妙变化·观众潜意识感知 |
| 3 | ✅ 可接受 | 明显变化·适合情绪转折点 |
| 4-5 | ⚠️ 过载 | 非情绪转折点 → 降低至≤3 / 情绪转折点 → 可以保留但仅限1镜 |
| 6-7 | 🔴 混乱 | 必须降低 |

# FIX-10：运镜×情绪曲线错位

## 修复方案

### 方案A：对齐运镜方向到情绪方向

```
情绪方向 → 运镜方向映射:

  情绪升温（愤怒累积/真相逼近/欲望增强）:
    → 推近类 / 仰拍类 / 手持加剧 / 快速推近
    → 🚫 禁止: 拉远 / 俯拍 / 静态

  情绪降温（失望/放弃/退缩/告别）:
    → 拉远类 / 俯拍类 / 缓慢拉远 / 静态
    → 🚫 禁止: 推近 / 仰拍

  情绪转折（反转/真相揭露/角色觉醒）:
    → 变速运镜 / 复合运镜 / 荷兰角 / 快速推近
    → 🚫 禁止: 静态 / 同速推近

❌ 修复前:
情绪: 对峙升温（@陈浩逼近·@林月后退·张力↑）
运镜: 缓慢拉远 0.3x ← 方向矛盾

✅ 修复后:
情绪: 对峙升温
运镜: 极缓慢推近 0.1x · @陈浩的中景→近景
      → 运镜方向 = 情绪方向（都在"逼近"）
```

### 方案B：利用"反向运镜"制造特殊效果（有意为之时）

```
✅ 如果导演有意为之（如: 强调角色的无力感）:
   情绪: 对峙升温但 @林月 感到无力
   运镜: 缓慢拉远——她在逼近的威胁面前"变小"
   → 这是合法的艺术选择——但必须在决策卡中标注理由:
   > 🎬 反向运镜: 拉远 vs 情绪升温 —— 目的: 外化 @林月 的主观无力感
```

### 方案C：情绪双人时的"双运镜"

```
✅ 对峙中两人情绪方向相反:
   @陈浩（进攻·升温） → 低角度仰拍·推近
   @林月（退缩·降温） → 高角度俯拍·拉远
   双人交替镜头 = 推近/拉远交替 = 权力拉锯的视觉化
```

# 🆕 FIX-13：运镜×对白不同步

## 根因分析

**为什么这是问题：**
推近到位后0.5秒才念出关键词——观众的注意力已经在"推近"时被引导到角色脸上，然后在等待关键词的0.5秒内注意力开始飘散。反之——关键词已经念出但推近还没到位——观众听到了重要信息但没有视觉强化。两者都让"推近"和"台词"各自为战而非协同作战。

**知识来源：** Murch准则#3节奏(10%) + Katz问答模式(K-DIA-04) + O'Steen反应镜头优先(E-CUT-03)

## 修复方案

### 方案A：对齐运镜到达点到关键词（首选）

```
❌ 修复前:
📐 缓慢推近 · 0.3x · 中景→近景 · 4秒 · slow push
对白: "你知道吗...（停顿）...我从来没有爱过你。"
→ ⚠️ 推近4秒到位后"我从来没有爱过你"才说出口——偏差>1秒

✅ 修复后:
将📐拆分为两个动作:
📐 缓慢推近 · 0.3x · 中景→中近景 · 2.5秒 · slow push
   → 推近到位在"你知道吗..."的停顿处
📐 极缓慢推近 · 0.1x · 中近景→近景 · 1.5秒 · extreme slow creep
   → 第二次推近到位恰好落在"我从来没有爱过你"的第一个字

原则: 推近的"到达"瞬间 = 关键词的"出口"瞬间
```

### 方案B：用运镜停顿制造对白悬念

```
✅ 📐 缓慢推近 · 0.3x · 中景→近景 · 3秒
   → 推近到位后: 停顿·0.5秒静止
   → 对白在停顿后: "是你杀了她。"
   
   推近到位→停顿→关键词 = 悬念三部曲
   观众: "推近了...停住了...他要说什么？" → 关键词落下 = 最大冲击
```

### 方案C：对白间歇的正确运镜选择

```
对白停顿/沉默 ≥ 2秒时的运镜选择:

✅ 保持当前运镜（静态/极慢推近）= 让沉默"说话" 
✅ 极慢推近 · 0.05x = 沉默中情绪升温
⚠️ 拉远 = 沉默中疏离感（如有意图→标注）
🚫 手持剧烈/快速推近/荷兰角 = 打破了沉默的力量（除非是惊吓/scare）
```

```
分镜#14 【画面：@安全屋 · 10分钟后 · @李峰 左肩已被白布条简单包扎。
         白布条上有暗红血迹渗透痕迹——约核桃大小。布条系结在右肩。
         受伤状态延续——伤口已包扎·绷带可见·血迹干涸暗红。】
         → 包扎后状态明确+时间流逝匹配
```

## Plan B：受伤状态声明（简化版·场景太多时使用）

```
✅ 【画面：@街头 · @李峰 左肩绷带仍在——白布条在夹克下微隆起。他行动时左臂略有僵硬。
    受伤状态延续·左肩枪伤(已包扎)·绷带不可见(在夹克内)·左臂活动受限。】

```
