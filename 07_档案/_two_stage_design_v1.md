# MODE:P 两阶段设计 v1 — 意图先行·参数后填

> **设计日期:** 2026-07-08
> **核心改变:** 当前管道让 Agent 同时思考"这个镜头是干什么的"和"用什么参数拍"。
>   两阶段设计把这两个拆开：先确认意图正确，再填充参数。
>   意图不对，参数全废。意图对了，大半参数可以推导。

---

## 第一阶段：导演意图 Agent

输入: MODE:A 增强剧本（含角色心理标注·情绪弧线·叙事节奏）
输出: 每镜的"导演功能卡"——不说怎么拍，只说为什么拍

### 意图卡格式

```
镜#[N] · [场景位置] · [涉及角色]

叙事功能: [一句话·这个镜头在整场戏里干什么]
  - 建立 / 推进 / 转折 / 揭示 / 反应 / 收尾

角色心理: [这个镜头里角色的内心状态]
  - Vincent: 从专注→怀疑→确信
  - Miguel: 从倾听→意识到被欺骗

观众感受: [希望观众感受到什么]
  - 不安 / 好奇 / 紧张释放 / 恍然大悟 / 压抑

情绪弧线位置: [在整场戏的情绪曲线上的位置]
  - 开场冷建立 / 上升 / 第一次转折 / 高潮 / 回落

视觉母题: [如果有·贯穿性视觉元素]
  - 螺旋 / 冷暖色温交界 / 光的遮蔽与揭示
```

### 为什么第一阶段不过参数

1. 人类导演不会在第一次读剧本时想"这里用 50mm 还是 85mm"
2. 先想通的不是技术参数，是"观众应该看到谁的眼睛"
3. 意图如果错了——比如把一个反应镜头当成建立镜头——参数全白做
4. 意图比参数更容易审查：人对 vs 人+系统辅助

---

## 第二阶段：参数填充

输入: 第一阶段输出的意图卡 + 剧本原文 + 空间地图 + 角色锚点
输出: 完整 segments_camera YAML + 台本

### 填充策略

| 意图类型 | 填充方式 | LLM参与 |
|---------|---------|:---:|
| 标准建立镜头 | 约束菜单自动: 全景·24mm·固定 | 零 |
| 标准对话双人 | 约束菜单自动: 中景·35mm·外反拍 | 零 |
| 标准物件特写 | 约束菜单+历史参考: ECU·100mm·侧光 | 零 |
| 标准单人对白 | 约束菜单自动: 近景·50mm·固定 | 零 |
| 人物出场/过渡 | 历史模式匹配: 参考相似情绪的历史方案 | 部分 |
| 情绪转折镜头 | LLM 设计: 参数服务于角色心理 | 需要 |
| 动作/运动镜头 | LLM 设计: 运镜速度/路径需要叙事判断 | 需要 |
| 场景收尾/空镜 | 约束菜单: 全景·24mm·固定 | 零 |

### 参数推导逻辑

```
意图: "Miguel沉默反应·他意识到Vincent在骗他"
  ↓
默认: 近景·50mm·固定 (标准单人反应)
  ↓
情绪强度: 沉默→冰冷 (不是爆发·是内收)
  ↓
调整: 从50mm换85mm·更近·更压迫
  ↓
光影: 保持前镜光源·但让Miguel面部进入更深的暗区
  ↓
运镜: 极慢推近0.05x·2秒·让观众"靠近"Miguel的沉默
```

**核心**: 90%的参数从意图类型推导。只有情绪需要调整的部分才让 LLM 介入。LLM 不"设计全部参数"——它在默认模板上做情绪驱动的微调。

## 审查层

### 意图审查 (人对·系统辅助)

1. 每镜意图卡输出后 → 人类快速扫一眼功能标注是否正确
2. 系统辅助: 自动检查功能标注一致性——
   "镜#3标注为'建立镜头'但前镜#2已建立·且#3是特写→标记'功能冲突'"
3. 人对 → 意图锁定 → 进入参数填充
4. 人否定 → 只改意图卡·不改参数

### 参数审查 (系统自动·人对异常)

1. Gate 0: 格式合规 (零 token)
2. Spatial: 空间安全 (零 token)
3. Intent-to-Param: 参数是否符合意图类型 (查表)
4. Scene Auditor: 只审 LLM 设计的部分 + 跨镜连贯性

## 与当前流程对比

| | 当前流程 | 两阶段流程 |
|------|---------|---------|
| Agent 第一遍输出 | 景别+焦距+运镜+光影（全部） | 叙事功能+角色心理+观众感受 |
| 人的角色 | 看完所有参数后判断 | 看完意图后判断·参数自动填 |
| 参数来源 | Agent 从头设计 | 90%从意图推导·10% LLM微调 |
| 修改成本 | 改参数=重跑 Agent | 改意图=改几行文字·参数自动更新 |
| Agent 输入 | 剧本+866条KB+5公共文件 | 剧本+意图卡+约束菜单 |
