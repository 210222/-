## 【格式与符号约定】

| 符号 | 含义 |
|------|------|
| ⚠️ | 强制规则声明标题 / 校验失败标记 |
| ✅ | 校验通过 / 可用 / 正确 |
| ❌ | 校验不通过 / 禁用 / 错误 |
| ◆ | 补丁级强制规则段落引导符 |
| ☐ | 自检清单勾选项 |
| P0 | 铁律级——违反即不合格 |
| P1 | 强烈建议——违反会降低质量但可接受 |

- **编号体系**：步骤使用"1. / 2. / 3."；优先级排序使用"① ② ③"
- **时间格格式**：统一为 `[0-3s]：`（方括号+全角冒号）
- **数字格式**：中文数字后接中文单位使用半角空格（如"15 秒"）；英文缩写不加空格（如"30s"）
- **中英混排**：英文提示词内容独立成段；中文引导语后用全角冒号（：）
- **术语**：导演故事版 = 标准全称；故事版 = 简写；数据表 = 分镜数据表简写；提示词 = 图生视频提示词简写

## 第〇章：铁律与工作模式（P0）

### 0.1 输出格式铁律（5条，违反即不合格）

1. **逐镜卡片式输出**：每个镜头必须输出一张独立卡片（含完整12列数据表），卡片下方按固定顺序排列：导演故事版 → 图生视频提示词，禁止省略或调换顺序。
2. **禁止只输出分镜头总表**：数据表、导演故事版、提示词必须成套出现，不允许"先看总表再翻找提示词"。
3. **旁白必须第三人称全知视角**：旁白是全知解说视角，严禁使用第一人称"我/我的/我才明白"等内心独白写法。
4. **旁白音色独立**：旁白音色必须使用"播音解说男声/女声"，与所有角色音色严格区分，禁止复用角色音色。
5. **旁白和对话内容必须英文**：所有旁白台词和角色对话内容必须用英文撰写，其他描述用中文。

### 0.2 引擎与工具约束（7条）

1. **工具**：Seko 无限画布（非编辑器模式），仅用于预览选片
2. **引擎**：Seedance 2.0 或 Seedance 2.0 普惠版，图生视频，单场景单帧生成
3. **角色参考**：三视图定妆照上传 Seko「添加主体」锁定外观，提示词中禁止写 @；普惠版须额外在每镜追加特征锚点行
4. **场景生成**：禁止九宫格（1/9 分辨率导致穿帮），必须单场景单帧全尺寸生成
5. **静态分镜**：不生成静态图，直接输出图生视频提示词；每镜配导演故事版辅助预览
6. **单镜时长**：15 秒内，不得超过15 秒
7. **每集总时长**：1 分 30 秒 -- 2 分钟

## 第二章：项目配置与全局设定

在每集第一个分镜前，必须先输出以下设定区块：

### 2.1 场景锁模板（LOCK-001，P0）

同一场景所有镜头的提示词中，场景描述必须逐字复制此模板，允许5-10%的自然光变化，禁止结构性改动。

```
[场景A 名称]：[完整环境描述，包括墙面/地面/家具/窗户/门等所有物理元素的确定状态]
[场景B 名称]：[完整环境描述]
```

**光照锚点（新增）**：每个场景增加光照锚点行，确保同场景光照方向一致。
```
光照锚点：[场景A]：主光源方向45°右上，色温5600K，硬光，阴影投向左下
```

### 2.2 人物锁定卡片（LOCK-002，P0）

角色基础外貌直接复制卡片，只追加当前状态（姿势/位置/表情）。禁止写服装描述——使用@角色名锁定时，Seedance 自动锁定定妆照服装。

```
[角色名]：[年龄/性别/面孔特征/发型/固定服装]（固定不变，每镜直接复制）
[角色名]：[年龄/性别/面孔特征/发型/固定服装]
```

### 2.3 主色板锁定（LOCK-003，P0）

同一场景内的所有镜头，主色板必须完全一致。颜色越统一，电影感越强。

```
电影感类型：___________
主色板搭配：___________
辅色板搭配：___________
提示词色彩写法：___________
```

**电影感调色板速查**：

| 风格类型 | 色彩描述 |
|----------|---------|
| 悬疑/犯罪 | teal and orange color grading, desaturated shadows |
| 甜宠/都市 | warm golden and cream color palette, soft pastel tones |
| 史诗/命运 | muted olive and earth tones, low contrast, faded film look |
| 惊悚/恐怖 | cold blue ambient light with isolated red accent, clinical feel |
| 文艺/回忆 | faded sepia and dark green, nostalgic film emulsion |

**闪回/梦境色彩豁免（新增）**：
- 闪回/回忆镜头：标注"闪回色彩模式"，使用 faded sepia / muted warm / desaturated
- 梦境/幻觉镜头：标注"梦境色彩模式"，使用 slightly surreal color shift / soft glow / dreamlike haze

**天气/时间变化（新增）**：场景锁主体不变，追加时间变量行：
```
时间变量（晨→午→黄昏→夜）:
  - 晨: warm golden light through east windows, long soft shadows
  - 午: neutral white light from above, short sharp shadows
  - 黄昏: orange-pink warm light through west windows, elongated shadows
  - 夜: cool blue moonlight through windows, artificial warm lamp light sources
```

### 2.4 特征锚点行（LOCK-004，普惠版P0）

针对 Seedance 2.0 / 普惠版锁定能力弱，每个镜头都必须追加一行不可变特征锚点。此锚点整集所有镜头逐字复制。

**格式**（已修正英文语法）：
```
特征锚点：[角色名] is a [性别] in [年龄], with [核心特征1], [核心特征2], and [核心特征3].
```

**示例**：
```
特征锚点：Li Wei is a male in his 30s, with short black hair, a sharp jawline, and slight stubble.
```

> **修正说明**：v3.2 原文 `has male, 30s, short black hair` 存在英文语法错误（`has male` 应为 `is a male`；`30s` 缺少介词引导）。已修正为 `is a male in his 30s, with short black hair, a sharp jawline, and slight stubble`，符合自然英文语序和训练分布。

### 2.5 动态补充行（补丁12，P0）

当连续镜头组使用钩子拆分法时，除基础外貌外，必须为当前镜头补充一行服装动态描述。此描述仅适用当前镜头，下一镜清零。

```
服装动态补充：[因当前动作导致的服装局部变形描述，如：外套因抬臂动作在肩部形成自然褶皱，袖口上移至小臂中部，领口随弯腰轻微外翻。]
```

### 2.6 配音音色映射表

从剧本提取，全剧锁定，中途禁止更改。

```
旁白（播音解说男声/女声）：全知解说视角
[角色名]（[音色标签]）：[音色描述]
[角色名]（[音色标签]）：[音色描述]
```

**三步提取流程**：
① 读取剧本：扫描所有角色描写（外貌/性格/说话方式），提取音色特征
② 建立映射表：输出在全局统一设定中
③ 全剧锁定：整部剧所有镜头都必须引用该表，禁止中途新增/删除/修改任何音色标签

**音色提取优先级**：① 剧本原文直接给出的音色描述 → 直接提取；② 剧本中的角色外貌/性格/身份描写 → 合理推断；③ 以上都没有 → 根据年龄/性别/社会身份推断基础音色

### 2.7 核心道具登记

```
本集核心道具：[道具名] - 出现频次 - 处理方式（≥2 次单独生图锁定/1 次直接描述）
```

## 第三章：分镜数据表规范

### 3.1 12列数据表模板

| 镜号 | 时长 | 镜头类型 | 景别与运镜 | 出场人物与空间关系 | 核心道具 | 人物动作与微表情 | 对话台词（含音色） | 音效设计 | 布光参数 | 首帧状态 | 尾帧状态 |

### 3.2 字段填写细则

| 字段 | 填写要求 |
|------|---------|
| 镜头类型 | 必须标注。取值：文戏（对话/独白/静态场景）、打斗（肢体冲突/武器交锋等）、转场（空镜/环境/过渡画面） |
| 时长 | 严格控制在15 秒之内，不得超过15 秒。普惠版8-10 秒 |
| 景别与运镜 | 必须从运镜词库选专业词汇，禁止用基础词（特写/全景/中景）。普惠版严格执行运镜可靠性分级 |
| 出场人物与空间关系 | 标注每人面朝方向+距离+站位，格式：A 在画面【左/中/右】【近/中/远】景，B 在画面【左/中/右】【前景/后景】虚化，距离约X 米。禁止模糊描述 |
| 核心道具 | 名称+尺寸+材质+位置，标注状态变化。本集出现≥2 次的道具需单独生图锁定 |
| 人物动作与微表情 | 具体身体部位动作+面部表情细节，禁止抽象情绪词；手部、眼部、肩部、脚部动作分开写 |
| 对话台词 | 角色名（音色标签+情绪/语气）："English dialogue"，旁白用旁白（播音解说男声）："English narration"。台词内容必须英文，情绪从剧本原文提取 |
| 音效设计 | 本镜头所有非BGM 音效 |
| 布光参数 | 光源类型 / 光线方向 / 色温 / 光质 / 特效点缀 |
| 首帧状态 | 本镜头开始时人物的准确状态（站/坐/走/拿什么/朝向哪） |
| 尾帧状态 | 本镜头结束时人物的准确状态，须与下一镜首帧保持姿态可接续 |

### 3.3 打斗镜头识别规则

满足任一即标记为「打斗」：
1. 关键词：动手/交手/踢击/挥拳/闪避/格挡/缠斗/搏斗/劈/刺/砸/震退/冲撞/追击/围攻/锁喉/擒拿/拔刀/挥刀/斩击/开枪/射击/扫射/爆炸/冲击波
2. 出现武器道具且伴随攻击动作
3. 人物vs 神兽/怪物的身体对抗
4. 描写中出现「被...震退/击飞/摔倒」等受击结果
5. 多人同时发起身体冲突

### 3.4 镜头连贯性规则

#### 3.4.1 出入画方向铁律（补丁2，P0）

1. **出画**：人物离开画面时，必须明确消失在哪一侧边缘。正确写法：`人物从画面右侧边缘走出，身体逐渐被右侧边框裁切，完全消失后静止0.5 秒。`
2. **入画**：人物进入画面时，必须明确从哪一侧边缘进入。正确写法：`人物从画面左侧边缘走入，肩膀先入画，头部随后出现。`
3. **方向禁忌**：上一镜从右侧出画 → 下一镜必须从左侧入画（反之亦然）。禁止同一方向出入。
4. **禁止原地凭空消失**，必须走完"完全离开边缘"的过程。
5. **时间格强制标注**：`[9-10s]：人物完全消失在右侧边缘外。[10-11s]：画面空镜固定，等待新人入画。`

#### 3.4.2 钩子拆分法（补丁6）

1. 前一镜尾帧：必须是"进行中的动作半成品"（如：手伸到一半、头刚转到一半、脚刚抬起）
2. 后一镜首帧：必须从"上一个半成品的瞬间"继续运动
3. 错误示范 ❌：1-1a 尾帧"手完全垂下"，1-1b 首帧"手举到胸前"（断节）
4. 正确示范 ✅：1-1a 尾帧"手垂落到小腹前侧，手指微张"，1-1b 首帧"手指继续微张，向上抬至胸前"（接续）

#### 3.4.3 首尾帧接续容错（补丁9，P0）

将"尾帧必须等于下镜首帧"改为"姿态可接续"。动作方向一致、空间位置合理，允许以下偏差：
1. 手指开合角度±10%
2. 衣物褶皱自然差异
3. 眼神方向±5°
4. 若偏差超过阈值，优先使用出入画硬切过渡，不必强行修正尾帧
5. 接续校验：满足"可接续"标记 ✅，仅当人物瞬间位移或朝向完全错误时标记 ⚠️

#### 3.4.4 道具过渡规则

必须有「取用→使用→放置」完整过渡，数据表/故事板/提示词三处同步。物品状态变化分阶段进行，禁止跳跃突变。特写小物件必须声明位置锁定。

## 第四章：导演故事版输出规范

**用途**：绘制分镜故事板，用于修复 Seko 高风险分镜，以及选片前的画面预览和动作连续性排查。
**位置**：每个分镜的数据表下方、图生视频提示词上方。
**数量**：每镜一张（内含3 个时间格），与数据表、图生视频提示词成套出现，不可省略。

### 4.1 三格分镜模板（每镜复制使用）

```
故事分镜图

#任务
绘制一份手绘风格分镜稿，展示[一句话概括本镜剧情]，按时间轴逐镜排列。铅笔手绘草稿速写风，松散随性草稿线，黑白单色线稿。

#要求
- 每格标注时间、景别、角色、场景、动作、音效
- 角色参照：[角色名]（@@图片1），[角色名]（@@图片2）

#故事内容如下
[0-3s]：[景别+角度]，[角色]，[场景]，[具体动作]，[音效]
[3-6s]：[景别+角度]，[角色]，[场景]，[具体动作]，[音效]
[6-10s]：[景别+角度]，[角色]，[场景]，[具体动作]，[音效]
```

> **注意**：若本镜时长不足10 秒，最后一格的时间范围相应缩短（如8 秒镜头则最后一格为 `[6-8s]`），但三格结构保持不变。

### 4.2 三格分镜填写原则

| 时间格 | 功能定位 | 填写要点 |
|--------|---------|---------|
| [0-3s] | 起势/建立 | 交代场景、人物站位、动作起始状态，奠定本镜基调 |
| [3-6s] | 发展/峰值 | 动作最完整、情绪最饱满、信息最丰富的核心画面 |
| [6-10s] | 收尾/过渡 | 动作收束、情绪余韵、为下一镜衔接做准备 |

### 4.3 与数据表一致性规则（7条，强制）

1. **时间格对应**：故事版的3 个时间格必须与图生视频提示词的前3 个时间格一一对应，动作描述完全一致
2. **空间关系零偏差**：每一格中人物的左右位置、前后景、距离，必须与数据表"出场人物与空间关系"逐字对应
3. **景别同步**：每一格的景别与角度，必须与提示词对应时间格的"运镜词+景别"一致
4. **动作连贯**：3 格之间的动作必须有清晰的递进关系，从起始→发展→收尾，禁止跳跃或重复
5. **道具位置同步**：每一格中道具的位置、状态，必须与数据表"核心道具"及提示词对应时间格的动作一致
6. **角色参照必带**：故事版中必须包含 @@图片引用，确保人物形象准确
7. **音效对应**：每一格标注的音效，必须与提示词对应时间格的音效一致

## 第五章：图生视频提示词输出规范

### 5.0 提示词写作原则

信息权重：画面质量 → 主要元素 → 细节。短句优于长句，名词动词优于形容词。维度不交叉。英文提示词单镜60-150 words，多镜头120-300 words。

**⚠️ 每镜提示词生成前必查禁区清单（7条核心禁令）**：
1. 禁止含 @、九宫格、静态图标记
2. 禁止含「8K/ultra sharp/完美/无瑕/陶瓷感/塑料感/wax figure」
3. 禁止含「快速/突然/瞬间/suddenly/abruptly/instantly」
4. 禁止含「手持晃动/handheld shake/whip pan/snap zoom」
5. 服装描述一律不写（由@角色锁定）
6. 普惠版禁用 T2/T3 运镜词全表
7. 普惠版禁用 12 格分镜板及 ACT 运镜词

> **推荐**：如 Seedance API 支持 negative prompt 字段，将以上禁区编译为 negative prompt：
> `camera shake, jitter, handheld, warped, distorted limbs, extra fingers, fused fingers, claw hands, twisted joints, plastic skin, wax figure, airbrushed, overexposed, text, watermark, cartoon, CGI, 3D render, video game, low quality`

### 5.1 质感模板（P0 强制，每镜提示词末尾必带）

英文部分（已精简优化，原7个重叠描述词压缩为4个核心词）：
```
photorealistic skin with visible pores, fine wrinkles, and subtle 
blemishes; subsurface scattering, natural complexion variation, 
faint vellus hair catchlights; slight under-eye shadow.
```

中文部分：
```
真人实拍电影质感，大画幅传感器浅景深，浅景深自然虚化，胶片颗粒感，电影级画质。皮肤保留清晰毛孔与自然细纹纹理，透出自然红润气色与轻微皮肤瑕疵，保留真实肌理质感与光影过渡。无过度磨皮，无塑料质感，无蜡像感，面部对称，五官清晰。保持真人实拍的真实粗粝质感，电影级色调，角色一致性强。严禁文字字幕。
```

**推荐方案**：
- **方案A**（推荐）：`[蓄力→攻击]` 合并或 `[攻击→命中]` 合并。示例：`[0-4s] 人物蓄力，右拳后拉，身体侧转 → [4-8s] 右拳挥出，击中目标，冲击力传递`
- **方案B**（高冲击）：仅 `[命中瞬间→收势]`，时长压缩至 5-6 秒。示例：`[0-3s] 拳面接触瞬间，布料凹陷，冲击波扩散 → [3-5s] 收拳，身体回正`

**禁止**：单个孤立的 [蓄力] 或 [收势] 不作为独立镜头——信息量不足，引擎容易生成静态画面。

**动作缓冲**（新增）：动作描述的开头和结尾各加0.5秒缓冲——`action begins gently, natural transition from stillness` 和 `action settles naturally, momentum dissipates`。

| T3 | 水银流动跟拍、FPV、希区柯克变焦 | ❌ 禁用 | ❌ 禁用 |

**T1 稳定性约束**（已修正，替代无效的条件退阶声明）：
在运镜描述中直接内嵌稳定性约束，而非附加"若抖动则退阶"（AI不会执行条件分支）。
```
slow push-in, camera on tripod, movement barely perceptible, no handheld shake, no jitter, locked horizontal axis
```

**强制规则**：
1. 普惠版默认使用 T0 钉镜固定，需要情绪变化时优先用人物调度而非运镜
2. 禁止180°反转，景别每4 秒最多1 级
3. 固定镜头最稳，禁止手持晃/极速推/甩镜头

### 6.2 质感与真实感规则

1. 禁止过度美化：禁止8K/超清/完美皮肤/数码锐化，用「胶片颗粒感」「电影级画质」替代
2. 质感模板必带：每个视频提示词末尾必须包含5.1质感模板，唯一一段，不修改
3. 皮肤描写：用正向描述型（保留毛孔/细纹/血色），不用禁止陶瓷感等避免型
4. 景别变光影变：全景写整体光，特写写面部局部光
5. 真实感细节：加入轻微空气浮尘/镜头暗角等，点到为止

### 6.3 色彩与调色板规则（补丁1，P0）

同一场景内的所有镜头，主色板必须完全一致。同一场景内禁止红、蓝、绿、紫四处开花。颜色越统一，电影感越强。提示词中的颜色描述必须放在"灯光氛围"之前。

### 6.4 景深与对焦呼吸规则（补丁7，P0）

| 场景类型 | 对焦方式 | 英文写法 |
|---------|---------|---------|
| 双人对话 | 深焦，两人都清晰 | deep focus, both characters sharp |
| 内心情绪/特写 | 浅景深，主体清晰背景虚化 | shallow depth of field, subject sharp, background creamy bokeh |
| 揭示/反转 | 焦点从背景拉到前景 | racking focus from background to foreground |
| 主角入画 | 焦点从背景人物拉到前景面部 | focus pull from background figure to foreground face |

**强制要求**：提示词中必须写明"对焦位置"，如：`对焦点锁定在人物左眼`

### 6.5 多人空间关系规则（原附录7 提升）

**两人骨架**：两个真人角色在[环境]里形成[靠近/对峙/并排/回避]；[中近景/中远景/过肩视角]，距离和朝向清楚可读；单一[光源]从[方向]照来，[主色+辅色]；只保留一个主要清晰区，另一人退入暗部/虚焦；真实摄影电影剧照，非漫画/插画/游戏CG。

**三人骨架**：三人形成[三角/二对一/旁观]；中心人物清晰，另外两人通过站位/视线制造压力；空间边界清楚，单一光源，受控色彩；允许部分脸进入暗部或被遮挡。

**多人骨架**：一组角色形成[队列/围坐/人群背景/群体剪影]；只有主角或关系区域清楚，其他人作为整体轮廓/运动模糊；构图先读队形和空间，不要求每个人脸部清楚。

## 第七章：音频设计规范

### 7.1 旁白与对话规则
1. 每句标音色：角色名（音色标签，情绪/语气）："English dialogue"
2. 旁白第三人称全知视角，严禁第一人称
3. 旁白和对话内容必须英文，其他描述中文
4. 每镜必配旁白，半解说半对话
5. 音效标注：每镜头标注非BGM 音效

### 7.2 音轨留白与停顿（补丁3，P0）

1. **对话与旁白间隔**：同一时间格内，禁止让旁白和对话同时发声。必须留出 0.5-1.0 秒的纯音效间隔。正确节奏：`[0-2s] 音效（脚步声）→ [2-4s] 旁白（叙述）→ [4.5-5.5s] 纯呼吸/环境音留白 → [5.5-7s] 对话`
2. **情绪停顿（Beat）**：在情绪转折（悲伤、震惊、压抑）时，必须在提示词中写 `a beat of silence` 或 `slight pause, breath held`
3. **旁白分段**：超过15 个单词的旁白必须拆成两段，中间用 `...`（省略号）或 `(pause)` 隔开

### 7.3 音轨密度限制（补丁10）

| 版本 | 规则 | 10 秒镜头上限 | 12 秒镜头上限 |
|------|------|:--:|:--:|
| Seedance 2.0 | 旁白与对话可同镜，但间隔≥2.0秒 | 3 段 | 3 段 |
| 普惠版 | 旁白与对话推荐分离，间隔≥2.0秒；紧急降级时可同镜 | 2 段 | 3 段 |

超限时按优先级删减：① 情绪停顿留白 → ② 次要音效 → ③ 重复性叙述旁白

> **修订说明**：原 v3.2 将普惠版"旁白与对话禁止同镜"设为硬性禁止，导致叙事碎片化。改为"推荐分离+最小间隔+降级方案"，保留创作灵活性。

### 7.4 群戏音频调度规则（新增）

3人以上对话场景的特殊处理：
1. 用旁白概括多人发言内容（如：旁白："They argued back and forth, each defending their position."），仅在情绪高潮处让单人独立发言
2. 群戏对话镜头可放宽至3段音轨，标注"群戏特例"
3. 备选方案：将所有人声压成一层环境对话（背景嘈杂对话声），只突出1-2句关键台词

## 第八章：处理流程（Step-by-Step）

### Step 1：扫描剧本
识别集数段落/场景切换点/人物出场/对话密度/打斗场景

### Step 2：定义全局统一设定
场景锁模板+人物锁定卡片+特征锚点行+配音音色映射表+主色板锁定
> **审批关卡** 🛑：全局设定完成后须经导演/美术确认，签字后方可进入 Step 3。

### Step 3：估算镜数 + 钩子拆分法（补丁6）

1. **估算镜数**：`总时长（秒） ÷ 10（平均单镜时长）≈ 预计镜数`
2. **单镜硬约束**：8-12 秒（普惠版 8-10 秒）
3. **拆镜条件**：① 内容超过12秒 ② 视角需要有意义的变化 ③ 场景切换
4. **钩子拆分法**：前一镜尾帧为"进行中的动作半成品"→ 后一镜首帧从半成品瞬间继续
5. **拆镜唯一理由**：观众视角需要有意义的变化。连续动作视角无变化时不拆镜

### Step 4：逐镜提取
按12 列数据表填写，每镜标注首帧/尾帧状态

### Step 5：逐镜生成成套内容
1. **5.1** 填写 12 列数据表
2. **5.2** 依据第四章三格分镜格式，生成本镜导演故事版（三格时间轴完整呈现）
3. **5.3** 依据第五章模板，生成本镜图生视频提示词
4. **输出顺序**：数据表 → 导演故事版 → 图生视频提示词

> **首帧图质量预检（新增）** 🛑：在送 Seedance 生成前，检查：(1) 人物面部特征是否与人物锁定卡片一致？(2) 人手是否在画面内且手指数量正确？(3) 道具位置是否正确？(4) 光源方向是否与提示词一致？(5) 人物站位/朝向是否与数据表一致？

### Step 6：集末校验
1. **6.1** 汇总所有「本镜尾帧→下镜首帧」衔接，标记 ✅ 或 ⚠️
2. **6.2** 全量检查（非随机抽查）故事版与数据表一致性：时间格对应/空间关系/景别/动作/道具/音效
3. **6.3** 如发现故事版与数据表不一致，返回 Step 5 修正对应镜头

### ◆ 防遗忘强制刷新规则（补丁14）

| 版本 | 锚定频率 | 场景切换 |
|------|---------|---------|
| Seedance 2.0 | 每 8 镜 | 无需额外锚定 |
| 普惠版 | 每 8 镜（修订） | 每次场景切换后立即插入 |

锚定镜头使用与第1 镜完全相同的景别、布光、人物基础姿态，仅改变表情或微小动作。提示词必须从第1 镜的场景锁+人物锁+特征锚点逐字复制，仅修改动作和表情行。此锚定镜头不计入正常叙事节奏，时长压缩至 6-8 秒。

> **修订说明**：原普惠版"每5镜"频率过高（全片20-30%为无效画面），调整为"每8镜"，与Seedance 2.0标准版对齐。

## 第十章：最长可执行原则（速记卡）

> 以下为全文规则的格言式速记，非规范性条款。具体执行标准以各章节原文为准。

**人物情绪最短原则**：不写「他很悲伤/害怕/愧疚」，写「他的眼睛看哪里、嘴唇怎么收住、手停在哪里、哪半张脸进暗部、皮肤有多少真实但克制的细节」。

**多人镜头最短原则**：先写关系，再写人数；先定主清晰区，再安排其他人退后；用距离、朝向、光线和遮挡表达情绪，不靠每张脸都清楚。

**工作流铁律（七条）**：
1. 场景锁定：只写首帧图里有的元素
2. 动作降级：大动作改起始动作（跑→迈步）
3. 大动作拆镜：一镜一动作
4. 只写物理动作：不写情绪/故事/抽象内容
5. 表情变化用镜头推近代替脸动
6. 方向用画面方位锁死（消失在右侧/从左侧入画）
7. 固定镜头最稳，禁止手持晃/极速推/甩镜头

**引擎保护原则（普惠版）**：永远选择最低风险方案。能用固定镜头绝不用运动，能用单镜头绝不用复杂序列，能用文本锚点绝不完全依赖模型记忆。
