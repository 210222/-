## §1 Seko平台渲染边界 (必读·所有Agent)

> **来源：** Seko2.0_用户操作手册_v1.0.md（2026.06）+ 枪王EP2/EP4/EP8生产实践
> **核心认知：** Seko不是一个模型，是一个多模型编排平台。不同模型有不同的渲染能力边界。

### 1.1 画布模式 vs 编辑器模式（关键架构区分）

```
┌──────────────────────────────────────────────────────────────┐
│  画布模式 (Canvas)                                            │
│  ✅ 首尾帧过渡可用 — 上一镜尾帧 → 下一镜首帧·视觉连续          │
│  ✅ Vidu Q2 专长此功能                                       │
│  ⚠️ 首尾帧过渡 与 SekoTalk口型同步 互斥·不可同时开启           │
│  适用: 无对白/旁白驱动的连续运镜段落                            │
├──────────────────────────────────────────────────────────────┤
│  编辑器模式 (Editor)                                          │
│  ❌ 不支持首尾帧过渡 — 每个分镜独立生成                        │
│  ❌ 模型不知道上一镜长什么样                                   │
│  → 连续性靠: 主体库面部锁定 + Anchor锚点文字描述 + 分镜图人眼对比 │
│  适用: 有对白的对话场景（可同时开启SekoTalk口型同步）            │
└──────────────────────────────────────────────────────────────┘

模式选择决策树:
  有对白且需要口型同步?
    → 编辑器模式 + SekoTalk（牺牲首尾帧过渡·靠锚点保持连续）
  无对白·需要镜头间视觉无缝衔接?
    → 画布模式 + 首尾帧过渡（牺牲口型同步·获得视觉连续）
  既有对白又需要首尾帧过渡?
    → 🛑 不可兼得·必须二选一（画布宪法第二条·REN-03阻断）
```

### 1.2 平台能力清单

```
平台提供的能力（Seko 2.0）:
  ✅ 画布模式首尾帧过渡 — 上一镜尾帧作为下一镜首帧（画布模式·Vidu Q2）
  ✅ 分镜图阶段可视 — 转视频前能看到每镜静态画面（两种模式均可用）
  ✅ 主体库锁定面部 — 角色跨镜基本一致（不是完美）
  ✅ 多剧集模式 — 跨集继承角色/场景
  ✅ 多种模型按镜头类型切换 — 动作用海螺·对话用即梦
  ✅ 局部重绘/消除笔 — 低成本修复单帧问题

底层模型仍然做不到的（渲染硬上限）:
  ❌ 编辑器模式下·模型不知道上一镜长什么样
     → 连续性靠: Anchor锚点描述 + 分镜图人眼对比
  ❌ 画布模式首尾帧过渡时·不能同时开启口型同步
     → 有对白的场景必须在"视觉连续"和"口型精准"之间二选一
  ❌ 复杂动作（转身拔剑斩茶杯）→ 需拆解为2-3个分镜
  ❌ 毫米级精确描述（"5mm唇间距"）→ 模型无法精确到mm·用相对描述
  ❌ 亚秒级时间精度（"每0.5秒滴落"）→ 时间精度约1秒
  ❌ 同时≥3个独立音效 → 音频通道可能合并或丢失
  ❌ 瞳孔控制 — Seko忽略瞳孔收缩/扩张描述·随机化
```

### 1.3 渲染硬上限速查

| 约束项 | 硬上限 | 替代方案 | 来源 |
|--------|--------|---------|------|
| 单段时长 | ≤15秒 | 拆分长段 | 平台硬约束 |
| 时间精度 | ≈1秒 | 不描述亚秒事件·用"持续"替代"每0.5秒" | P-FAL-03 |
| 空间精度 | ≈cm级 | 不描述mm级间距·用"微张""紧贴"替代 | P-FAL-02 |
| 同时音效 | ≤2层 | 缩减音效层数·优先级排序 | P-FAL-04 |
| VO语速 | ≤4字/秒 | 缩减文本·或延长画面时长 | P-FAL-05 |
| 瞳孔变化 | 不可控 | 固定瞳孔状态·不描述变化过程 | P-FAL-01 |
| 窄空间横移 | <3m深禁横移 | 改用推近替代 | P-FAL-06 |
| 单镜动作数 | ≤1核心动作 | 拆解为多镜 | 模型限制 |
| 多人面部差异 | ≥3人不可控 | 仅描述最近角色面部·远景用姿态 | P-OPN-02 |
| 🆕 高频视觉噪声 | 闪烁/条纹/噪点/马赛克 | 降低视觉熵·简化背景·降低风格锚点对比度 | P-FAL-07 |
| 🆕 画面文字 | 必乱码 | 禁止prompt中要求画面内文字·标注"后期叠加" | P-FAL-08 |
| 🆕 极端运动形变 | 快速/大幅度运动时局部形变 | 动作降速·拆分复杂动作·缩短动作窗口 | P-FAL-09 |
| 🆕 多人口型误差 | ≥2人同时说话口型不匹配 | 多人对话拆为交替单人口型特写+听者反应镜头 | P-FAL-10 |

## §2 视频模型选择策略 (设计Agent必读)

### 2.1 9模型矩阵

| 模型 | 核心优势 | 适用镜头 | 弱点 | 积分 |
|------|---------|---------|------|:--:|
| **即梦 4.0** | 亚洲面部写实度最高 | 对话·面部特写·静态/微动态 | 快速动作表现力弱 | 中 |
| **海螺 02** | 动态表现最强 | 打斗·奔跑·追逐·动作密集 | 静态画面细节略逊 | 中 |
| **Vidu Q2** | 首尾帧过渡最佳 | 一镜到底·长推轨·长镜头 | 单段时长有限 | 中 |
| **可灵 3.0** | 运镜最平滑自然 | 唯美慢镜·情感·慢节奏 | 快速动作跟不上 | 中 |
| **Seedance 2.0** | 1080p/30秒·通用 | 复杂运镜·长片段·电影级 | 积分消耗高 | 高 |
| **万相 Wan2.5** | 特殊风格 | 古风/水墨/赛博朋克 | 真人写实不如即梦 | 中 |
| **Nano Banana Pro** | 动漫风格最稳定 | 二次元·国漫·卡通 | 真人写实不擅长 | 低 |
| **Pixverse V5** | 像素风/2D剪影 | 特殊视觉风格 | 真人写实不擅长 | 低 |
| **Veo 3.1** | 音效同步·电影级 | 高端电影场景 | 积分最高 | 最高 |

### 2.2 按镜头类型自动推荐

```
镜头类型 → 推荐模型（按优先级排序）:

  对话·面部特写:
    首选: 即梦 4.0 → 次选: 可灵 3.0 → 高配: Veo 3.1

  动作·打斗·追逐:
    首选: 海螺 02 → 次选: Seedance 2.0 → ❌禁用: 即梦 4.0

  一镜到底·长镜头:
    首选: Vidu Q2 → 次选: Seedance 2.0

  唯美慢镜·情感:
    首选: 可灵 3.0 → 次选: Seedance 2.0

  风格化(古风/水墨/赛博朋克):
    首选: 万相 Wan2.5 → 次选: Seedance 2.0

  动漫·二次元:
    首选: Nano Banana Pro → 次选: 万相 Wan2.5

  像素风/特殊视觉:
    首选: Pixverse V5

  高端电影级:
    首选: Veo 3.1 → 次选: Seedance 2.0
```

### 2.3 积分成本优化

```
节省积分策略:
  基础模型批量跑全部镜头 → 仅关键分镜换高级模型重新生成

  关键分镜定义:
    钩子(首镜)·爽点·高潮·结尾·面部特写

  动作密集型 → 必须用海螺02（避免用不擅长动态的模型反复抽卡·浪费积分）

  模型选择错误=渲染失败 → 不修提示词·换模型（画布宪法第二条·REN-04）
```

## §3 画面描述约束 (prompt_composer + 设计Agent必读)

### 3.1 禁止词汇清单

```
过程动词和时间模糊词（首帧重点检查）:
  禁止: 刚/尚未/正在/即将/正要/刚要/开始/逐渐/缓缓/慢慢/渐渐/猛地/骤然
  替代: 首帧用静态完成态描述——"手持""头位于""身体静止""位于""接触"

模糊完成度量词:
  "刚离地" → AI理解为"已离地"·无法渲染瞬间态
  首帧定在动作完成前的悬停态

抽象情绪/气氛词:
  禁止: 气氛/情绪/感觉/仿佛/如同/像是/似乎/有一种说不出的
  替代: 转化为光线/阴影/色彩/面部表情/身体姿态的精确描述

文学修饰词:
  禁止: 像幽灵一样/深邃如深渊/温柔地拥抱/诡异的气氛
  替代: 精确参数——速度/色温/光源方向/面部肌肉状态
```

### 3.2 物体存在链约束

```
每个画面中出现的物体必须满足（画布宪法第六条）:

  🅰 参考图已存在 — 标注参考图格位
  🅱 角色随身携带 — 人物表声明(🅱-A) 或 行为推断(🅱-B)
  🅲 前序镜引入   — 标注引入镜#和引入方式

  禁止: 凭空出现·状态跳跃·消失后无重新引入

  详见: P-CONSTITUTION.md §6 · OBJECT_TIMELINE_[剧本名].md
```

### 3.3 跨镜连续性约束

```
同一场景内跨镜连续性:
  · 色彩锚点: 每镜独立描述色温·不引用上一镜
  · 光影锚点: 每镜独立标注光源方向+类型
  · 道具锚点: 每镜独立列出可见道具·与OBJECT_TIMELINE对齐
  · 人物锚点: 每镜独立描述位置+姿态·不假设上一镜状态

跨场景连续性:
  · 通过场景末状态快照传递（STORYBOARD末尾）
  · 新场景Step A1读取上一场景快照
  · 不跨场景引用具体画面描述
```

### 3.4 音轨描述约束

```
音轨格式:
  音轨: [声音描述——什么声音·什么节奏·什么变化]
  第X秒——[声音事件·精确触发时刻]

约束:
  · 同时音效≤2层
  · 音效事件精确到秒（不描述亚秒事件）
  · VO ≤4字/秒（超出则缩减文本或延长画面）
  · 画面外声音 → 只放音轨·不放在【生成指令】画面描述中
  · 音轨不描述"情绪"（"悲伤的音乐"）→ 描述类型+节奏（"慢节奏钢琴·单音符·降B小调"）
```

## §4 分镜图确认清单 (人类审核用)

> 来源: Seko 2.0 Step 6 · 8项逐张检查

```
Seko生成每镜静态图后·人类逐张检查:

  1. 面部连续性 — 同一角色在N-1/N/N+1分镜图脸一致吗？
  2. 空间连续性 — 家具/门窗/光影方向跨镜一致吗？
  3. 服装一致性 — 同集内服装与剧本描述一致吗？
  4. 景别多样性 — 超过3张连续同景别吗？
  5. 视觉锚点 — 相邻两张图共享≥1个物件/角色/光影吗？
  6. 运镜构图 — "推近"的图是否构图紧致？"仰拍"是否低视角？
  7. 面部表情 — 与台本画面描述一致吗？
  8. 手指/肢体 — 有没有多余手指或肢体畸变？

Seko提供的修改工具:
  · 局部重绘: 框选不满意区域 → 输入修正指令
  · 消除笔: 去除多余元素
  · 元素添加: 在画面中新增内容
  · 重新生成: 切换模型重新出图

⚠️ 口型同步(SekoTalk)和首尾帧过渡(Vidu Q2)不能同时开启——两者冲突
```
