| 空间精度 | ≈cm级 | 不描述mm级间距·用"微张""紧贴"替代 | P-FAL-02 |
| 同时音效 | ≤2层 | 缩减音效层数·优先级排序 | P-FAL-04 |
| VO语速 | ≤4字/秒 | 缩减文本·或延长画面时长 | P-FAL-05 |
| 瞳孔变化 | 不可控 | 固定瞳孔状态·不描述变化过程 | P-FAL-01 |

| 单镜动作数 | ≤1核心动作 | 拆解为多镜(≥2动作→≥2镜) | 模型限制 |
| 画布+口型同步 | 互斥·不可同时 | 有对白→编辑器模式·无对白→画布模式 | REN-03 |

| 多人口型误差 | ≥2人同时说话口型不匹配 | 拆为交替单人口型特写+听者反应镜头 | P-FAL-10 |

### B.4 禁止词汇清单 (prompt_composer + 设计Agent必读)

```
过程动词(首帧): 禁止"刚/尚未/正在/即将/正要/刚要/开始/逐渐/猛地/骤然"
  → 替代: 首帧用静态完成态——"手持""头位于""身体静止""位于"

时间模糊词: 禁止"缓缓/渐渐/慢慢/逐渐/徐徐/冉冉"
  → 替代: 精确参数(速度/色温/方向)

抽象情绪/气氛词: 禁止"气氛/情绪/感觉/仿佛/如同/像是/似乎/有一种说不出的"
  → 替代: 光线/阴影/色彩/面部表情/身体姿态的精确描述

文学修饰词: 禁止"像幽灵一样/深邃如深渊/温柔地拥抱/诡异的气氛"
  → 替代: 精确参数——速度/色温/光源方向/面部肌肉状态

负向词(禁止进入prompt): "不要/避免/禁止/不能/不应/勿/别"
  → sd2.0将所有token当正向指令

画面外描述: 禁止"画面外/镜头外/屏幕外/画框外"在【生成指令】中出现
  → 画面外声音→放【音轨】中

跨镜引用: 禁止"同上/参考上镜/如前/同镜#/与镜#"
  → 每镜独立完整描述
```
