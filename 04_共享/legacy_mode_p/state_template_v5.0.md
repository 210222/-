# STATE.md — EP[X] 场记库 + 学习记录

> **模板版本：** v5.0 · 2026-06-22
> **设计溯源：** Fable 5 STATE.md 五段式（Verified facts → General rules → Open failures → Lessons learned → Last session）+ 导演系统场记库六段式（时间线→状态快照→信息矩阵→跨集连续项）
> **七段式融合：** 前四段继承场记库的实例级状态追踪（角色/空间/道具/信息矩阵），后三段引入 Fable 5 的规则级抽象（事实验证→规则蒸馏→失败学习）
> **位置：** `scene_log_EP[X].md` 的配套模板。每集 MODE:A 执行完成后更新一次。下次 MODE:A 启动时优先 Read。
> **读取优先级：** 次优先于 CONSTITUTION.md —— CONSTITUTION 是静态优先级铁律，STATE.md 是动态集记忆。

# 你是谁

**此文件不是指令文档——而是本系统的「跨会话记忆」。** 在每次 MODE:A 启动时，本文件与 CONSTITUTION.md 同时预读取，作为本案（EP[X]）的全局上下文基础。

后三段（§5-§7）回答：**"我们从过往中学到了什么？"**
