# KB_SUMMARY 模板 v1.0

> **定位:** 调度器在 MODE:P 启动时为每个场景预提取的 KB 规则摘要。替代 Agent 各自加载完整 KB 文件 (42K tokens)。
> **生成者:** 调度器自执行 (Step 0.7B·纯文本提取·零 LLM)
> **消费者:** 所有 MODE:P Agent (替代 `Read 03_导演知识库_v5.0.md 完整文件`)
> **大小目标:** ≤10K tokens (L1_CORE ~3K + L2_SCENE ~5-7K)
> **设计依据:** EP14_TOKEN_FORENSICS.md §1 · EP14_ARCHITECTURE_WASTE.md §4 浪费项#4

---

## 三层规则架构

```
L1_CORE (~50条·~3K tokens):
  §0 通用铁律全部 (GEN-01~10)
  + 所有标记 P0 的规则 (来自 §1-§9)
  → 所有 Agent 始终加载 · 不可路由淘汰 · 不可跳过

L2_SCENE (~80-120条·~5-7K tokens):
  kb_index_v2.0.md 路由命中的场景类型章节
  → 调度器根据场景类型预提取 · 场景内所有 Agent 共享
  → 提取内容: 规则ID + 规则全文 + 优先级 + 来源

L3_FULL (~700+条·~42K tokens):
  03_导演知识库_v5.0.md 完整文件
  → Agent 仅在 L1/L2 规则摘要不够时按需深读
  → 深读方式: Read 03_导演知识库_v5.0.md 指定行号范围
```

## 调度器生成指令

```
[Orchestrator] Step 0.7B: 生成 KB_SUMMARY_[剧本名].md

1. Read 03_导演知识库_v5.0.md 全文 (一次性·调度器上下文)
2. Read kb_index_v2.0.md §二 场景路由表 → 确定场景类型 → 确定 L2_SCENE 章节列表
3. 提取 L1_CORE:
   a. 提取 §0 全部 (GEN-01~10)
   b. 扫描全文 → 提取所有 `| P0 |` 行 → 提取该行所属规则的完整文本
   c. 去重 (同一规则可能出现在多个章节)
4. 提取 L2_SCENE:
   a. 对每个路由命中的章节 → 提取该章节全部规则的完整文本
   b. 规则格式: | 规则ID | 规则全文 | 来源 | 优先级 |
5. 组装 KB_SUMMARY_[剧本名].md (按模板格式)
6. 验证: 文件 ≤10K tokens · 每条规则含 ID+全文+来源+优先级

禁止:
  - 将规则文本内联到 Agent prompt 中 (Agent 自己 Read KB_SUMMARY)
  - 跳过 P0 规则提取 (P0 不可路由淘汰)
  - 包含非路由章节的规则 (那是 L3_FULL 的范围)
```
