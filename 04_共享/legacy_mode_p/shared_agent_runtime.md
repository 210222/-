## §2 Murch六大准则 {#sec-murch}

> **来源：** Walter Murch, *In the Blink of an Eye* (1995)
> **核心原则：** 如果必须牺牲 → 从下往上牺牲。情感比其余五项加起来更重要。

```
┌──────────────────────────────────────────────────────────────────┐
│  Murch 六大准则 · 牺牲层级（从下往上·不可逆）                      │
│                                                                   │
│  层级  准则                      权重    检测问题                  │
│  ────  ────────────────────────  ────    ────────────────────     │
│  1     情感 (Emotion)            51%     这个切点感觉对吗？        │
│  2     故事 (Story)              23%     这个切点推进故事了吗？    │
│  3     节奏 (Rhythm)             10%     这个切点在节奏上对吗？    │
│  4     视线追踪 (Eye-Trace)       7%     观众的眼睛跟得上吗？      │
│  5     二维平面 (Planarity)       5%     180°规则/舞台线对吗？     │
│  6     三维空间 (Spatial)         4%     物理空间连续性对吗？      │
│                                                                   │
│  牺牲规则:                                                        │
│    情感 > 故事 > 节奏 > 视线追踪 > 二维平面 > 三维空间             │
│    情感(51%) > 故事+节奏+视线+平面+空间(49%)                       │
│    如果情感对了——观众不会注意到下层违规                            │
└──────────────────────────────────────────────────────────────────┘
```

### 导演系统映射

| Murch准则 | 导演系统对应 | 级别 |
|-----------|------------|:---:|
| 情感(51%) | 审计3 Murch牺牲层级·审计9 运镜×情绪 | 🛑 |

| 节奏(10%) | 审计2E 运镜节奏·审计5 视觉能量流 | ⚠️ |
| 视线追踪(7%) | 审计4B 首帧锁定·B6 视线方向 | ⚠️ |
| 二维平面(5%) | 审计1 180度规则·B2 参考系 | 🛑 |
| 三维空间(4%) | 审计12 空间可行性·B1 空间桥接 | 🛑 |

## §3 Block七视觉组件 {#sec-block}

> **来源：** Bruce Block, *The Visual Story* (2008)
> **核心原理：** 视觉结构应当镜像戏剧结构。冲突上升=对比增强·冲突解决=亲和增强。

```
┌──────────────────────────────────────────────────────────────────┐
│  Block 七视觉组件 · 子维度防重复计数                               │
│                                                                   │
│  组件        子维度                  计数规则                      │
│  ────────   ──────────────────────   ────────────────────────     │
│  空间        景别·角度·构图          三个子维度统一计1次           │
│  影调        亮度·光比·影调风格      独立计数                      │
│  运动        摄影机运动·物体运动      同时变化仍计1次              │
│  节奏        分镜时长·切点密度        独立计数                      │
│  色彩        色温·饱和度·色彩方案     ≠影调·独立计数              │
│  线条        主导线条方向·秩序感      独立计数                      │
│  形状        主体轮廓·正负空间形状    独立计数                      │
│                                                                   │
│  变化安全等级:                                                    │
│    ≤2变化 = 低变化·亲和力高(适合对话·情感积累)                    │
│    3变化  = 标准推进(适合大多数场景)                               │
│    4变化  = 高变化·需🎯标注(适合闪回/插入/场景转换/情绪转折)      │
│    5变化  = 极高·必须标注蓄意节点类型                              │
│    ≥6变化 = 全维度断裂·除非场景转换否则阻断                        │
└──────────────────────────────────────────────────────────────────┘
```

## §4 运镜覆盖策略速查 {#sec-coverage}

> **来源：** 03_导演知识库_v5.0.md §11 + enhance §2A-A5

### 对话场景（8机位模板）

```
基本覆盖: 主镜头(MS·建立空间) + OTS-A + OTS-B + CU-A + CU-B + 插入×1 + 反应×1 + 空镜×1
机位分布: 正反打各2机位·插入1·反应1·宽1·特1
```

### 动作场景（6机位模板）

```
基本覆盖: 全景建立 + 跟拍主体 + 低角度动作 + 特写关键 + 反应镜头 + 空镜过渡
机位分布: 宽2·中2·紧1·插入1
```

### 悬疑场景（5机位模板）

```
基本覆盖: 主镜头(氛围) + 主观视角 + 特写线索 + 反应镜头 + 空镜(空间)
机位分布: 宽1·主观1·紧2·插入1
```

### §4.1 静态运镜例外规则 {#sec-static-exceptions}

> **来源：** enhance §2C-C2 + director_agent审计2D
> **核心原则：** 画面静止是例外·不是默认。仅以下三种情况允许静态：

```
允许静态的情况                   📐 格式
──────────────────────────────────────────────────
1. 信息密集(对白≥8行/复杂视线)    固定机位 + 理由标注"信息密集·静态服务于视线追踪"
2. 情感沉浸(悲伤/沉思/静默时刻)   固定机位 + 理由标注"情感沉浸·静态服务于情绪停留"
3. 空间受限(物理无法运动)         固定机位 + 理由标注"空间受限·[具体约束]"

非以上三类 → 必须有运镜·不允许惰性静态
```

## §5 空间-运镜可行性矩阵 {#sec-spatial}

> **来源：** 03_导演知识库_v5.0.md §12 + enhance §2C-C1.5

```
┌──────────────────────────────────────────────────────────────────┐
│  空间类型 → 运镜可行性                                             │
│                                                                   │
│  空间          可行运镜                禁止/受限                    │
│  ────────     ──────────────────────   ──────────────────────     │
│  走廊          横移·跟拍·推近·拉远     摇镜(窄空间受限)            │
│  小房间(<10m²) 固定·手持·缓推         横移·大幅度摇镜·升降        │
│  大空间        全部可行                无                           │
│  楼梯间        固定·手持·升降         横移·大幅度推拉              │
│  车内          固定·特写·POV          大幅度运镜·横移·升降        │
│  门口/门槛     固定·缓推·手持         快速横移·大幅度摇镜          │
│                                                                   │
│  运镜速度约束:                                                    │
│    空间深度 < 2m  → 速度 ≤ 0.5x                                   │
│    空间深度 2-5m → 速度 ≤ 1.0x                                    │
│    空间深度 > 5m  → 速度 ≤ 3.0x                                   │
└──────────────────────────────────────────────────────────────────┘
```

## §6 7-DOF相机状态模型 {#sec-7dof}

> **来源：** Jasinschi et al. (2000) "Apparent 3-D Camera Velocity-Extraction" (IEEE Trans. CSVT) · MPEG-7标准

```
┌──────────────────────────────────────────────────────────────────┐
│  7-DOF 相机状态向量 V = [ω_pan, ω_tilt, ω_roll,                   │
│                          v_track, v_boom, v_dolly, v_zoom]        │
│                                                                   │
│  3个旋转速度:                                                     │
│    ω_pan  (Y轴·水平摇摄)    °/s                                  │
│    ω_tilt (X轴·垂直俯仰)    °/s                                  │
│    ω_roll (Z轴·横滚)       °/s                                   │
│                                                                   │
│  3个平移速度:                                                     │
│    v_track (X轴·横移)      m/s                                   │
│    v_boom  (Y轴·升降)      m/s                                   │
│    v_dolly (Z轴·推拉)      m/s                                   │
│                                                                   │
│  1个缩放速度:                                                     │
│    v_zoom  (焦段变化)       mm/s                                  │
│                                                                   │
│  常见运镜→7-DOF映射:                                              │
│    固定: 全零向量                                                  │
│    推近: v_dolly(主) + 可能ω_tilt(微)                             │
│    拉远: v_dolly(负)                                              │
│    横移: v_track(主)                                              │
│    跟拍: v_track + v_dolly(复合)                                  │
│    摇镜: ω_pan或ω_tilt(主)                                       │
│    甩镜: ω_pan或ω_tilt(高速)                                     │
│    升降: v_boom(主)                                               │
│    变焦: v_zoom(主·区别于v_dolly)                                 │
└──────────────────────────────────────────────────────────────────┘
```

## §8 常见禁止事项模板 {#sec-prohibitions}

> **每个Agent在此基础上增加自己特有的禁止事项。**

```
通用禁止（所有Agent·不可违反）:
  1. 禁止在KB不可用时静默退化 → 必须显式报告🛑
  2. 禁止跳过前提条件检查 → 每个审计/检测前检查N/A条件
  3. 禁止无KB引用的🛑裁决 → 宪法第〇条·降级为⚠️
  4. 禁止模糊裁决 → 宪法第五条·每个裁决需量化阈值+检测方法
  5. 禁止越界判断 → 导演不判美学·摄影不判规则·桥接不判剪辑
  6. 禁止在画面描述中使用跨镜文本引用 → 底层模型调用时不知道上一镜长什么样（详见 canvas_runtime.md §1.1）
  7. 禁止从头读取KB文件 → 用kb_index路由·Grep锚点·局部扫描
```
