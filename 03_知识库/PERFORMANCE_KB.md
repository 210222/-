> **定位:** Scene Designer v2.1+ 的共享知识库。将对白潜台词/心理状态映射为 Seko 可渲染的解剖学指令。
> **来源:** 微表情心理学(Ekman)·行为心理学·表演理论(Stanislavski/Meisner/Hagen)

## §1 映射规则 (15个心理状态 × 5个解剖维度)

每个状态的描述 = Seko 可逐条执行的视觉/声音指令。不使用情绪标签。

### 1.1 说谎 (lying)

```
eyes:     "眨眼频率先抑制(0-2秒)后激增(3-5秒)·注视对方时间增加以监控反应·瞳孔无变化"
brow:     "短暂眉间纵纹(<500ms微表情)·随后被抑制·眉位恢复基线"
mouth:    "代偿性过度控制·微笑启动延迟约200ms·嘴角不对称(左低右高约1mm)·上唇微紧"
hands:    "自我安抚动作增加·触碰面部/颈部/衣物·手指无意识缠绕或摩擦"
voice:    "基频微升10-15Hz·回答前潜伏期延长·陈述句尾音微扬(不确定化)"
```

### 1.2 回避 (avoidance)

```
eyes:     "注视时长显著减少·视线向下方或侧方漂移·眨眼频率增加·回避直接眼接触"
mouth:    "嘴唇内收(上下唇同时卷入口腔)·或代偿性过度微笑·笑容持续时间延长但无眼部参与"
posture:  "躯干后倾·肩部微收·与对方物理距离增加·身体朝向微偏(偏离对方正面)"
hands:    "手部动作增加·整理衣物或物品·占用双手以回避手势交流"
```

### 1.3 权力博弈 (power_play)

```
eyes:     "注视时长增加·不首先中断对视·瞳孔轻微散大·注视对方眼睛而非面部其他区域"
posture:  "躯干前倾·占据更多空间·头位微仰·肩部展开·姿态不对称(一侧高于另一侧)"
hands:    "手部动作减少·静止传达控制·展示手掌(不具威胁)·手指尖塔形(自信)"
voice:    "音量稳定·语速控制(不急促)·停顿使用增加(控制节奏)·句尾下沉(陈述而非询问)"
```

### 1.4 恐惧(抑制) (fear_suppressed)

```
eyes:     "上眼睑微抬·下眼睑收紧·巩膜暴露增加·视线快速扫描环境·注视对象不足1秒即转移"
brow:     "眉头微抬且向内收拢(恐惧微表情)·持续不到500ms·随后强行恢复基线"
mouth:    "嘴唇微启·嘴角水平拉宽(恐惧口型)·随后被抑制·代偿性吞咽动作"
posture:  "躯干微后倾·肩部上提(颈部保护反射)·身体准备后退但被意志抑制"
voice:    "音量微降·语速微增或微降(不稳定)·气息变浅·停顿增多"
```

### 1.5 愤怒(抑制) (anger_suppressed)

```
eyes:     "眼睑收紧·下眼睑微升·视线锁定对方·注视强度增加·眨眼频率减少"
brow:     "眉头下降且向内收拢·眉间纵纹加深·上眼睑被眉部下压(愤怒三角区)"
mouth:    "嘴唇紧抿·唇红变薄·嘴角下降·下颌肌肉隆起(咬肌收缩)·或代偿性僵硬微笑"
hands:    "手指屈曲·握拳或半握·指关节发白·或双手用力按压静止物体"
voice:    "音量控制(刻意稳定)·语速微降·咬字加重·停顿处有未释放的呼气"
```

### 1.6 悲伤(掩饰) (sadness_masked)

```
eyes:     "上眼睑微垂·下眼睑微紧·视线向下·泪膜增厚(反光增强)·不形成泪滴"
brow:     "眉头内侧微抬(悲伤微表情)·持续时间约1秒·随后被社交微笑覆盖"
mouth:    "嘴角下降约1-2mm·与代偿性微笑交替·微笑时眼部无皱褶(假笑特征)"
hands:    "手部动作减少·静止时间延长·可能无意识触摸慰藉物(杯子/照片/戒指)"
voice:    "音量微降·语速微降·音调范围收缩·句尾下沉·停顿增加"
```

### 1.7 内疚 (guilt)

```
eyes:     "注视时间减少·视线向下或向侧·不直视对方·眨眼频率增加·眼睑微垂"
brow:     "眉头微皱·眉间浅纹·非愤怒性的收紧(不涉及上眼睑下压)"
mouth:    "嘴唇内收·嘴角微降·下颌微收·可能自我惩罚性咬下唇"
posture:  "躯干微缩·肩部前收·身体面积缩小·头位微低·自我安慰姿势增加"
hands:    "手部自我接触增加·手指摩擦·触碰面部(遮盖型)·整理衣物(拖延型)"
voice:    "音量降低·语速减慢·音调范围收缩·停顿增多·句尾声音减弱"
```

### 1.8 轻蔑 (contempt)

```
eyes:     "单侧眼睑微紧·视线从对方身上扫过后移开·或俯视角度注视"
brow:     "单侧眉头上扬(轻蔑标志性不对称)·持续约1-2秒·另一侧眉位不变"
mouth:    "单侧嘴角收紧上提(不对称微笑)·或上唇单侧微升·唇红变薄"
posture:  "头位微仰(俯视角度)·身体微微转离·或过度放松的姿态(假装不care)"
```

### 1.9 惊讶(短暂) (surprise_brief)

```
eyes:     "上眼睑瞬间抬高·巩膜上方暴露增加·持续约500ms·随后恢复基线"
brow:     "双眉同时上扬·额头出现横纹·持续约500ms·随后眉位恢复"
mouth:    "下颌瞬间微降·嘴唇分开约5mm·持续约500ms·随后闭合"
voice:    "呼吸瞬间暂停(约200ms)·随后恢复正常呼吸节奏"
```

### 1.10 专注 (focus)

```
eyes:     "注视时长大幅增加·视线锁定目标对象·眨眼频率减少50%以上·瞳孔轻微散大"
brow:     "眉位微降·眉间微收·非愤怒性·是注意力集中的生理反应"
posture:  "躯干前倾·头位朝向目标·身体其他部位静止·减少不必要的微动作"
hands:    "手部动作减少或完全静止·可能单手支撑下巴·或双臂交叉(自我封闭以集中)"
```

### 1.11 评估/判断 (evaluation)

```
eyes:     "注视时长中等·视线在对象和远处之间交替·每次注视约2-3秒·眨眼频率正常"
brow:     "单侧眉头微抬(约1秒)·或眉头微皱(约2秒)·非对称性"
mouth:    "嘴唇微抿·下唇可能被上齿轻咬·或嘴角微偏一侧(思考中的不对称)"
hands:    "手部可能出现评估性手势·指尖触碰下巴或嘴唇·头部微倾"
```

### 1.12 放松/真实 (relaxed_genuine)

```
eyes:     "眼轮匝肌参与·下眼睑出现真实笑纹(鱼尾纹)·眼型改变·上眼睑微垂"
mouth:    "嘴角对称上提·上唇自然升露上齿·微笑启动平滑(无延迟)·唇形自然"
brow:     "眉位自然·无多余张力·眉间平滑"
posture:  "姿态开放·躯干正对对方·肩部放松·身体面积正常展开"
voice:    "音量自然·语速正常·音调范围正常·笑声真实(声带松弛)"
```

### 1.13 紧张 (tension)

```
eyes:     "眼睑微紧·眨眼频率增加·视线不稳定(在多个点之间快速移动)·瞳孔轻微散大"
brow:     "眉间微收·眉位微升·额头可能出现浅横纹·整体眉毛张力增加"
mouth:    "嘴唇微紧·唇红变薄·可能出现舔唇(紧张的口干)·或代偿性过度微笑"
posture:  "躯干僵硬·肩部上提·颈部肌肉可见张力·身体面积收缩·姿态对称但不自然"
hands:    "手部动作增加·手指抖动·握拳或抓握衣物·自我安抚·无法保持静止"
voice:    "音量不稳定·语速微增或微降·音调微升·气息变浅·可能出现声带紧绷"
```

### 1.14 疏离 (detachment)

```
eyes:     "注视时长减少·视线焦点柔和(不聚焦于对方)·眼神空洞·眨眼频率正常或微降"
brow:     "眉位平坦·无表情·无张力·眉间平滑"
mouth:    "嘴唇自然闭合·唇形中性·无上扬无下降·无肌肉张力"
posture:  "躯干微后倾·身体朝向微偏·姿态对称但无张力·与环境的物理距离增加"
voice:    "音量中等偏低·语速微降·音调单调(范围收缩)·缺乏语调变化·句尾平直"
```

### 1.15 威胁感知 (threat_perception)

```
eyes:     "视线瞬间锁定威胁源·注视强度增加·瞳孔先散大(警戒)后收缩(评估)·眨眼暂停"
brow:     "眉位微降·眉间微收·上眼睑微抬(增加视野)·整体眉毛向眉心集中"
posture:  "躯干瞬间静止·准备反应(战斗/逃跑)·重心微降·颈部肌肉收紧·头位朝向威胁源"
hands:    "手部动作瞬间停止·手指屈曲准备·或手部移向身体(保护性)·右手/左手根据威胁方向"
```

## §2 心理状态识别规则 (Scene Designer 推理指南)

### 2.1 从对白文本推断心理状态

```
对白特征 → 可能心理状态:

  否定+回避主题:          "我不在问你。" → 回避 + 轻微权力博弈
  反问:                   "你看到了什么。" → 权力博弈 + 威胁感知
  短句·延迟回复:          "咖啡？老样子。" → 回避(用日常掩盖紧张)
  陈述伪装为问句:         "你看到了什么。"(句尾不下沉) → 权力博弈(不是真问句)
  破碎句:                 "你手上有血。你凌晨...你是不是有麻烦了？" → 恐惧(抑制) + 内疚
  命令式:                 "今天早点关门。" → 权力博弈 + 威胁感知(保护对方)
  旁白/VO:                "这座城市的每个人都在看着别人。" → 疏离(上帝视角)
  职业化回应:             "早啊，塞拉。老样子？" → 放松/真实(日常·无伪装)
  单字回复:               "Busy." → 疏离(用最小字数维持距离)
```

### 2.2 从角色关系推断心理状态

```
关系动态 → 影响:

  Isabela→Rico(恋人·怀疑):   亲密+恐惧=矛盾体
    → 表面: 关心(放松/真实)
    → 潜层: 恐惧(真相)+内疚(擅自进入工作室)
    → 每句对白有两种心理状态共存

  Isabela→Sera(顾客·正常世界): 职业化=无伪装
    → 此时是真实的(放松/真实)
    → 作为对比基线: 她对Sera的笑 vs 对Rico的笑

  Rico→Isabela(保护者):    权力+回避
    → 他比她更早知道危险(棒球帽男人)
    → 每句对白: 表层=日常·深层=威胁感知+权力博弈
    → "咖啡？老样子。" = 用日常词语掩盖"我看到窗外有人"

  Rico→窗外(棒球帽男人):   威胁感知
    → 无对白·纯身体反应
    → "目光扫过窗户——定在那个男人身上" → 威胁感知(瞬间锁定)

  Isabela→Rico质问时:
    → 外层: 愤怒(抑制) = "我看到一条毛巾——上面有血"
    → 内层: 恐惧 = "你——是不是有麻烦了？"
    → 两层交替出现: 先愤怒(质问)→恐惧(暴露关心)→愤怒(再次质问)
```

### 2.3 个性化调整 (角色基线)

```
Isabela 基线:
  真实性: 高(不是擅长说谎的人)
    → 她的假笑可被识别: 眼轮匝肌缺失·嘴角启动延迟
  情绪表达: 外显(容易被读取)
    → 微表情持续时间较长(1-3秒·非典型<500ms)
  调整: performance中的微表情持续时长×2

Rico 基线:
  真实性: 低(专家级掩饰者)
    → 他的假笑难以识别: 眼轮匝肌参与度高于常人(后天训练)
  情绪表达: 内隐(难以读取)
    → 微表情持续时间极短(<250ms)
  调整: performance中的微表情持续时长×0.5·注视增加·静止增加

Sera 基线:
  真实性: 中性(普通人)
    → 无特殊调整·使用KB默认值

棒球帽男人 基线:
  不可读性: 最大化(角色设定)
    → 帽檐阴影遮眼·只露下半脸
    → 不应用面部performance
    → 身体语言: 静止·无多余动作·站姿笔直但肩膀微前收
```

## §3 使用方式

```
Scene Designer v2.1:
  1. 读取本文件 (一次性·750 tokens)
  2. 对每句对白:
     a. 检查剧本是否有显式表演注释 → 有则直接翻译
     b. 无显式注释 → 分析对白文本+角色关系 → 确定心理状态
     c. 查询本KB → 获取解剖学描述
     d. 应用个性化调整(角色基线) → 产出 performance YAML
  3. 自检: performance不含情绪标签·描述可量化

Scene Auditor:
  Phase 1 新增 R-PERF-07~09 检查:
    - 正则扫描 performance 字段禁止情绪词 (零LLM·100%准确)
    - 对白帧 performance 必须覆盖 ≥1 个 facial 维度
    - performance 描述必须包含可量化标记(约/mm/Hz/ms/秒)

Gate 0:
  R16: performance 字段禁止情绪词 (正则·零LLM)
  R17: performance 字段禁止文学修饰词 (正则·零LLM)

prose_smoother:
  无需变更·已有 performance 消费规则
```
