# 导演手册：视觉叙事决策框架

> 基于 KB v5.0 §0-§8（~866条规则）蒸馏而成。四个领域的思维文档（运镜/构图/光影/剪辑）的统一合成。
> 这不是规则书。这是导演在片场做决策时的思维框架。

---

# 卷一：核心原则

## 1. 叙事驱动一切

摄影机、画面、光线、剪辑——它们都是故事的仆人。在做任何视觉决策之前，你只问一个问题：**"这个选择在传达什么？"**

- 运镜：为什么现在动？因为角色的内心状态在变化——他发现了什么、走向什么、逃避什么。删掉这个运动，这场戏会不会变弱？不会就别动。
- 构图：这一帧的视觉重心在哪里？观众的视线应该从哪里出发、经过哪里、最终落在哪里？画面中最大的错误不是"不好看"，而是"视线不知道该看哪里"。
- 光影：这束光在故事世界里的来源是什么？窗户？台灯？月光？没有动机的光源，观众潜意识会感到不安。
- 剪辑：情感是唯一不可妥协的尺度。Murch 的六准则优先级——情感(51%) > 故事(23%) > 节奏(10%) > 视线(7%) > 二维空间(5%) > 三维空间(4%)。情感对了，观众不会注意到视线反了。

## 2. 视觉强度 = 戏剧强度

Bruce Block 的七视觉组件（空间、影调、运动、节奏、色彩、线条、形状）——每个都可以在"对比"和"亲和"之间滑动。组件变化的数量决定观众感知的戏剧强度。

- 紧张场景：增加组件变化——运镜加速、景别收紧、光比拉大、剪辑加快、色彩对比增强
- 平静场景：减少组件变化——运镜静止或极慢、景别稳定、光比柔和、剪辑舒缓、色彩亲和
- 波浪法则：视觉强度必须呈波浪形——连续 >3 个组件变化太久，观众麻木；连续 <2 个组件变化超过 3 分钟，观众走神

## 3. 空间是权力的地图

画面中每一个空间关系都在编码权力：角度、景别、深度分层、受光面积、运动方向。

- 仰角 = 力量/威胁 · 俯角 = 脆弱/渺小 · 平视 = 平等
- 推进 = 进入内心 · 拉远 = 抽离/孤立 · 环绕 = 审视/围困
- 全亮脸 = 坦率/安全 · 半暗脸 = 复杂/冲突 · 全暗脸 = 威胁/未知
- 深空间(多层级) = 冲突/复杂 · 平空间(压缩) = 和谐/亲密

## 4. 省略是最高的技巧

默奇说："少即是多，暗示优于明示。" 你交代的细节越多，观众越成为旁观者。省略掉的部分，观众用自己的想象力填充——想象力永远比银幕上能呈现的更丰富。

- 运镜：什么都不做——固定镜头——往往是最强烈的选择
- 构图：负空间不是"空"，它是未被填满的叙事潜力。大面积负空间压迫主体 = 孤独/无力
- 光影：阴影不是没有光，是主动隐藏信息。悬疑的本质是"信息被阴影掌控"
- 剪辑：保留事件的高峰时刻，删除所有拖沓无新信息的部分。一镜值得留多久？只到它完成叙事传递的那一刻

## 5. 裁决链

当两个好想法冲突时，按此优先级裁决：

```
空间安全(不穿墙·不越界) > 关系线(180度规则) > 动作连续性 > 构图美观 > 光影氛围 > 运镜风格 > 剪辑节奏
```

对应 KB 的来源权威性：Arijon(轴线/机位) > Katz(构图) > Kenworthy(动作) > Gurney(色彩) > Framed Ink(构图风格) > Murch(剪辑)

# 卷二：意图→技法映射

## "我要紧张/悬疑"

| 域 | 响应 |
|------|------|
| 机位 | 低角度仰拍·强化威胁感·机位在关系线同侧但不稳定(手持微晃) |
| 运镜 | 极慢推(S1-S2)·长焦(85mm+)压缩空间·或变速推近——先慢后快再骤停 |
| 构图 | 紧框·浅景深·主体被负空间压迫·深度分层增加(前-中-后各有活动暗示威胁) |
| 光影 | 高光比(1:8+)·硬光·单侧低角度光源·冷色温(5600K+)·暗区>70%·高光区<20%·光源动机明确但方向异常 |
| 剪辑 | 镜头时长逐渐缩短·动作→反应间隙压缩·间歇式节奏——紧-松-紧-松(不让观众适应) |

## "我要亲密/温馨"

| 域 | 响应 |
|------|------|
| 机位 | 平视·内反拍单人·关系线同侧·较近的机位距离 |
| 运镜 | 极慢推(S1)·或固定·摄影机跟随角色的微动作(不是主动运动) |
| 构图 | 浅景深·主体占画面大部分·视觉重心在面部三角区·平空间(压缩景深)·负空间温暖柔和 |
| 光影 | 低光比(1:2-1:3)·柔光·侧上45度标准角度·暖色温(2800-3200K)·全亮脸·辅光充足·阴影有细节 |
| 剪辑 | 镜头时长延长·多留反应镜头·小角度剪接(30度内)·让观众"停留"在人物脸上 |

## "我要权力/压迫"

| 域 | 响应 |
|------|------|
| 机位 | 仰角拍强势方·俯角拍弱势方·机位高度差越大权力差越大 |
| 运镜 | 对强势方：推进(S2-S3)强化侵入感·对弱势方：固定或拉远(S2)强化无力感 |
| 构图 | 强势方占画面2/3以上·弱势方被边缘化·或强势方在画面高处·弱势方在低处 |
| 光影 | 强势方半暗脸(伦勃朗光·三角区亮)=复杂/有深度·弱势方全亮脸=暴露/脆弱·或光比不对等(一人高光比一人低光比) |
| 剪辑 | 强势方的镜头持续更长·弱势方的反应被缩短·剪辑节奏由强势方主导 |

## "我要脆弱/孤独"

| 域 | 响应 |
|------|------|
| 机位 | 俯角·较远的机位距离·让角色在画面中显得小 |
| 运镜 | 拉远(S2-S3)=抽离·或静止=无力改变·摄影机不跟随角色 |
| 构图 | 主体在画面中占比小·大面积负空间压迫·平空间(压缩景深)·角色在画面边缘 |
| 光影 | 全亮脸+正面柔光=暴露·或逆光剪影=消失·低光比(但冷色温)=脆弱版的柔和 |
| 剪辑 | 镜头多留·让角色"独自在画面里"的时间延长·少切·弱化外部世界 |

## "我要揭示/发现"

| 域 | 响应 |
|------|------|
| 机位 | 从遮挡物后或透过框架拍摄·营造"偷看/发现"的感觉 |
| 运镜 | 推进(S2-S3)+跟焦·从全景推到揭示物·或升降(Crane up/down)改变视角 |
| 构图 | 逐层展开——前景遮挡→中景活动→背景揭示·深度分层增加 |
| 光影 | 从暗到亮——被揭示处有明确的高光锚点·或从亮到暗——揭示的是阴影中的东西 |
| 剪辑 | 揭示前的镜头拉长(蓄力)→揭示瞬间切到特写(释放)→停留(消化) |

## "我要动作/能量"

| 域 | 响应 |
|------|------|
| 机位 | 低角度·广角(24-35mm)夸大运动感·多机位覆盖关键位置 |
| 运镜 | 跟拍(S4-S6)·手持微晃增加临场感·或摇摄跟随·反向运动制造碰撞感 |
| 构图 | 对角线构图·动感最强·广角近拍夸大透视·运动方向留空间 |
| 光影 | 中等光比(1:4-1:6)·硬光·多点位照明(动作范围大)·不用复杂布光(运动轨迹优先) |
| 剪辑 | 在运动中切·三阶段(建立-升级-释放)·动作越激烈越需要间歇的"静" |

# 卷三：场景模式速查

## 对话场景（双人）

**建立**: 外反拍双人·交代空间关系和人物位置
**推进**: 情绪上升→内反拍单人→共轴推进→景别收紧(MS→MCU→ECU)
**权力博弈**: 低角度强势方+平视弱势方·光比不对等·强势方镜头更长
**关系转折**: 可跨线一次(仅此一次)·跨线后用演员重新就位建立新轴线
**节奏**: 情绪紧张→镜头逐渐缩短·情绪释放→镜头逐渐加长·多留反应镜头

## 动作场景

**三阶段节奏(P0)**:
1. 建立：全景·交代空间·人物关系·冲突来源
2. 升级：运镜加速(S4→S7)·景别收紧(FS→MCU)·剪辑加快(10→25次/分钟)
3. 释放：慢镜·远景·静默——给观众呼吸窗口

**在运动中切**：每个新镜头以某种运动开始·运动掩盖剪切点
**动作方向一致(P0)**: 同一演员连贯动作在两个镜头中方向必须一致
**呼吸法则**: 紧张段→释放段→紧张段·持续高强度=观众麻木

## 悬疑场景

**核心机制**: 信息被阴影掌控——观众能看到什么和不能看到什么由光决定
**运镜**: 极慢推(S1)+长焦(85mm+)·或固定广角+演员在画面内移动
**光影**: 低调(Low-Key)·暗区>70%·硬光·单侧低角度·冷色温(5600K+)
**构图**: 前景亮+背景暗(压迫感)·或被摄体在画面边缘·大面积负空间
**节奏**: 间歇式——紧-松-紧-松·不让观众适应·变速推近制造"有什么要发生"

## 抒情/沉思场景

**运镜**: 超慢推(S1)+柔焦·或静止→拉远(S2)·或横向漂移(S2-S3)
**光影**: 高调或中间调·低光比(1:2-1:3)·暖色温(2800-3200K)·柔光
**构图**: 平空间·主体居中或三分法·画面稳定·留呼吸空间
**剪辑**: 镜头延长·多留反应和空镜·让观众"在画面里停留"

# 卷四：跨域联动网络

## 运镜起止 ↔ 构图景别

运镜的起幅和落幅是两个独立的构图画面。起幅=观众的空间锚点，落幅=运动的目的地。落幅的景别决定运动的情绪终点：落在ECU=推向内心·落在LS=拉向环境。运动轨迹中间经过的区域需要是可构图的——如果轨迹中间经过不可放置区域(穿墙/道具)，这个运动不可行。

## 光源方向 ↔ 可用机位

主光方向确定后，摄影机的可移动范围被限制在光源的同一侧。如果主光在右侧，摄影机跑到左侧去拍——阴影方向在剪辑时会跳。解决方案：先定光源、再定机位。硬光单侧光源时，机位必须在光源同侧180度内。

## 景别变化 ↔ 剪辑节奏

景别变化幅度 = 视觉跳跃幅度。全景→特写 = 大跳 = 强调/震惊。中景→近景 = 小跳 = 自然的注意力转移。连续小跳(小角度剪接) = 亲密/流畅。连续大跳 = 断裂/紧张。景别变化频率 = 剪辑节奏——收紧景别+加快切 = 紧张上升。

## 色彩基调 ↔ 情绪弧线

暖色域(橙/黄/红) = 推进/亲近/温馨。冷色域(蓝/青/紫) = 后退/疏离/紧张。互补色碰撞(蓝-橙/红-绿) = 冲突/能量。色彩亲和(类似色) = 和谐/平静。整场戏的色温从暖→冷 = 情绪从亲密→疏离。色温从冷→暖 = 情绪从紧张→释放。

## 运动速度 ↔ 光比 ↔ 剪辑速率（三者联动）

紧张上升 = 运镜加速(S1→S5) + 光比拉大(1:2→1:8) + 剪辑加快(镜头缩短) + 景别收紧(FS→ECU)。
情绪释放 = 运镜减速(S5→S1或静止) + 光比缩小(1:8→1:3) + 剪辑放缓(镜头延长) + 景别放宽(ECU→FS)。

# 卷五：安全网（P0 阻断级）

这些不是你"应该考虑"的——这些是开拍前必须检查的：

## 1. 关系线同侧（D-TRI-02）
**检查**: 画俯视图——两个演员的连线。所有机位在同一侧吗？
**违反**: 观众的空间感知崩溃——"跳轴"。唯一例外：场景中段有明确戏剧理由(冲突升级/权力转移)，跨线后必须用演员重新就位建立新轴线。

## 2. 动作方向一致
**检查**: 角色从镜A到镜B的运动方向。从左到右？保持从左到右。
**违反**: 观众以为角色突然转身了。修：要么方向一致，要么中间插入转身镜头。

## 3. 视线方向匹配（E-MTC-01）
**检查**: A和B互视。A看右 → B必须看左。如果两人都看同一方向，他们一定不是在互相对视。
**违反**: 观众不知道他们在看什么。这不是"不顺眼"——是空间关系直接瓦解。

## 4. 光源物理锚点
**检查**: 每个镜头的主光方向，空间里有没有对应的光源(窗户/灯具/天光)？
**违反**: 光源无来处——观众潜意识感到不安。混合色温必须有叙事理由(L-CT-02 P0)。

## 5. 空间可行性（GEN-02）
**检查**: 运镜轨迹是否穿过墙壁/家具？机位是否在可放置区域内？演员站位是否越界？
**违反**: 物理上不可拍摄——这是P0阻断，不可降级。

## 6. 单镜≤15秒（SD2.0硬上限）
**检查**: 每镜设计时长是否在15秒内？
**违反**: SD2.0无法执行。拆分方案：A镜末帧=B镜首帧·动作连续·观众察觉不到拆分。

## 7. 多人面部≤2人（SD2.0硬上限）
**检查**: 同一镜头内是否有≥3人的面部需要清晰渲染？
**违反**: SD2.0面部不可控。方案：拆分单人/双人交替·或降为全景(面部不可见)。

## 8. 正向描述（SD2.0铁律）
**检查**: 所有画面描述中是否出现：不/别/勿/禁止/避免/没有/不要？
**违反**: SD2.0将所有token视为正向指令。"不要抖动"→读到"抖动"→画面抖动。修：用正向替代——"固定机位·画面稳定"。
