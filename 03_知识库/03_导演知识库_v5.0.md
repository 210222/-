# 一、对话场景 · 镜头调度

## 1.1 三角形原理（Arijon 电影语言的语法 Ch.4）

| 规则ID | 规则 | 来源 | 优先级 |
|------|------|------|:--:|
| D-TRI-01 | 两个对话演员之间有一条关系线(line of interest)，以相互视线走向为基础 | Arijon Ch.4 | P0 |
| D-TRI-02 | **首要规则：** 选择关系线的一侧并保持在那侧——不能从一个三角形机位跳到另一侧的机位。这是电影语言最重要的规则之一 | Arijon Ch.4 §4.2 | P0 |
| D-TRI-03 | 关系线必须穿过两个中心人物的头部——无论身体位置如何，头部是注意力的来源 | Arijon Ch.4 §4.3 | P0 |
| D-TRI-04 | 三角形底边上的两个摄影机位+顶端位置，构成七个可选机位 | Arijon Ch.4 §4.4 | P1 |
| D-TRI-05 | **外反拍角度(external reverse angles)**：底边上两机位在演员背后，靠近关系线，向里把两人都拍入画面——最经典的对话机位 | Arijon Ch.4 §4.4 图4.7 | P0 |
| D-TRI-06 | **内反拍角度(internal reverse angles)**：摄影机在两个演员之间，从三角形向外拍，靠近关系线——单人近景机位 | Arijon Ch.4 §4.4 图4.8 | P0 |
| D-TRI-07 | **主观视点角度**：摄影机背对背位于关系线上，各自成为镜头外演员的主观视点(POV) | Arijon Ch.4 §4.4 图4.9 | P1 |
| D-TRI-08 | **平行位置**：摄影机位于接近关系线的三角形底边，视轴互相平行，各拍一个演员的侧面像 | Arijon Ch.4 §4.4 图4.10 | P1 |
| D-TRI-09 | **大三角形组合**：上述三种基本变化可组合成一个大三角形布局，共七个摄影机视点。唯内反拍和平行位置只能各拍一个演员 | Arijon Ch.4 §4.4 图4.11 | P1 |
| D-TRI-10 | 演员成直角排列时，仅有两种三角形可选。摄影机视点在底边上形成直角关系 | Arijon Ch.4 §4.4 | P1 |
| D-TRI-11 | **四种基本形体关系**：①面对面 ②并排 ③一个背向另一个 ④背靠背 | Arijon Ch.4 §4.1 | P2 |
| D-TRI-12 | **五种基本姿势**：卧姿/跪姿/坐姿/倚姿/立姿。组合提供宽广的视觉表现 | Arijon Ch.4 §4.1 | P2 |
| D-TRI-13 | 主镜头的摄影机视点在三角形顶端角上。主要优点是演员各自保持在画面固定一侧 | Arijon Ch.4 §4.2 | P1 |
| D-TRI-14 | **共轴推进法**：三角形底边上两个视点之一的摄影机沿视轴向前推，得到更近镜头——使该演员更突出 | Arijon Ch.4 §4.4 图4.14 | P1 |
| D-TRI-15 | **成直线的演员有三种三角形处理，成直角的演员仅两种——共五种变化** | Arijon Ch.4 §4.4 | P2 |

## 1.2 双人对话 · 九种机位变体（Arijon 第5章）

| 规则ID | 规则 | 来源 | 优先级 |
|------|------|------|:--:|

| D-DUO-02 | **外反拍最强对话机位**：两个优点①纵深——演员位于两个不同平面 ②一个演员面对摄影机(开放形体)占主导 | Arijon Ch.4 §4.5 | P0 |
| D-DUO-03 | **三分之二构图法**：标准画幅(4:3)，讲话演员占画面三分之二，对话者占三分之一。后者稍微虚化更有力突出说话者 | Arijon Ch.4 §4.5 | P2 |
| D-DUO-04 | 前景演员的鼻尖不应超出面颊轮廓线——外反拍中我们根本看不到背向者的鼻子 | Arijon Ch.5 §5.1 | P2 |
| D-DUO-05 | **数量对比(number contrast)**：外反拍(两人) + 内反拍(一人)结合→三种位置：两人到两人/两人到一人/一人到一人 | Arijon Ch.5 §5.2 | P1 |
| D-DUO-06 | **演员肩并肩**：两人面向同一方向——共同注视而非互视。关系线横跨他们的头部 | Arijon Ch.5 §5.3 | P1 |
| D-DUO-07 | **演员一前一后**：纵深方向形成层次，创造空间深度。常用外反拍+平行摄影机位 | Arijon Ch.5 §5.4 | P1 |
| D-DUO-08 | **摄影机距离与高度**：距离决定景别，高度决定视角心理学。低角=人物主导力，高角=人物弱势 | Arijon Ch.5 §5.5 | P2 |
| D-DUO-09 | **三角形2号位置最弱**：从侧面拍演员，处于同一平面、所占空间相等。可用于对话开始/结束、剪辑顿歇(pause)、或过渡 | Arijon Ch.4 §4.5 | P2 |
| D-DUO-10 | **电话里交谈**：非面对面交流的机位处理。视线方向不直接相对，但仍需维持银幕方向一致 | Arijon Ch.5 §5.5 | P1 |
| D-DUO-11 | **演员在镜子中的反映**：镜子对话的特殊机位——摄影机不直接拍演员而拍镜中映像 | Arijon Ch.5 §5.5 + Katz Ch.10 | P2 |
| D-DUO-12 | **相反的对角线**：对角线方向对比创造对抗感，反拍时可互换画面位置 | Arijon Ch.5 §5.5 | P2 |
| D-DUO-13 | 拍摄单人镜头时让第二个演员留在摄影机视线之外——保证不跨关系线+让表演更自然 | Arijon Ch.5 §5.5 | P1 |
| D-DUO-14 | 演员一定不能看着摄影机镜头——除非有强烈戏剧动机(独白/讲述) | Arijon Ch.5 §5.5 | P1 |
| D-DUO-15 | **人物并排躺着**：特殊体位衍生机位规则。关系线穿过头部，即使身体平行或反向 | Arijon Ch.5 §5.5 | P2 |

| C-DEP-04 | **大气透视(空气透视)**：距离越远的物体饱和度越低、色温越冷(偏蓝灰)，近景偏暖偏饱和(→参见COL-PRI-08·色彩章节的完整大气透视规则) | Gurney + Visual Story | P1 |
| C-DEP-05 | **景深调度**：前景-中景-背景的分层不仅通过清晰度，还可通过光照强度、色彩温度、运动速度区分 | Katz Ch.4 | P1 |
| C-DEP-06 | **重叠法创造深度**：物体部分重叠他人/物，自然指示前后空间关系——最原始也最有效的深度线索 | Visual Story | P2 |

## 5.2 摄影机运动方式（Kenworthy Vol.3 + Katz）

| 规则ID | 规则 | 来源 | 优先级 |

| M-MOV-01 | **演员驱动摄影机**：摄影机根据演员运动轨迹和动作同步移动，保持演员在画面中的位置连续性。参考《艾利之书》 | Vol.3 | P0 |
| M-MOV-02 | **与摄影机一同运动**：摄影机和演员以相同速度和方向同步移动，演员保持在画面核心。参考《越轨追击》《功夫梦》 | Vol.3 | P0 |
| M-MOV-03 | **揭示式运动**：摄影机运动(环绕/推进)打破常规构图期待；将观众注意力从已建立角色转移到新引入的演员或元素 | Vol.3 | P1 |
| M-MOV-04 | **向前运动**：摄影机向前推进以强调主体在后续段落中的重要性；演员运动可牵引摄影机。参考《命运规划局》 | Vol.3 | P1 |
| M-MOV-05 | **侧向运动**：摄影机缓慢侧向移动配合演员运动；创造反映人际关系的复杂场景；保持运动不引人注目。参考《月桂谷》 | Vol.3 | P1 |
| M-MOV-06 | **转向与曲线运动**：摄影机以弧形围绕主体或与主体同步移动。参考《功夫梦》《月桂谷》 | Vol.3 | P1 |
| M-MOV-07 | **短距离运动**：使用走廊固定摄影机+平面运动图；线性空间引导视觉，强化演员短距离运动节奏。参考《命运规划局》 | Vol.3 | P2 |
| M-MOV-08 | **推轨引入演员**：摄影机沿轨道移动跟随或引导演员入画；运动轨迹强化演员出场动态。参考《盗梦空间》《银翼杀手》 | Vol.3 | P1 |
| M-MOV-09 | **摇摄运动**：结合演员运动与摄影机摇摄；最小的努力创造丰富多样的镜头。参考《艾利之书》《功夫梦》 | Vol.3 | P1 |
| M-MOV-10 | **融合运动**：多机位调度与演员运动协调；镜头运动(推/轨)和演员运动形成连贯动态关系 | Vol.3 | P1 |
| M-MOV-11 | **对角线运动**：摄影机沿对角线移动(同时平移)将分离的演员带入同一画面；视觉接近暗示角色关系变化 | Vol.3 | P2 |
| M-MOV-12 | **反向推进**：摄影机和演员以相反方向运动；反向运动增强动态张力和空间深度。参考《艾利之书》 | Vol.3 | P2 |
| M-MOV-13 | 摇镜是三种镜头运动(摇镜/推轨/升降)中唯一不移动摄影机位置完成运动的 | Katz Ch.5 | P2 |
| M-MOV-14 | 摇镜表现空间速度比推轨、升降快 | Katz Ch.5 | P2 |
| M-MOV-15 | 推轨镜头可在单一镜头内移进或移出动作范围，实现视角从一般到特定或相反的转换 | Katz Ch.5 | P1 |
| M-MOV-16 | 环状推轨镜头通过弧形轨道环绕主体，使推轨重要性超过对话，消解主体观察与意见 | Katz Ch.5 | P3 |

## 5.3b ⭐ 运动镜头的二十条基本规律（Arijon Ch.20·全量·必读）

> **来源**: Arijon《电影语言的语法》第20章·"运动镜头的二十条基本规律"
> **重要度**: P0/P1·每一条都是电影语法的基石
> **前置规则**: M-MOT-01(运镜必须有动机) — 这是二十条规律的零号法则

| 规则ID | 规则 | 来源 | 优先级 |
|------|------|------|:--:|
| M-20R-01 | **主观视点=最强烈的动作感**：把摄影机当作运动中的人物眼睛——当摄影机代表一个参与者的视点时，动作最富于紧张感 | Ch.20 §1 | P1 |
| M-20R-02 | **摄影机作为演员眼睛需节制使用**：用摄影机代表演员眼睛会使观众无法看到演员面部——除非戏剧上绝对必要，否则不采用 | Ch.20 §2 | P1 |
| M-20R-03 | **直接表现vs主观表现的选择**：可以客观地表现参与者(让他留在画面内·正面拍摄)，也可以主观地表现(以他的视点拍摄)——决定取决于戏剧需要 | Ch.20 §3 | P1 |
| M-20R-04 | **揭示被期待或未被期待的事物**：每个运动镜头结束时，画面应对准观众期待的东西，或反其道对准未被期待的东西——取决于戏剧效果 | Ch.20 §4 | P1 |
| M-20R-05 | **直接切换比移动镜头更经济**：如果事情已交代明白，一个直截了当的切换比一个精心设计的移动镜头更有效，也更省钱 | Ch.20 §5 | P1 |
| M-20R-06 | **跟随次要人物从一个注意中心转移到另一中心**：利用次要人物的运动把戏从一个中心人物转到另一中心人物——摄影机跟随次要人物离开第一中心，在运动中引向第二中心 | Ch.20 §6 | P1 |
| M-20R-07 | **三部分运动公式(静→动→静)**：所有摄影机运动都应尽可能遵从"静止开始→移动→静止结束"的三段模式。镜头从完全静止开始，然后移动，最后又完全静止 | Ch.20 §7 | P0 |
| M-20R-08 | **摇摄和移动摄影结合**：只包含一种运动的摄影机动作比几种方向不同的运动结合在一起更受欢迎。摇摄和移动摄影在一条连贯的运动路径上结合最为自然 | Ch.20 §8 | P1 |
| M-20R-09 | **重复性动作镜头剪辑灵活性高**：表现反复的动作(如锯木/钉钉子/擦洗)的镜头比只表现一次的镜头容易剪辑得多——剪辑师可在任何动作周期剪断 | Ch.20 §9 | P2 |
| M-20R-10 | **同一对象在同一画面区域沿同一方向运动**：如果一个运动对象要在若干镜头中出现，必须使它在每个镜头的画面中保持在同一区域，并且向同一方向运动 | Ch.20 §10 | P0 |
| M-20R-11 | **省略与重新引入画面元素**：摇摄或横移过程中可有意省略某些元素(如中间景物)，然后在运动终点引入新的元素——这比直接剪切更流畅 | Ch.20 §11 | P1 |
| M-20R-12 | **运动要顺畅、有把握**：犹豫不决、时断时续的运动一看就知道是业余的。摄影机运动必须有自信——要么完全静止，要么平稳移动 | Ch.20 §12 | P0 |
| M-20R-13 | **人物先动→摄影机跟动**：当摄影机跟拍运动的人物时，让被摄者先开始运动，然后摄影机才跟上去——这样运动动机明确，观感自然 | Ch.20 §13 | P1 |
| M-20R-14 | **摄影机走最简单的路线**：摄影机的运动路线应尽可能简单——直线或简单弧线。演员走复杂的调度，摄影机走简单的路 | Ch.20 §14 | P1 |
| M-20R-15 | **起幅和落幅的构图平衡**：运动镜头开始和结束时的静止构图都必须完整平衡——起幅和落幅是观众印象最深的两个画面 | Ch.20 §15 | P0 |
| M-20R-16 | **运动镜头长度由运动本身决定**：一个运动镜头的最短长度等于摄影机完成其运动所必需的时间——不能用剪切缩短正在运动中的镜头 | Ch.20 §16 | P1 |
| M-20R-17 | **人物出画后重新平衡构图**：如果在运动镜头中有人物进出画面，必须在人物离开后重新平衡构图——不能让画面"等着"人物回来 | Ch.20 §17 | P2 |
| M-20R-18 | **背景放映与跑步机创造运动幻觉**：车/船/飞机内的对话场景可用静止摄影机+活动背景(窗外活动景片/背景放映)创造运动幻觉 | Ch.20 §18 | P3 |
| M-20R-19 | **跟拍镜头中背景变化而人物构图不变**：摄影机随人物移动时，人物在画面中的大小和位置保持不变，但背景不断变化——这是跟拍和变焦的本质区别 | Ch.20 §19 | P1 |
| M-20R-20 | **用光效暗示交通工具运动**：可用移动的光线(掠过演员面孔的时明时暗)来表现经过路灯或树木的运动效果，而不必实际移动摄影机 | Ch.20 §20 | P2 |
| M-20R-00 | **⭐ 所有摄影机运动必须有戏剧动机(零号法则)**：运动不是外加的花招——运动必须出于内在的戏剧需要。绝不为"好看"而移动摄影机 | Ch.20 §20.3 | P0 |

> **核心理念**: 视觉结构应当镜像戏剧结构。冲突上升=对比增强·冲突解决=亲和增强。

## 8.1 七视觉组件

| 规则ID | 组件 | 核心原理 | 来源 | 优先级 |
|------|------|---------|------|:--:|
| VS-COM-01 | **空间** | 景别·角度·构图三子维度统一控制——决定观众与场景的距离感 | Block Ch.1-3 | P1 |
| VS-COM-02 | **影调** | 亮度·光比·影调风格独立计数——影调对比度=戏剧张力强度 | Block Ch.4 | P1 |
| VS-COM-03 | **运动** | 摄影机运动+物体运动同时变化仍计1次——运动变化频率=节奏感知 | Block Ch.5 | P1 |
| VS-COM-04 | **节奏** | 分镜时长+切点密度独立计数——节奏模式决定观众疲劳/兴奋曲线 | Block Ch.6 | P1 |
| VS-COM-05 | **色彩** | 色温·饱和度·色彩方案·≠影调·独立计数——色彩即情绪语言 | Block Ch.7 | P1 |
| VS-COM-06 | **线条** | 主导线条方向+秩序感独立计数——水平(稳定)·垂直(力量)·斜线(动态)·曲线(柔和) | Block Ch.2 | P2 |
| VS-COM-07 | **形状** | 主体轮廓+正负空间形状独立计数——圆形(和谐)·三角形(张力)·矩形(秩序) | Block Ch.2 | P2 |

## 8.2 对比与亲和法则（Contrast & Affinity）

| 规则ID | 规则 | 来源 | 优先级 |
|------|------|------|:--:|
| VS-CA-01 | **视觉对比=戏剧冲突**：场景中变化的视觉组件越多，感受的视觉强度越大。冲突上升场景应增加对比维度 | Block Ch.8 | P1 |
| VS-CA-02 | **视觉亲和=戏剧和谐**：组件保持相似=观众感到平静、和谐、可预测。和解/平静场景应使用亲和 | Block Ch.8 | P1 |
| VS-CA-03 | **变化安全等级**：≤2组件变化=低变化·亲和力高(适合对话/情感积累)·3组件变化=标准推进·4组件变化=高变化·需标注(适合闪回/插入/情绪转折)·5组件变化=极高·必须标注蓄意节点类型·≥6组件变化=全维度断裂·除非场景转换否则阻断 | Block Ch.8 | P1 |
| VS-CA-04 | **连续高对比=视觉噪音**：持续>3组件的连续变化会让观众视觉疲劳→麻木→失去注意力 | Block Ch.8 | P1 |
| VS-CA-05 | **连续高亲和=视觉单调**：连续<2组件变化的段落超过3分钟→观众注意力涣散 | Block Ch.8 | P1 |
| VS-CA-06 | **对比/亲和的波浪法则**：视觉强度应呈波浪形——建立(低对比)→上升(增加对比)→高潮(最大对比)→释放(降低对比) | Block Ch.8 | P1 |

## 🆕 8.2b 影调体系 (VS-TONE · 高调/低调/对比/渐变/分层/情绪)

> **核心理念**: 影调是视觉结构中最直接的情绪传递器——从高调到低调的光谱映射着从安全到危险的叙事弧线。
> **覆盖**: 高调理论(15条)·低调理论(15条)·影调对比(10条)·影调渐变(8条)·影调分层(6条)·影调与空间(4条)·影调与情绪(4条)

| 规则ID | 规则 | 来源 | 优先级 |
|------|------|------|:--:|
| VS-TONE-01 | **高调画面以白色和浅灰色为主导**，阴影面积最小化，整体亮度值集中在7-9区(10区制)，适合梦幻/回忆/纯真/乐观场景 | Visual Story Ch.4 P89-92 | P1 |
| VS-TONE-02 | **高调场景中主体曝光应比中性灰高1-2档**，使画面呈现"明亮轻盈"的视觉质感——但不可过曝丢失纹理细节 | Visual Story P91 | P1 |
| VS-TONE-03 | **高调画面并非没有阴影**，而是阴影极淡极弱——用柔光散射/反光板填充/大面积柔光箱消除硬边阴影的存在感 | Visual Story P92 | P1 |
| VS-TONE-04 | **高调适合表现轻盈正向情感**：梦幻/回忆/天堂/纯真/乐观/安全——不可用于压抑或悬疑场景，否则产生矛盾情绪 | Visual Story P91 | P1 |
| VS-TONE-05 | **高调场景中服装/道具/背景应避免大面积深色块**——任何超过画面20%面积的暗区都会破坏高调的整体统一感 | Visual Story P92 | P2 |
| VS-TONE-06 | **高调布光的反光率目标为70-80%**——用测光表确认整体亮度保持在高亮范围，亮部保留纹理细节而非全白 | Light Science P152 | P2 |
| VS-TONE-07 | **高调场景的前景/中景/背景亮度差不应超过1.5挡**——层次通过微妙的明度变化而非大反差区分，保持整体轻盈感 | Visual Story P92 | P2 |
| VS-TONE-08 | **高调用干/少用补光**——直接用主光提高整体亮度等级，补光仅用于控制关键阴影密度而非补充基础亮度 | Set Lighting P92 | P1 |
| VS-TONE-09 | **高调场景中色彩饱和度应整体偏低**——高亮环境下高饱和色产生刺目感，使用粉彩色系/中性色系搭配 | Visual Story P91 | P1 |
| VS-TONE-10 | **高调中的"白上加白"技术**：用不同色温的白(暖白3200K/冷白5600K)区分同亮度区域，避免画面平白无层次 | Set Lighting P93 | P2 |
| VS-TONE-11 | **高调人像需用边缘光勾勒轮廓**——白色背景中的白色主体若无边缘光分离，面部轮廓会融入背景消失 | Light Science P153 | P2 |
| VS-TONE-12 | **高调场景适合开场/转场/和解/升华**——利用高调的"轻"感让观众从紧张情绪中释放，但不适合冲突核心段落 | Visual Story P91 | P1 |
| VS-TONE-13 | **高调摄影常用柔光箱/反光板/散射材料扩散光线**，消除锐利阴影以获得"无重量"的画面质感 | Visual Story P92 + Light Science | P1 |
| VS-TONE-14 | **逐层曝光法用于高调布光**：先设定背景光到7区→再设定主体光到7-8区→最后用补光控制阴影密度在5区以上 | Light Science | P2 |
| VS-TONE-15 | **高调中的"亮上加亮"技术**：白色/亮色主体+白色/亮色背景+均匀漫射前光+无可见阴影——创造干净无重量感画面 | Light Science P150-153 | P1 |
| VS-TONE-16 | **低调画面以深灰和黑色为主导**，大面积阴影覆盖70%以上画面，仅小范围精确控制的高光区域揭示形态和叙事焦点 | Visual Story P89, P92 | P1 |
| VS-TONE-17 | **低调场景的关键不是"暗"而是"控制"**——精确控制高光区域的位置/面积/亮度，决定观众看到什么和看不到什么 | Visual Story P93 | P1 |
| VS-TONE-18 | **低调摄影中高光区域应占画面面积不超过20-30%**——过多的亮区会稀释低调的压抑感和神秘性 | Visual Story P92 | P1 |
| VS-TONE-19 | **单点光源是低调布光的基础**——用一只聚光灯或束光筒制造窄光束，仅照明主体关键部分（眼睛/手部/道具） | Light Science P156 | P1 |
| VS-TONE-20 | **低调适合表现神秘/悬疑/压抑/危险/悲伤/噩梦/权力**——阴影的不可见性激活观众想象，适合惊悚类型 | Visual Story P91 | P1 |
| VS-TONE-21 | **低调场景中补光应控制在主光1:4以上光比**——大光比是低调的灵魂，最低不可低于1:4否则失去低调质感 | Light Science P157 | P1 |
| VS-TONE-22 | **低调布光需注意暗部细节保留**——完全漆黑(0区)面积不应超过画面40%，否则信息过少观众失去视觉锚点 | Visual Story P93 | P1 |
| VS-TONE-23 | **侧光和侧逆光是低调的首选方向**——正面光缩小阴影面积削弱低调感，应尽量避免无遮挡的正面光源 | Light Science P156 | P1 |
| VS-TONE-24 | **低调场景中人物服饰和背景应选择深色系**——浅色服装反射过多光线会被坏场景暗调的统一沉浸感 | Visual Story P93 | P2 |
| VS-TONE-25 | **暗中加暗技术**：用旗板/遮光片/黑布进一步削减环境中的多余光线，仅在需要的位置保留精确亮区 | Light Science P158 | P2 |
| VS-TONE-26 | **低调场景中光源动机必须明确**——台灯/烛光/月光/窗口的光线方向必须交代，无动机的亮区让观众感到疑惑 | Set Lighting P156 | P1 |
| VS-TONE-27 | **低调人像常用单侧硬光(伦勃朗光/分割光)**，让半边脸融入黑暗——半张脸的缺失=角色神秘性/复杂性/不可知 | Gurney P134 | P1 |
| VS-TONE-28 | **低调场景反光率目标为15-30%**——测光表读数集中在低亮度范围，确保暗部有纹理区别而非全黑死黑 | Light Science P157 | P2 |
| VS-TONE-29 | **低调场景的整体亮度不应均匀降低**——保持亮区与暗区的锐利对比是低调的力量来源，均匀暗淡=曝光不足而非低调 | Visual Story P93 | P1 |
| VS-TONE-30 | **低调中的"黑中有黑"技术**：用不同色温(蓝黑/暖黑/灰黑/冷黑)区分大面积阴影中的层次，避免单一死黑 | Set Lighting P158 | P2 |
| VS-TONE-31 | **影调对比度由画面中最高亮度和最低亮度之间的差值决定**——差值越大对比度越高，视觉冲击越强 | Visual Story P95 | P1 |
| VS-TONE-32 | **高对比度在每场戏中最多使用两次**——频繁使用高对比会使观众的对比敏感性降低，失去震撼效果 | Visual Story P97 | P1 |
| VS-TONE-33 | **低对比度=柔和/梦幻/朦胧**——明度值集中在2-3个连续区域内的画面产生柔和安静的视觉感受，适合抒情/回忆段落 | Visual Story P96 | P1 |
| VS-TONE-34 | **影调对比度可通过摄影机曝光/布光/后期调色三层控制**——任一层改变都可调整整体对比度水平，三层叠加效果最强 | Visual Story P95 | P2 |
| VS-TONE-35 | **高对比场景中明暗过渡的边界锐度决定能量强度**——锐利硬边=强能量/紧张·柔和渐变=低能量/舒缓 | Visual Story P96 | P1 |
| VS-TONE-36 | **故事转折点/情感爆发点应使用高影调对比**——和解/平淡段落应使用低影调对比，对比度曲线映射戏剧曲线 | Visual Story P97 | P1 |
| VS-TONE-37 | **在宽银幕画面中，对比度最高的区域自动成为视觉重心**——利用这一点控制观众的视线落点和注意力分配 | Visual Story P98 | P1 |
| VS-TONE-38 | **明暗反差控制中的"三区剥离"法**：将画面分为亮区(7-9)/中间区(4-6)/暗区(1-3)——反差来自最大区和最小区之间的跳跃 | Visual Story P98 | P2 |
| VS-TONE-39 | **低对比度环境(雾/阴天/柔光)去饱和化色彩也柔化了影调边界**——适合表现不确定/模糊/过渡/中间状态 | Visual Story P97 | P2 |
| VS-TONE-40 | **影调对比的叙事节奏匹配**：开场用中对比→冲突升温时提高对比→高潮达最大对比→释放时降低对比——波浪形节奏 | Visual Story P98 | P1 |
| VS-TONE-41 | **影调渐变是从黑到白的连续明度递变**——包含尽可能多的中间灰阶，创造平滑连贯的视觉流动和情绪过渡 | Visual Story P123 | P1 |
| VS-TONE-42 | **渐变梯度越缓(更多中间灰阶)画面越宁静舒缓**——渐变梯度越陡(灰阶跳跃)画面越紧张越具戏剧性 | Visual Story P123 | P1 |
| VS-TONE-43 | **天空/水面/墙壁/布料等大面积表面上的影调渐变产生情绪流动感**——渐变方向(上→下/左→右)引导视线扫描方向 | Visual Story P125 | P1 |
| VS-TONE-44 | **平行渐变(水平方向递变)传递稳定与延展**——放射状渐变(中心向四周)传递膨胀/爆发/能量扩散 | Visual Story P127 | P2 |
| VS-TONE-45 | **影调渐变的缺失会产生平面感和硬朗感**——完全无渐变的画面(明亮区域直接邻接暗区)产生果断/分割的视觉感受 | Visual Story P126 | P2 |
| VS-TONE-46 | **两个相邻场景可通过影调渐变的连接实现视觉转场**——从A场景的暗部渐变自然连接到B场景的亮部渐变 | Visual Story P128 | P2 |
| VS-TONE-47 | **角色面部上的影调渐变(从额头亮到下巴暗)创造立体感和情绪深度**——全亮脸=开放·半暗脸=神秘·全暗脸=威胁 | Visual Story P125 | P1 |
| VS-TONE-48 | **黎明/黄昏场景利用自然影调渐变(天空从亮到暗的连续过渡)建立时间感和情绪基调**——是最自然的渐变来源 | Visual Story P126 | P1 |
| VS-TONE-49 | **影调分层将画面划分为三个功能区**：暗区(0-3区·神秘/隐藏/基础)+中间区(4-6区·细节/过渡/信息)+亮区(7-9区·重点/揭示/空间) | Visual Story P126 | P1 |
| VS-TONE-50 | **三层比例决定画面性格**：暗区主导=低调叙事·中间区主导=自然写实·亮区主导=高调梦幻——主导区移动=情绪转型 | Visual Story P127 | P1 |
| VS-TONE-51 | **影调分层强化深度**: 前景暗→中景中间调→背景亮·前景暗+背景亮=最强空间深度感 | Visual Story | P1 |
| VS-TONE-52 | **中间调是信息最密集的区域**——观众的细节搜索行为主要发生在中间区，暗区和亮区起情绪引导而非信息传递作用 | Visual Story P125 | P1 |
| VS-TONE-53 | **在每个场景的交代镜头中先用三层分布明确画面的影调空间结构**，再在后续镜头中保持影调分层的相对比例一致性 | Visual Story P128 | P1 |
| VS-TONE-54 | **影调分层的戏剧性运用**：角色从亮区走向暗区=从安全走向危险/从已知走向未知——空间中的影调移动本身就是叙事 | Visual Story P129+ | P1 |
| VS-TONE-56 | **前景亮+背景暗=压迫/不稳定感**——反向影调分布制造视觉紧张，适合悬疑/危机/噩梦/角色被围困的场景 | Visual Story P60 | P1 |
| VS-TONE-57 | **影调对比度与空间深度呈正比关系**——同一场景中前后景的影调差异越大，感知空间深度越强；对比越小空间越平 | Visual Story P97 | P1 |
| VS-TONE-58 | **多层影调构建超级深度阶梯**：背景(8区)+中景(4区)+前景(1区)+最前景剪影(0区)=四层深度结构，制造极致纵深感 | Visual Story P122 | P1 |
| VS-TONE-59 | **高调情绪谱系**：明亮=开放/安全/纯真·轻=无忧/自由·明亮+柔光=梦幻/回忆·明亮+冷色=冷静/医疗/无菌/疏离 | Visual Story P91 | P1 |
| VS-TONE-60 | **低调情绪谱系**：暗=压抑/神秘/威胁·暗+硬边阴影=悬疑/恐惧·暗+柔光=忧郁/沉思·暗+窄光=聚焦/权力/控制 | Visual Story P91 | P1 |
| VS-TONE-61 | **中间调情绪谱系**：中等亮度+均匀分布=自然/日常/真实·中间调+低对比=平静/平凡/无聊·中间调+暖色=舒适/怀旧 | Visual Story P90 | P1 |
| VS-TONE-62 | **影调情绪的突变用于叙事转折**：从高调突变低调=灾难降临/真相揭露/命运反转——影调突变本身即是叙事事件 | Visual Story P130 | P1 |

## 8.4 空间深度构建（The Visual Story）

| 规则ID | 规则 | 来源 | 优先级 |
|------|------|------|:--:|
| VS-SPA-01 | **三层深度结构**：始终用最少三层构建空间深度——前景(最近·最高权重/细节)+中景(过渡·平衡权重)+背景(最远·提供环境氛围)——通过尺寸/影调值/清晰度区分各层 | Visual Story P65-66, P147-148 | P1 |
| VS-SPA-02 | **画面平面(Picture Plane)**：画面平面是摄影机投射影像的矩形表面——四条边定义画框边界，所有视觉元素必须在其内排列 | Visual Story P49/P99 | P1 |
